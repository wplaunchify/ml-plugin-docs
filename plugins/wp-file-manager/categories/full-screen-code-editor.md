## Full Screen Code Editor < File Manager Pro Plugin for Wordpress

**Source:** [https://filemanagerpro.io/article/full-screen-code-editor/](https://filemanagerpro.io/article/full-screen-code-editor/)

1. Please login to your WordPress Dashboard and click on the WP File Manager Tab in the wordpress panel as shown in the screenshot.

![Dashboard](https://filemanagerpro.io/wp-content/uploads/2018/10/step-1.jpg)

2. Click on Settings tab under File Manager Panel in the left side and then click on Code Editor as shown in the screenshot.

![Code Editor](https://filemanagerpro.io/wp-content/uploads/2018/10/fullscreen-editor.jpg)

3. Now Tick the checkbox under the field “Code editor allow fullscreen?” and click Save Changes.
