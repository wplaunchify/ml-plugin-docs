## User Role Restrictions < File Manager Pro

**Source:** [https://filemanagerpro.io/article/user-role-restrictions/](https://filemanagerpro.io/article/user-role-restrictions/)

User Role Restriction is another powerful feature that allows you a lot of feasibility to set different User Roles and Restrictions to each User Role. Here are its Main Features:

- 1. You can define different set of conditions to different kind of User Roles.
- 2. You can give separate folder access to each User Role.
- 3. You can only enable certain options and restrict other options.
- 4. You can hide certain Folder Paths or File Paths.
- 5. You can lock extensions so that the user will not be able to action anything on those particular type of files.
