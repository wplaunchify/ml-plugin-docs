## How to migrate your license to other domain? < File Manager Pro

**Source:** [https://filemanagerpro.io/article/how-to-migrate-license-to-other-domain/](https://filemanagerpro.io/article/how-to-migrate-license-to-other-domain/)

Step 1: Go to the current **My Account**Page
![my account](https://filemanagerpro.io/wp-content/uploads/2019/09/screen-1.jpg)

Step 2: Click on**Active Licenses**
*My Account > Active Licenses*

![Active Licenses](https://filemanagerpro.io/wp-content/uploads/2019/09/screen-2.jpg)

Step 3: Click on **Deactivate** button
**My Account > Active Licenses > Deactivate**

The license will get deactivated from the existing website.

![Active Licenses](https://filemanagerpro.io/wp-content/uploads/2019/09/Screenshot_3.jpg)

Step 4: To activate the license
Use the same order ID and license key for the required website as shown in the screenshot.

The License will get activated.

![Active Licenses](https://filemanagerpro.io/wp-content/uploads/2019/09/Screenshot_4.png)
