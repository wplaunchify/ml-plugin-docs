## User Restrictions < File Manager Pro

**Source:** [https://filemanagerpro.io/article/user-restrictions/](https://filemanagerpro.io/article/user-restrictions/)

User Restriction is a very powerful feature that allows you a lot of feasibility to set different Accessibility and Restrictions to Different Users. Here are its Main Features:

- 1. You can define different set of conditions to different kind of Users.
- 2. You can give separate folder access to each User.
- 3. You can only enable certain options and restrict other options.
- 4. You can hide certain Folder Paths or File Paths.
- 5. You can lock extensions so that the user will not be able to action anything on those particular type of files.
