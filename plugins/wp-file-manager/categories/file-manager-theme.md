## File Manager Theme < File Manager Pro Plugin for Wordpress

**Source:** [https://filemanagerpro.io/article/file-manager-theme/](https://filemanagerpro.io/article/file-manager-theme/)

Our Powerpacked plugin also takes care of the ease of user to work properly and efficiently. As different users are comfortable with different kind of editors so we kept that in mind and created 4 beautiful file manager themes. Please follow these instructions to change the theme you are most comfortable to write code in.

1. Please login to your WordPress Dashboard and click on the WP File Manager Tab in the wordpress panel as shown in the screenshot.

![File Manager Dashboard](https://filemanagerpro.io/wp-content/uploads/2018/10/step-1.jpg)

2. Now Once you are on the page. Click on Settings tab on the left. You will see “Select Filemanager Theme” on that page as shown in the screenshot.

![Setting](https://filemanagerpro.io/wp-content/uploads/2018/10/step-2.jpg)

3. Then you can select any Theme from the dropdown as shown.

![File Manager](https://filemanagerpro.io/wp-content/uploads/2018/10/theme-2.jpg)
