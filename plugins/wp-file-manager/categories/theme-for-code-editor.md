## Theme for Code Editor < File Manager Pro

**Source:** [https://filemanagerpro.io/article/theme-for-code-editor/](https://filemanagerpro.io/article/theme-for-code-editor/)

1. Please login to your WordPress Dashboard and click on the WP File Manager Tab in the wordpress panel as shown in the screenshot.

![File Manager Dashboard](https://filemanagerpro.io/wp-content/uploads/2018/10/step-1.jpg)

2. Click on Settings tab under File Manager Panel in the left side and then click on Code Editor as shown in the screenshot.

![File Manager Panel](https://filemanagerpro.io/wp-content/uploads/2018/10/fullscreen-editor.jpg)

3. Now Select any Theme from the Dropdown in the option “Select theme for Code Editor”

![Themes](https://filemanagerpro.io/wp-content/uploads/2018/10/select-theme-2.jpg)
