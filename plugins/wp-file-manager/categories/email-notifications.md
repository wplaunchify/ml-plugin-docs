## Email Notifications < File Manager Pro Plugin for Wordpress

**Source:** [https://filemanagerpro.io/article/email-notifications/](https://filemanagerpro.io/article/email-notifications/)

Now Keep the site secured and be assured about the person who is making changes and when. We have created this beautiful feature so you can get Email Notification on your Admin Email when someone Uploads, Downloads ans Edits any file. Save the settings and you are safe. Please follow these instructions to make thses settings.

1. Please Click on Settings under the WP File Manager Tab and then Make sure you are under the General Tab.

![Setting](https://filemanagerpro.io/wp-content/uploads/2018/06/email1.jpg)

2. Now If you scroll down you will see the option to Send Notification as shown in this screenshot for Download, Upload and Edit. Please check the boxes shown in the screenshot and you are ready to receive emails on any of the mentioned action taken by the user.

![Send Notification](https://filemanagerpro.io/wp-content/uploads/2018/06/email2.jpg)

3. If you would like to receive email on any email other than Admin Email. Then please navigate to Notification Email and add the email where you would like to see the notifications.

![Notification Email](https://filemanagerpro.io/wp-content/uploads/2018/06/email3.jpg)
