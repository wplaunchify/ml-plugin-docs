## How to get Google Cloud keys < File Manager Pro

**Source:** [https://filemanagerpro.io/article/how-to-get-google-cloud-keys/](https://filemanagerpro.io/article/how-to-get-google-cloud-keys/)

**Create a Service Account:**

1. In the Cloud [Console](https://console.cloud.google.com/projectselector/iam-admin/serviceaccounts/create?supportedpurview=project), go to the Create Service Account Page
2. Select a project.

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen1.png)

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen2.png)
3. In the Service account name field, enter a name. The Cloud Console will fill in the Service account ID field based on this name

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen3.png)
4. In the Service Account description field, enter a description. (e.g. Service account for quickstart)
5. Click Create
6. Select a role

Under Quick access, select Basic, then Owner

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen4.png)
7. Click Continue
8. Click Done to finish creating the Service Account

**Create a service account key:**

1. In the Cloud Console, click the email address for the Service Account you created
2. Select Manage keys

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen5.png)
3. Add key, then click Create new key

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen6.png)
4. Click CreateA JSON key file is downloaded to your computer

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen7.png)
5. Close

![](https://filemanagerpro.io/wp-content/uploads/2021/06/screen8.png)
