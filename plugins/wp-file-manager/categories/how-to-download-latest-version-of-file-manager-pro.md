## How to download the latest version of file manager? < File Manager Pro

**Source:** [https://filemanagerpro.io/article/how-to-download-latest-version-of-file-manager-pro/](https://filemanagerpro.io/article/how-to-download-latest-version-of-file-manager-pro/)

**File Manager Free**

Please go to your WordPress Dashboard and click on Plugins. If there is a new version available there will be a notice under the plugin, where you will be able to click “update now”.

**File Manager Pro**

Method 1:

Please go to your WordPress Dashboard and click on Plugins. If there is a new version available there will be a notice under the plugin, see the screen shot below. If a notice does not appear, you can also click the “Check for updates” button.

![my-account-download](https://filemanagerpro.io/wp-content/uploads/2019/04/plugin-update-7_9.jpg)

Method 2:

Please go to the [My Account](https://filemanagerpro.io/my-account/) page. Under dashboard, you will find the “Licenses & Downloads” section. From there you will be able to download the latest version. Please see the screenshot below:

![my-account-download](https://filemanagerpro.io/wp-content/uploads/2019/04/file-manager-my-account.jpg)

If you still encounter an issue please contact [support](https://filemanagerpro.io/contact/).
