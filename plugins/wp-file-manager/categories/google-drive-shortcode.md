## Google Drive Shortcode < File Manager Pro Plugin for Wordpress

**Source:** [https://filemanagerpro.io/article/google-drive-shortcode/](https://filemanagerpro.io/article/google-drive-shortcode/)

The File Manager Google Drive add-on provides you the ability to edit, delete, upload, download, copy and paste files and folders in Google Drive directly from your WordPress website.

### Please use shortcode for front end

```
[wp_file_manager_google_drive view="list" lang="en" dateformat="d M, Y h:i A" allowed_roles="administrator,editor,author" access_folder="*" write ="true" read="false" allowed_operations="upload,download" ban_user_ids="2,3"]
```
