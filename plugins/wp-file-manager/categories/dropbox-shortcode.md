## Dropbox Shortcode < File Manager Pro Plugin for Wordpress

**Source:** [https://filemanagerpro.io/article/dropbox-shortcode/](https://filemanagerpro.io/article/dropbox-shortcode/)

The File Manager Dropbox add-on provides you the ability to edit, delete, upload, download, copy and paste files and folders in Dropbox directly from your WordPress website.

### Shortcode

```
[wp_file_manager_dropbox app_key="xxxxxxxxxx" app_secret="xxxxxxxxxxx" token="xxxxxxxxxxxxxxx" view="list" lang="en" theme="light" dateformat="d M, Y h:i A" allowed_roles="administrator,editor,author" access_folder="*" write = "true" read = "false" allowed_operations="upload,download" ban_user_ids="2,3"]
```

### Note:

This is standard shortcode, you can make required changes in shortcode according to your need, i.e allowed_operations, allowed_roles, language, themes etc.
