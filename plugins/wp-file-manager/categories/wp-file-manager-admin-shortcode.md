### Shortcode for wp file manager admin

This shortocde will show the file manager on front end. You can control all settings from file manager Backend settings. It will work same as backend WP file Manager.

```
[ wp_file_manager_admin ]
```

Here is how you can control settings related to User Restrictions: Go to your WordPress Dashboard, Click on WP File Manager in the wordpress left panel in wordpress dashboard. Then click on User Restrictions Tab at the top. Where you can change all the settings for the File Manager.

![user-settings](https://filemanagerpro.io/wp-content/uploads/2019/03/user-settings.jpg)

Similarly, You can also control all the settings for the User Role Restrictions from there too. Just Switch tab from “User Restriction” to “User Role Restriction” and You can change all the settings for the File Manager from there.

![user-role-settings](https://filemanagerpro.io/wp-content/uploads/2019/03/user-role-settings.jpg)

Here is how it would show on Front End:

![file-manager-admin-front](https://filemanagerpro.io/wp-content/uploads/2019/03/file-manager-admin-front.png)

Note: All the settings that we do for Backend File Manager applies to Frontend File Manager as well.
