# Where are snippets stored

Sometimes, adding a bad snippets could cause an issue, and deleting it from the database is the easiest way to fix it.

WPCodeBox stores the snippets in the database in two tables:

- ```
wp_wpcb_snippets
```

 - stores the code snippets
- ```
wp_wpcb_folders
```

 - stores the folders
