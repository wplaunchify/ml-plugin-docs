## Getting Started with Kadence Site Assist

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/kadence-site-assist/](https://www.kadencewp.com/help-center/docs/kadence-theme/kadence-site-assist/)

**Kadence** **Site** **Assist** guides you on setting up your *Kadence website* efficiently and thoroughly. **Site** **Assist** is a feature available with the free [Kadence Starter Templates](https://wordpress.org/plugins/kadence-starter-templates/) plugin. Whether you are a WordPress expert or a beginner, Site Assist helps set up the foundation of your website, such as the Site Logo, Colors, Security Configurations, and more.

## Getting Started

To get started with **Site** **Assist**, you must install and activate the free [Kadence Starter Templates](https://wordpress.org/plugins/kadence-starter-templates/) plugin. You can find this plugin by going to the **Dashboard -> Plugins -> Add New** **Plugin** page and searching for **“Kadence”**.

![Search for Kadence Plugins](https://res.cloudinary.com/lwcom/images/w_1024,h_622,c_scale/f_auto,q_auto/v1780435181/prod/Screenshot-2026-06-02-at-4.18.01-PM/Screenshot-2026-06-02-at-4.18.01-PM.png?_i=AA)Once the *Starter Templates*plugin is active on the website, you can access the *Site Assist* *settings* from the **Dashboard -> Site Assist -> Site Assist** page.

![Site Assist Settings](https://res.cloudinary.com/lwcom/images/w_1024,h_865,c_scale/f_auto,q_auto/v1780435735/prod/Screenshot-2026-06-02-at-16-22-37-Site-Assist-by-Kadence-WP-‹-anthony-wp70.instawp.xyz-—-WordPress/Screenshot-2026-06-02-at-16-22-37-Site-Assist-by-Kadence-WP-‹-anthony-wp70.instawp.xyz-—-WordPress.png?_i=AA)This document will walk you through each step of the **Kadence Site Assist** setup process from start to finish.

### Basic Site Setup

The **Basic** **Site** **Setup** helps establish your website identity. From setting the title, tagline, and icon, to setting up the language and timezone. These steps will guide you in setting up your **General WordPress Settings** for your website.

![Basic Site Setup](https://www.liquidweb.com/wp-content/uploads/2025/03/basic-site-setup.jpg)
#### Provide Site Title & Tagline

The first step is to provide the **Site Title & Tagline**. Once clicking on the Setup button, you will be brought to the **Dashboard -> Settings -> General**page.

You can adjust the first two fields to set the Site *Title* and *Tagline*.![Tagline](https://www.liquidweb.com/wp-content/uploads/2025/04/Tagline.jpg)
#### Set Site Icon

The **Site** **Icon** can be set from the **Dashboard -> Settings -> General** page. The *Site Icon* represents the Favicon and will be displayed as the Site Icon in web browsers and other applicable areas.

![SiteIcon](https://www.liquidweb.com/wp-content/uploads/2025/04/SiteIcon.jpg)
#### Upload Site Logo

The **Site** **Logo** can be set from the **Customizer -> Header -> Site Identity**settings. The logo will appear in the website header across your website.

Adjust the **Logo Max Width** setting to control the overall Size of the logo.

Use the **Logo Layout** settings to choose what you want to display: just the logo, the logo with your site title, or the full combo of logo, title, and tagline.

You’ll also be able to choose how these things are positioned. Options include:

- Logo on the left, title on the right
- Logo on the right, title on the left
- Logo above, title below
- Title above, logo below![Site Identity](https://www.liquidweb.com/wp-content/uploads/2025/04/Site-Identity.jpg)
#### Set Site Language

Set the default Site Language. This will determine which language WordPress will use and your website code will identify your site as using. *(This setting can be found on the Dashboard -> Settings -> General page.)*

![Site Language](https://www.liquidweb.com/wp-content/uploads/2025/04/Site-Language.jpg)Site languages can also be set on a user-to-user basis by editing the user from the Dashboard -> Users page.

#### Get Site Timezone

Set the official website **Timezone**. You can choose either a city in your desired timezone or a UTC Time Offset.

Use the **Date** **Format** setting to control the format of dates across your website.

Use the **Time** **Format** setting to control the format of specified times across your website.

Use the **Week Starts On** setting to control which day of the week is the first day of the week.![Timezone](https://www.liquidweb.com/wp-content/uploads/2025/04/Timezone.jpg)
### Design & Customization

![Design Customization](https://www.liquidweb.com/wp-content/uploads/2025/03/Design-Customization.jpg)
#### Customize Colors

The first *Design & Customization* step is to **Customize** the **Colors**. This includes setting up the Website Global Palette and other *basic color styles*. This****option will bring you to the **Customize -> Colors & Fonts -> Colors** settings. Notice the settings offer a desktop, tablet, and mobile icon. Use these Icons to control these settings responsively.

Use the **Global** **Palette** settings to adjust the *Global Palette Colors*. Learn how to properly set up your Global Palette [by clicking here](https://www.liquidweb.com/help-docs/software/kadence/theme/theme-color-palette/).

Use the **Site** **Background** setting to set the Site Background. This is for the main website and will appear as the main layer under the content layer. This Background is only viewable on Boxed-Styled-Content.

![Boxed Styled Content](https://www.liquidweb.com/wp-content/uploads/2025/04/Boxed-Styled-Content-scaled.jpg)Use the **Content Background** setting to set the Content Background Color. This is the main Background Color for UnBoxed-Styled-Content and the secondary background for Boxed-Styled-Content.![Customize Colors](https://www.liquidweb.com/wp-content/uploads/2025/04/Customize-Colors-402x1024.jpg)Use the **Title Above Content Background** setting to control the Color of the *Title Above Content background*. This setting offers the use of a Color, Gradient, or Image.

Then, use the **Title Above Content Overlay Color** setting to control an *Overlay* *Color*. You can use a Solid Color or a Gradient.![Above Title Colors](https://www.liquidweb.com/wp-content/uploads/2025/04/Above-Title-Colors.gif)

#### Customize Footer

The next step is to set up and customize the **Footer**. This will bring you to the **Customize -> Footer**settings. 

Use the **Footer** **General** and **Design** **Tab** to control the main *Footer Functionalities* and *Styles*.![Footer settings](https://www.liquidweb.com/wp-content/uploads/2025/04/Footer-settings.gif)To customize the **Footer**, drag and drop items from the **Available Items list**into the *Footer area*. #### Customize Typography

The **Typography** **Settings** control the **Font** **Color**, **Size**, and other **Styles** across your website. 

The **Base** **Font** controls the basic font across the website. For example, in paragraph text and navigation texts.

The **Heading** **Font** **Family** option allows you to set a font that applies across all headings. Notice each Heading Font is set to inherit, which inherits this main font. You can change any individual font by manually selecting the heading font.![Typography Settings](https://res.cloudinary.com/lwcom/images/w_315,h_1024,c_scale/f_auto,q_auto/v1780522295/prod/Typography-Settings_46147045723/Typography-Settings_46147045723.webp?_i=AA)Use the *Color Picker* to select a **Font** **Color**. Then, you can use the *Font Selector* to**set a specific font. On the side of the *Font Selector*, you can set the **Font** **Weight**. Next to the *font weight,* you can set a specified **Font** **Size** and adjust additional font settings.

On the far right of the **Typography** **Setting**, use the dropdown arrow to view an example of the current font setting selection.![Font Settings](https://res.cloudinary.com/lwcom/images/w_357,h_426,c_scale/f_auto,q_auto/v1780522339/prod/Font-Settings_46147206294/Font-Settings_46147206294.webp?_i=AA)

### Website Email Setup

WordPress can handle basic emails, like admin emails, out of the box. However, configuring SMTP is essential to ensure more complex emails, such as contact form submissions, go through properly. The **Website Email Setup** options allow you to install, configure, and test your **Email SMTP Setup**.

![Website Email setup](https://www.liquidweb.com/wp-content/uploads/2025/03/Website-Email-setup.jpg)
#### Install SMTP Plugin

Use the Install SMTP Plugin option to install and activate the [Solid Mail](https://wordpress.org/plugins/wp-smtp/) plugin. This plugin will allow you to quickly set up and configure the SMTP settings for your WordPress website.

![Solid Mail](https://www.liquidweb.com/wp-content/uploads/2025/04/Solid-Mail.jpg)
#### Configure Email Connection

The next step is to configure your **SMTP** **Connection** settings.

![Add Connection](https://www.liquidweb.com/wp-content/uploads/2025/04/Add-Connection.jpg)Once you click on the Add Connection button, select a provider and fill out your SMTP settings respectively.

![SMTP Gif](https://www.liquidweb.com/wp-content/uploads/2025/04/SMTP-Gif.gif)To learn more about the Solid Mail Connection Settings and how to set them up, [click here](https://www.liquidweb.com/help-docs/software/kadence/solid/mail/legacy/set-up-solid-mail/).

#### Test Email Connection

Once you have configured the *SMTP settings*, you should **Test** the **Email** **Connection**. This will check and confirm that the email connection is working as it should. You can do so by filling out the Email Test form. 

This form includes the **To** **Email**, a **Subject**, and a **Message**. Fill out the details, then click on the **Send Test Email**button to test your email.

![Test Connection](https://www.liquidweb.com/wp-content/uploads/2025/04/Test-Connection-1024x373.jpg)Once the test email is confirmed to work, your emails will work across the website. Including emails from [Kadence Forms (Adv)](https://www.liquidweb.com/help-docs/software/kadence/advanced-form-block/) blocks.

### Website Performance Setup

![Website Performance Setup](https://www.liquidweb.com/wp-content/uploads/2025/04/Website-Performance-Setup.jpg)
#### Install Performance plugin

Use the **Install Site Performance Plugin** option to install and activate the **Solid** **Performance** plugin. This plugin will allow you to configure various optimization settings for your website, improving your overall page speed and performance.

![Solid Performance Plugin](https://www.liquidweb.com/wp-content/uploads/2025/04/Solid-Performance-Plugin.jpg)
#### Enable Page Caching

Page Caching helps improve the overall front-end performance of your website. [Click here](https://www.liquidweb.com/help-docs/software/kadence/solid/performance/) to learn more about caching in general.

You can enable **Solid Performance Caching** from the **Dashboard -> Settings -> Solid Performance** page.![Enable Page Caching](https://www.liquidweb.com/wp-content/uploads/2025/04/Enable-Page-Caching.jpg)
#### Enable Lazy Load Images

Images that appear below the fold should be **Lazy Loaded**. This is standard practice in optimal web development. *Lazy Loading images* allow your website to load important **above-the-fold** content first. Then, as you scroll down the page, the lazy-loaded images will load as needed.

You can enable **Lazy** **Loading** from the **Dashboard -> Settings -> Solid Performance -> Advanced** page.

![Lazy Load Images](https://www.liquidweb.com/wp-content/uploads/2025/04/Lazy-Load-Images.jpg)
## Disabling/Enabling Site Assist

You can **disable** **Site** **Assist** if you do not wish to use it. This can be done from the **Dashboard -> Site Assist -> Site Assist** page. In the top right corner, click on the three dots to access the option to *disable Site Assist*.

![Disable Site Assist](https://www.liquidweb.com/wp-content/uploads/2025/04/Disable-Site-Assist.gif)Once **Site** **Assist** is disabled, you can still access **Starter Templates** from the **Dashboard -> Kadence -> Starter Templates** page.

You can also disable Site Assist programmatically by using the following filter (for developers) :

```
add_filter('kadence_starter_site_assist_enabled', '__return_false');
```

On the other hand, if you want to see the Site Assist area again, you can do that from the **Dashboard -> Kadence -> Starter Templates** page.

Click on the same three-dot icon at the top right to access the option to *Enable Site Assist*.
