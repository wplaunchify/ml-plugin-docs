## Kadence Theme Kit Pro Plugin

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/theme-kit-pro-plugin/](https://www.kadencewp.com/help-center/docs/kadence-theme/theme-kit-pro-plugin/)

The Kadence Theme Kit Pro plugin enhances the functionality of the free Kadence Theme by adding premium features such as Hooked Elements, Header Add-ons, Conditional Headers, and more. Learn more about purchasing a Kadence plan [here](https://www.liquidweb.com/software/kadence/).

Before you begin

		**Kadence Theme Kit Pro** is a plugin, not a theme. This plugin requires the [free Kadence Theme](https://wordpress.org/themes/kadence/), and should be installed via your WordPress dashboard by going to **Plugins > Add New**.

## Enable Addons

Once you have Kadence Theme Kit Pro active, you can toggle on any of the add-ons you’d like to activate from the **Dashboard -> Appearance -> Kadence** page. These extensive options include:

- **Header Addons.** Adds [20 elements](https://docs.nexcess.com/software/kadence/theme/header-addons/) to the header builder.
- **Conditional Headers.** [Build Extra Headers to display conditionally](https://docs.nexcess.com/software/kadence/theme/conditional-headers/).
- **Ultimate Menu.**Adds menu options for[mega menus](https://docs.nexcess.com/software/kadence/theme/mega-multicolumn-menu/), highlight tags, icons and more.
- **Header/Footer Scripts.** Adds options into the WordPress Customizer to add [header and footer scripts](https://docs.nexcess.com/software/kadence/theme/add-scripts-in-header-footer/).
- **Hooked Elements.** Add [content anywhere](https://docs.nexcess.com/software/kadence/theme/use-element-hooks/) into your site conditionally. This is what you’ll need for [Kadence Elements Templating](https://docs.nexcess.com/software/kadence/).
- **WooCommerce Addons.** Adds new options into the customizer for WooCommerce stores.
- **Infinite Scroll.** Adds infinite scrolling for archive pages.
- **Color Palette Switch (Dark Mode).** Adds a color palette switch so you can [create a dark mode](https://docs.nexcess.com/software/kadence/theme/color-palette-switch-dark-mode/) for your website.
- **Local gravatars.** Local gravatars from your servers to improve site performance.
- **Archive custom settings.** Allows you to [assign custom display settings for taxonomies](https://docs.nexcess.com/software/kadence/theme/archive-custom-settings/).
