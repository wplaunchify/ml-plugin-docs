## Working with the Sticky Header

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/working-with-the-sticky-header/](https://www.kadencewp.com/help-center/docs/kadence-theme/working-with-the-sticky-header/)

To set up your sticky header, navigate to Customize > Header > Sticky Header.

![](https://www.liquidweb.com/wp-content/uploads/2020/11/Screen-Shot-2020-06-19-at-12.56.53-PM-422x1024-1.png)Next, select which elements you would like to be sticky from the dropdown.

![](https://www.liquidweb.com/wp-content/uploads/2020/11/Screen-Shot-2020-06-19-at-1.15.48-PM.png)You can then choose to have your sticky header shrink when scrolled, and you can also upload a different logo for the sticky header.

![](https://www.liquidweb.com/wp-content/uploads/2020/11/Screen-Shot-2020-06-19-at-1.51.25-PM-438x1024-1.png)All of these settings can be adjusted for mobile devices from Customize > Header > Sticky Header > Mobile Sticky.

Lastly, you can open the Design tab and set the color settings for your sticky header elements.
