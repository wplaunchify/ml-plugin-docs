## How to Use a Transparent Header

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/use-transparent-header/](https://www.kadencewp.com/help-center/docs/kadence-theme/use-transparent-header/)

To set up a transparent header with just a few clicks, follow the steps below.

Go to the WordPress Customizer, either at **Appearance > Customize** from the wp-admin menu or by clicking Customize in the wp-admin bar on the front end of your WordPress site.

Next, go to the Customizer *Header* section.

Scroll down and click on *Transparent Header*.

![](https://docs.nexcess.com/wp-content/uploads/2026/07/Customize-Chase-the-horizon-2025-02-06-at-8.19.59-AM.jpg-1024x488-1.jpg)

Turn on the “**Enable Transparent Header?**” setting.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Customize-Chase-the-horizon-2025-02-06-at-8.18.13-AM-1024x485-1.jpg)

This will enable the transparent header for both desktop and mobile by default.

Tip: **If the logo is not changing on your website**. This is most likely because the transparent header is enabled on the page. The transparent header allows you to set a different logo for the transparent header. You also need to change that to make sure that the correct logo is displayed on the page using the transparent header:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Customize-Teejay-2025-03-17-at-10.05.35-AM.jpg)

In the *DESIGN tab,* you can set the various colors when the header is made transparent.

![Kadence Transparent Header Design Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/kadence-transparent-header-design.png)

Click on **Publish** when you are done.

*Note: The global Transparent Header setting acts as the default for all pages and posts. However, you can override this on individual pages or posts. When set, the individual page or post setting takes precedence over the global option.*

How to enable/disable transparent header on individual pages and posts?

1. Edit the page
2. Click the **Page Settings** Icon
3. Select the **Transparent Header** settings for the page
4. Click the **save** button

![](https://www.kadencewp.com/help-center/wp-content/uploads/sites/14/2025/07/Edit-Page-Home-‹-teejay-—-WordPress-?-2025-07-21-at-3.31.40-PM-edited.jpg)

*This allows you to fine-tune the header appearance on a per-page basis, regardless of the global settings.*
