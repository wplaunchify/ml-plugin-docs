## Woo Template Block – Product: Description

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-product-description/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-product-description/)

When creating Woo Templates, you can access the Product: Description. This block displays the description of the current product.

Find the Product: Description block under the Woo Template Blocks section and add it to your template like any other block.

![Product Description](https://www.liquidweb.com/wp-content/uploads/2022/11/Product_description_block.png)
## Product: Description Block Settings

You can modify different Block Settings of your Product: Description block.

![Product Description Block Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_description_Block_settings.png)In the **General Settings** of the Product: Description, you can change the alignment of your Product: Description.![Product Description General Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_description_general_Settings.png)The **Styling Settings** allow you to adjust the color and typography settings of your Product: Description.![Product Short Description Styling Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_short_desc_settings2.png)**Spacing Settings**

You have the ability to adjust the **Spacing Settings** for your Product: Description block. These settings will allow you to adjust the margin and the padding of your block. You can adjust the padding or margin for *desktop*, *tablet*, and *mobile* devices.![Spacing Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/spacing_settings.jpg)![Advanced Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_advanced.jpg)**Advanced**
