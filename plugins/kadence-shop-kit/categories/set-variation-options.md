## How to Set Variation Options

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/set-variation-options/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/set-variation-options/)

Kadence Shop Kit allows you to set a few **Variation Options**. Products in your store can have variable products with different prices, and this feature allows you to set the price(s) that appear for your variable products. There are three options available.

- Show Price Range ($lowest – $highest)
- Show lowest price only
- Show highest price only
