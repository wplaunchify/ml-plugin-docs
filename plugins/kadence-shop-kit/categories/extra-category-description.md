## Extra Category Description

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/extra-category-description/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/extra-category-description/)

If your store has products, you most likely organize them by categories. Shop Kit’s Extra Category Description feature enables an additional description box which will be visible at the bottom of category pages. This simple feature lets you present your buyers with information on a categorical level. Impress your customers with relevant category descriptions.

![Extra Category Description](https://docs.nexcess.com/wp-content/uploads/2026/06/Extra-Category-Description.gif)Extra Category Description

How to Enable Extra Category Description

Enabling the extra category description feature is fast and easy. There is only a single option to enable in the admin panel at **Shop Kit > Extra Category Description**. After enabling the feature, you add the description to the product category edit page. Find the description box under Products > Categories and by clicking “Edit” for one of your categories. The description box will be at the bottom of the category edit page.
