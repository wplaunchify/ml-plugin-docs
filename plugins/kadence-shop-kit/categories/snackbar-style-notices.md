## Snackbar Style Notices

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/snackbar-style-notices/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/snackbar-style-notices/)

![Snackbar Add to Cart Example](https://docs.nexcess.com/wp-content/uploads/2026/06/Snackbar-Add-to-Cart-Example.gif)Snackbar Add to Cart Example

Shop Kit includes a feature for snackbar style notices. Snackbar style notices add flair to your WooCommerce notices by providing a “snackbar” notice that appears at the bottom of the screen. The notices include the same information as the standard notices provided by WooCommerce.

![Standard Notice example](https://docs.nexcess.com/wp-content/uploads/2026/06/Standard-Notice-example-1024x483-1.jpeg)Standard Notice example

How to Enable Snackbar Style Notices

To use snackbar style notices, you must enable the feature in the admin menu at **Shop Kit → Snackbar Style Notices**. After you enable the feature, you have two more options to add the notices to the cart and checkout pages.

When **AJAX Add to Cart** is enabled, standard WooCommerce notices will not be displayed. As a result, **Snackbar notices** also will not appear.
