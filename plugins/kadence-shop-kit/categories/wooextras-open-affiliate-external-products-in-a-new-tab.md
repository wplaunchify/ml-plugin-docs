## Open Affiliate/External Products In A New Tab

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/wooextras-open-affiliate-external-products-in-a-new-tab/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/wooextras-open-affiliate-external-products-in-a-new-tab/)

By default, there are no options in WooCommerce to open affiliate or external product links in another tab. This is one of the most frequently asked for features with those using WooCommerce for affiliate stores.

We built some amazing features into our [Kadence Shop Kit](https://www.liquidweb.com/help-docs/software/kadence/shop-kit/install-activate-kadence-shop-kit/) plugin that allows for the “Add to cart” or action button to open in a new tab. We also added support to make the product image in an archive open to the affiliate link. Getting it set up is simple!

## Enable Affiliate/External Product Options

First, be sure you have the latest version of Shop Kit installed on your site. Once installed, navigate to **Shop Kit → Affiliate Product Options** and enable the option:

![Enable affiliate options](https://res.cloudinary.com/lwcom/images/w_579,h_599,c_scale/f_auto,q_auto/v1780603551/prod/Affiliate-product-options-1/Affiliate-product-options-1.gif?_i=AA)Once you’ve enabled the affiliate options in the Shop Kit Settings, turn on the features you’d like to use.

Publish the product, and test that your link opens as desired.
