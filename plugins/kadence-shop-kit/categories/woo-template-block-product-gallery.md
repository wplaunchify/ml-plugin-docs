## Woo Template Block – Product: Gallery

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-product-gallery/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-product-gallery/)

When creating Woo Templates, you can access the Product: Gallery block. This block displays the gallery of the current product.

Find the Product: Gallery block under the Woo Template Blocks section and add it to your template like any other block.

![Product Gallery Block](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery.png)
## Product: Gallery Block Settings

![Product Gallery Block Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_blocksettings-1024x471.png)**Sale Tag Settings**
The Sale Tag is a tag that appears on top of your Product: Gallery block whenever a product is marked as on sale.

![Product Gallery Sale Tag Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_settings-e1668190841343.jpg)![More Product Gallery Sale Tag Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_settings2.jpg)**A preview of the Sale Tag.**

![Product Gallery Sale Tag](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_saletag.jpg)**Spacing Settings**

You can adjust the padding and margin of the Product: Gallery.

![Product Gallery Spacing Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_spacing.png)**Advanced Settings**

You can add custom CSS classes to a Product: Gallery.
