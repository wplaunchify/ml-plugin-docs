## Woo Template Block – Product: Short Description

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-product-short-description/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-product-short-description/)

When creating Woo Templates, you can access the Product: Short Description. This block displays the short description of the current product.

Find the Product: Short Description block under the Woo Template Blocks section and add it to your template like any other block.

![Product Short Description](https://www.liquidweb.com/wp-content/uploads/2022/11/product_short_description.png)
## How to edit a Short Description on a product

1. Edit the product in which you wish to add a Short Description.
2. Look for the setting named Product Short Description.
3. You can add a short description for the product in the text box.

![Add Short Description To Product](https://www.liquidweb.com/wp-content/uploads/2022/11/add_short_description.gif)
### Product: Short Description Block Settings

You can modify different Block Settings of your Product: Short Description block.

![Product Short Description Block Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_short_desc_block_settings.png)In the **General Settings** of the Product: Short Description, you can change the alignment of your Product: Short Description.![Product Short Description General Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_short_desc_settings1.png)The **Styling Settings** allow you to adjust the color and typography settings of your Product: Short Description.![Product Short Description Styling Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_short_desc_settings2.png)**Spacing Settings**

You have the ability to adjust the **Spacing Settings** for your Product: Short Description block. These settings will allow you to adjust the margin and the padding of your block. You can adjust the padding or margin for *desktop*, *tablet*, and *mobile* devices.![Spacing Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/spacing_settings.jpg)![Advanced Settings](https://www.liquidweb.com/wp-content/uploads/2022/11/product_gallery_advanced.jpg)**Advanced**
