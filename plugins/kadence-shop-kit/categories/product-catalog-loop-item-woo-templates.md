## Product Catalog Loop Item Templates (Woo Templates)

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/product-catalog-loop-item-woo-templates/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/product-catalog-loop-item-woo-templates/)

The [Kadence Shop Kit](https://www.liquidweb.com/help-docs/software/kadence/shop-kit/install-activate-kadence-shop-kit/) plugin features the **Product** **Catalog Loop Item Woo Template**, allowing you to take complete control over *WooCommerce product loop items*. Choose from multiple customizable [Woo Template Blocks](https://www.liquidweb.com/knowledge-base/kadence-shop-kit/woo-template-blocks/) to display common WooCommerce elements, such as the add-to-cart button and product price. 

This document will go over the process of building and using a Product Loop Woo Template. **Click here** to learn about the four *Woo Template types*.

## Creating a Product Catalog Loop Item Template

In order to create a **Product** **Catalog** **Loop** **Item** **Template**, you must install, activate, and license the Kadence Shop Kit plugin ([learn more about Shop Kit](https://www.liquidweb.com/help-docs/software/kadence/shop-kit/)). Once the Shop Kit plugin is activated on the website, navigate to the **Dashboard -> Shop Kit** page and go to the **Product** **Templates** tab.

![Shop Kit - Enable Product Templates](https://res.cloudinary.com/lwcom/images/w_1024,h_600,c_scale/f_auto,q_auto/v1779999803/prod/Screenshot-2026-05-28-at-3.22.57-PM/Screenshot-2026-05-28-at-3.22.57-PM.png?_i=AA)*Enable Product Templates* and save the changes. Afterward, refresh the page. Then, navigate to the **Dashboard -> Products -> Woo Templates** page. At the top of the *Woo Templates page*, click on the **Add New Woo Templates** button.

![Shop Kit - Add New Woo Template](https://res.cloudinary.com/lwcom/images/w_980,h_672,c_scale/f_auto,q_auto/v1779999932/prod/Screenshot-2026-05-28-at-3.25.11-PM/Screenshot-2026-05-28-at-3.25.11-PM.png?_i=AA)This will open a **new** **Woo** **Template** **Post** with the option to select the template type. Select the **Product Catalog Loop Item** option.

Once you have selected the template type, you will have the option to select a **prebuilt template** or start from a **blank** state.

![Woo Template - Prebuilt Template Select](https://res.cloudinary.com/lwcom/images/w_1024,h_298,c_scale/f_auto,q_auto/v1780000033/prod/Screenshot-2026-05-28-at-3.26.37-PM/Screenshot-2026-05-28-at-3.26.37-PM.png?_i=AA)There are various *Woo Template Blocks* that can be used within the *Product Catalog Loop Item*, such as the Product Price and Product Add To Cart blocks. *(Click here for a full list of Woo Template Blocks.)*

Use the **Block** **Settings** of each **Woo Template Block** to control the initial design and style of the current block.

## Woo Template Settings

Use the **Woo** **Template** **Settings** to control where the current Woo Template will override and who will see it. Click on the **pencil/paper icon** in the top right of the editor.

**Template Type:** Define the template type. This document overviews the Product Catalog Loop Item. However, there are other Woo Template types available as well.![Woo Template - Template Settings](https://res.cloudinary.com/lwcom/images/w_556,h_488,c_scale/f_auto,q_auto/v1780000307/prod/Screenshot-2026-05-28-at-3.31.27-PM/Screenshot-2026-05-28-at-3.31.27-PM.png?_i=AA)**Display Settings:**Use the Display Settings to determine where the Product Catalog Loop Item will take effect. Use the Add Rule button to include additional options.

- **Show On (Page Wide):** Use this setting to determine specific page(s) where the loop should display.- *Available options include: All Product Loops, Brand Archives, Category Archives, Tag Archives, Product Archives, and Product Search.*
- **Show On (Inner Loop Specific):** Use this setting to only target specific inner loop items, such as a specific category.- *Available options include: All Product Loops or Has Category Term.*![Woo Template - Display Settings](https://res.cloudinary.com/lwcom/images/w_558,h_862,c_scale/f_auto,q_auto/v1780000565/prod/Screenshot-2026-05-28-at-3.32.16-PM/Screenshot-2026-05-28-at-3.32.16-PM.png?_i=AA)**User Settings:** Determine which user roles will be able to see the Woo Template in effect.

- Options include: All Users (Default), Logged Out Users, Logged In Users, or based on the Website Available Roles. Use the *Add Rule button* to add more visibility options.![Woo Template - User Settings](https://res.cloudinary.com/lwcom/images/w_556,h_456,c_scale/f_auto,q_auto/v1780000661/prod/Screenshot-2026-05-28-at-3.37.07-PM/Screenshot-2026-05-28-at-3.37.07-PM.png?_i=AA)**Expires Settings:** Enable this option to add an expiration to the Woo Template. Once the expiration is met, the Woo Template will no longer take effect.![Woo Template - Expire Settings](https://res.cloudinary.com/lwcom/images/w_514,h_1024,c_scale/f_auto,q_auto/v1780000742/prod/Screenshot-2026-05-28-at-3.38.37-PM/Screenshot-2026-05-28-at-3.38.37-PM.png?_i=AA)Was this article helpful?Yes NoThank you for your input.Thank you for your feedback.
