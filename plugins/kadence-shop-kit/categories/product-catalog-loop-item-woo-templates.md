## Product Catalog Loop Item Templates (Woo Templates)

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/product-catalog-loop-item-woo-templates/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/product-catalog-loop-item-woo-templates/)

The [Kadence Shop Kit](https://www.kadencewp.com/kadence-shopkit/pricing/) plugin features the **Product** **Catalog Loop Item Woo Template**, allowing you to take complete control over *WooCommerce product loop items*. Choose from multiple customizable [Woo Template Blocks](https://docs.nexcess.com/software/kadence/) to display common WooCommerce elements, such as the add-to-cart button and product price. 

This document will go over the process of building and using a Product Loop Woo Template. **Click here** to learn about the four *Woo Template types*.

Creating a Product Catalog Loop Item Template

In order to create a **Product** **Catalog** **Loop** **Item** **Template**, you must install, activate, and license the Kadence Shop Kit plugin. ([Click here to learn more](https://docs.nexcess.com/software/kadence/install-activate-kadence-shop-kit/).) Once the Shop Kit plugin is activated on the website, navigate to the **Dashboard -> Shop Kit** page and go to the **Product** **Templates** tab.

![Enable Product Templates](https://docs.nexcess.com/wp-content/uploads/2026/06/Enable-Product-Templates.jpg)

*Enable Product Templates* and save the changes. Afterward, refresh the page. Then, navigate to the **Dashboard -> Products -> Woo Templates** page. At the top of the *Woo Templates page*, click on the **Add New Woo Templates** button.

![Add New Woo Template](https://docs.nexcess.com/wp-content/uploads/2026/06/Add-New-Woo-Template-1024x850-1.jpg)

This will open a **new** **Woo** **Template** **Post** with the option to select the template type. Select the **Product Catalog Loop Item** option.

![Add Product Catalog Template](https://docs.nexcess.com/wp-content/uploads/2026/06/Add-Product-Catalog-Template-scaled-1.jpg)

Once you have selected the template type, you will have the option to select a **prebuilt template** or start from a **blank** state.

![Template Type](https://docs.nexcess.com/wp-content/uploads/2026/06/Template-Type-scaled-1.jpg)

There are various *Woo Template Blocks* that can be used within the *Product Catalog Loop Item*, such as the Product Price and Product Add To Cart blocks. *(Click here for a full list of Woo Template Blocks.)*

Use the **Block** **Settings** of each **Woo Template Block** to control the initial design and style of the current block.

![Woo Template Block Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Woo-Template-Block-Settings.gif)

Woo Template Settings

Use the **Woo** **Template** **Settings** to control where the current Woo Template will override and who will see it. Click on the **pencil/paper icon** in the top right of the editor.

![Template Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Template-Settings.jpg)

**Template Type:** Define the template type. This document overviews the Product Catalog Loop Item. However, there are other Woo Template types available as well.

**Display Settings:**Use the Display Settings to determine where the Product Catalog Loop Item will take effect. Use the Add Rule button to include additional options.

- **Show On (Page Wide):** Use this setting to determine specific page(s) where the loop should display.
- *Available options include: All Product Loops, Brand Archives, Category Archives, Tag Archives, Product Archives, and Product Search.*
- **Show On (Inner Loop Specific):** Use this setting to only target specific inner loop items, such as a specific category. 
- *Available options include: All Product Loops or Has Category Term.*

**Visibility Settings:** Determine which user roles will be able to see the Woo Template in effect.

- Options include: All Users (Default), Logged Out Users, Logged In Users, or based on the Website Available Roles. Use the *Add Rule button* to add more visibility options.

**Expires Settings:** Enable this option to add an expiration to the Woo Template. Once the expiration is met, the Woo Template will no longer take effect.
