## Woo Template Block – Archive: Main Query

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-archive-main-query/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-archive-main-query/)

The Archive: Main Query block allows you to display the main query of products on your shop archive pages.

![Archive Main Query](https://www.liquidweb.com/wp-content/uploads/2023/02/archivemainquery.png)You can use the Archive: Main Query block on your Product Archive Woo Templates.![Product Archive Template](https://www.liquidweb.com/wp-content/uploads/2023/02/Product-Archive-Template.png)You can add a new Archive: Main Query block to your Woo Template by finding it under the Woo Templates section.

![Add Archive Main Query](https://www.liquidweb.com/wp-content/uploads/2023/02/productmainquery.gif)
## Archive: Main Query Block Settings

You can customize your Archive: Main Query by accessing the Block Settings.

![Main Query Block Settings](https://www.liquidweb.com/wp-content/uploads/2023/02/Main-Query-Block-Settings.png)**General Settings**
The General Settings allow you to adjust the Columns of Products shown for different devices. You can set your Archive: Main Query to display 1-6 columns for mobile, tablet, and desktop devices.![Main Query General Settings](https://www.liquidweb.com/wp-content/uploads/2023/02/Main-Query-General.png)**Spacing Settings**
The Spacing Settings allow you to adjust the Spacing of your Archive: Main Query. You can adjust the padding and margin for mobile, tablet, and desktop devices.![Main Query Spacing Settings](https://www.liquidweb.com/wp-content/uploads/2023/02/Main-Query-Spacing-Settings.png)**Advanced Settings**The Advanced Settings allow you to add Additional CSS Class(es) to your Archive: Main Query block.![Main Query Advanced Settings](https://res.cloudinary.com/lwcom/images/w_544,h_286,c_scale/f_auto,q_auto/v1780588579/prod/Main-Query-Advanced-Settings/Main-Query-Advanced-Settings.png?_i=AA)Was this article helpful?Yes NoThank you for your input.Thank you for your feedback.
