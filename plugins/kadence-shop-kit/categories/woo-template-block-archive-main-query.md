## Woo Template Block – Archive: Main Query

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-archive-main-query/](https://www.kadencewp.com/help-center/docs/kadence-shop-kit/woo-template-block-archive-main-query/)

The Archive: Main Query block allows you to display the main query of products on your shop archive pages.

![](https://docs.nexcess.com/wp-content/uploads/2023/02/archivemainquery-scaled-1.webp)

You can use the Archive: Main Query block on your Product Archive Woo Templates.

![Product Archive Template](https://docs.nexcess.com/wp-content/uploads/2026/06/Product-Archive-Template.png)

You can add a new Archive: Main Query block to your Woo Template by finding it under the Woo Templates section.

![Add Archive Main Query](https://docs.nexcess.com/wp-content/uploads/2026/06/productmainquery.gif)

Archive: Main Query Block Settings

You can customize your Archive: Main Query by accessing the Block Settings.

![](https://docs.nexcess.com/wp-content/uploads/2023/02/Main-Query-Block-Settings-scaled-1.webp)

**General Settings**
The General Settings allow you to adjust the Columns of Products shown for different devices. You can set your Archive: Main Query to display 1-6 columns for mobile, tablet, and desktop devices.

![Main Query General Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Main-Query-General.png)

**Spacing Settings**
The Spacing Settings allow you to adjust the Spacing of your Archive: Main Query. You can adjust the padding and margin for mobile, tablet, and desktop devices.

![Main Query Spacing Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Main-Query-Spacing-Settings.png)

**Advanced Settings**The Advanced Settings allow you to add Additional CSS Class(es) to your Archive: Main Query block.

![Main Query Advanced Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Main-Query-Advanced-Settings.png)
