# Smart Coupons

			[Smart Coupons](https://woocommerce.com/products/smart-coupons/) provides a powerful, all-in-one solution for gift certificates, store credits, discount coupons, and vouchers.

The extension allows customers to buy credits for themselves or gift them to others. It automatically issues coupons on product purchase, provides “Apply Coupon with One Click” technology and more.

## Installation

[↑ Back to top](#doc-title)

- Download Smart Coupons plugin .zip file from your [WooCommerce account](https://woocommerce.com/my-account/downloads).
- Go to WordPress Admin > Plugins > Add New and upload the file you downloaded.
- Activate the plugin.

More information at: [Installing and managing plugins](https://wordpress.org/documentation/article/manage-plugins/#upload-via-wordpress-admin).
