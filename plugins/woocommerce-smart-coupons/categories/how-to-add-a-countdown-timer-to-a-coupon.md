# How to add a Countdown Timer to a Coupon

			Smart Coupons provide a powerful, “all-in-one” solution for gift cards, store credits, discount coupons, and vouchers extending the core functionality of WooCommerce coupons.

This doc explains how you can set a countdown timer for coupons using the Smart Coupons plugin.

## Steps to create a countdown timer

[↑ Back to top](#doc-title)

1. Go to **Marketing > Coupons**.
2. Create a new coupon code or edit an existing code.
3. Choose an **Expiry date** for the coupon code.![WooCommerce Expiry date field](https://woocommerce.com/wp-content/uploads/2026/01/Countdown-timer.png?strip=all&w=704)
4. **Update** or **Publish** the coupon code.![WooCommerce countdown timer Smart Coupons](https://woocommerce.com/wp-content/uploads/2026/01/countdown-timer-kettle.png?strip=all&w=704)
5. Navigate to the product page or any custom page on your website and include the shortcode in your editor “
```
[smart_coupon_countdown coupon_id=519]
```

”.

Here, 
```
coupon_id
```

 refers to the ID of the coupon.

![](https://woocommerce.com/wp-content/uploads/2026/01/coupon-id.png?strip=all&w=704)

**Note:**
(The Shortcode to display timer can also be placed on the header or widget area so that your customers can easily notice.)
