# How to migrate coupons from one store to another

			Smart Coupons provide a powerful, “all-in-one” solution for gift cards, store credits, discount coupons, and vouchers, extending the core functionality of WooCommerce coupons.

This document provides a step-by-step guide on how to migrate coupons from one WooCommerce store to another.

## Steps to export coupons

[↑ Back to top](#doc-title)

1. **Navigate to your** WordPress Admin Panel.
2. Go to **Marketing > Coupons** and click **the Export**button. 
![](https://woocommerce.com/wp-content/uploads/2025/02/smart-coupons-export-button.png?strip=all&w=704)
3. Optional: If you want to export any specific coupons, use the checkboxes to select those coupons & then click the **Export** button
4. Once the export process is completed, a CSV file with all coupon information will be downloaded to your system. ![](https://woocommerce.com/wp-content/uploads/2025/02/smart-coupons-exported-csv.png?strip=all&w=704)

## Steps to import coupons into another store

[↑ Back to top](#doc-title)

1. In the new store, go to **Marketing > Coupons** in the WordPress admin panel.
2. Click the **Import Coupons** tab at the top of the page. You can refer to the documentation [here](https://woocommerce.com/document/smart-coupons/how-to-import-coupons-in-bulk-using-a-csv-file/)for the coupon import process.
3. When you import coupons, you will see the importing message in your coupons dashboard. ![](https://woocommerce.com/wp-content/uploads/2025/02/smart-coupons-import-in-process.png?strip=all&w=704)
4. Once the import is finished, check if all coupons have been successfully added. ![](https://woocommerce.com/wp-content/uploads/2025/02/smart-coupons-import-success.png?strip=all&w=704)

That’s it.

By following these steps, you can migrate all of your coupons from one WooCommerce store to another.
