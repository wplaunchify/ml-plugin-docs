# How to change coupon page URL/endpoint in My Account

			Smart Coupons provide a powerful, “all-in-one” solution for gift cards, store credits, discount coupons, and vouchers extending the core functionality of WooCommerce coupons.

This doc article explains how using Smart Coupons you can change the URL of the page on which all the available coupons are shown.

## Changing coupon page URL in My Account

[↑ Back to top](#doc-title)

By default, the Smart Coupons plugin sets the coupon page URL as 
```
wc-smart-coupons
```

. But you can change this value as per your need.

![](https://woocommerce.com/wp-content/uploads/2022/04/smart-coupons-custom-coupon-page-endpoint-setting.png?strip=all&w=704)

1. Go to your WordPress Admin panel. Click on **WooCommerce > Settings**.
2. Click on the **Advanced** tab.
3. Find Coupons under **Account endpoints**
4. Set the value as per your need. For example: 
```
smart-coupons
```
5. Click on the **Save changes** button.

That’s it.

Here’s how the URL will look on the My Account page:

![](https://woocommerce.com/wp-content/uploads/2022/10/woocommerce-smart-coupons-custom-endpoint-frontend.png?strip=all&w=704)
