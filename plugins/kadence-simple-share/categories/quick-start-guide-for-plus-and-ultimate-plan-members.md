## Getting Started with Kadence Ultimate & Lifetime Plans

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-general/quick-start-guide-for-plus-and-ultimate-plan-members/](https://www.kadencewp.com/help-center/docs/kadence-general/quick-start-guide-for-plus-and-ultimate-plan-members/)

The **Kadence** **Ultimate and Lifetime** **Plans** are designed for site creators who want to build with the **most** **powerful** **tool** **set**. This plan includes all Premium Kadence products, giving you access to all of the available possibilities.

Some key plugins and features that are included in the Ultimate/Lifetime Plans include:

- **Kadence Blocks Pro:** Expands on the free Kadence Blocks plugin with premium blocks, dynamic content, custom icons, and access to the full Kadence Design Library.
- **Kadence Theme Pro:** Expands on the Kadence Theme with advanced features like Hooked Elements, Ultimate Mega Menus, Conditional Headers, and more header options.
- **Kadence Shop Kit:**Gives you full control over WooCommerce pages and layouts using Woo Templates, along with added features like Product Quickview, Badges, Global Tabs, and a customizable Checkout Editor.
- Kadence Conversions: Create converting pop-ups, slide-ins, and banners right inside the block editor to engage users and grow your audience.
- **Kadence Insights:** Run A/B tests and track performance metrics to make data-driven design and content decisions.
- **Kadence Pattern Hub:** Build and share your own design library collections across multiple websites. Ideal for agencies, affiliates, and creators who want consistent, reusable design assets.

The **Ultimate and Lifetime** **Plans** are premium plans offered by Kadence. [Learn more ⧉](https://kadencewp.com/pricing).

Before You Begin

The Plus Plan builds directly on the free Kadence products. Before installing the premium features, you should have the **free Kadence Theme**, the **free Kadence Blocks plugin**, and the **free Kadence Starter Templates plugin** already installed and activated.

A helpful guide is available for users who have not yet installed the free products: [Getting Started with Free Kadence Products ⧉](https://docs.nexcess.com/software/kadence/free-kadence-products/).

Core Kadence Plugins

The Kadence Blocks Pro Plugin extends**the free Kadence Blocks Plugin,** and the Kadence Theme Kit Pro Plugin extends the **free Kadence Theme**. The combination of these two plugins on your website will also unlock Premium Design Library Items along with Premium Starter Templates. These are the core Premium Kadence Plugins when using the Ultimate/Lifetime Plans. Kadence offers more premium products. However, they further extend this initial base of plugins.

Installing Kadence Blocks Pro

1. Log in to the Kadence account and go to the **Downloads** section.
![Downloads and licenses](https://docs.nexcess.com/wp-content/uploads/2026/06/Downloads-and-licenses-1024x601-1.jpg)
2. Download the **Kadence Blocks Pro** zip file to a computer.
![Download Kadence blocks pro](https://docs.nexcess.com/wp-content/uploads/2026/06/Download-Kadence-blocks-Pro-1.jpg)
3. In the WordPress Dashboard, navigate to **Plugins → Add New Plugin**.
4. Click the **Upload Plugin** button and choose the zip file.
![Upload Kadence Blocks Pro](https://docs.nexcess.com/wp-content/uploads/2026/06/Upload-Kadence-Blocks-Pro-scaled-1.jpg)
5. After the installation is complete, click **Activate Plugin**.
![Activate Kadence Blocks Pro](https://docs.nexcess.com/wp-content/uploads/2026/06/Activate-Blocks-Pro-1024x491-1.jpg)

You now have full access to Kadence Blocks Pro features.

Blocks Pro Features

The **Kadence Blocks Pro** plugin expands the Kadence Blocks toolkit with advanced features and powerful blocks for creating complex and dynamic content. Some popular Blocks Pro features are listed below. However, there are many more features, and this is a brief overview.

- [Dynamic Content ⧉](https://docs.nexcess.com/software/kadence/dynamic-content/)**:** With Kadence Blocks Pro, **Dynamic Content** lets you insert content that’s not statically typed but pulled dynamically from your site’s database or custom fields.

- You can pull values like post title, URL, excerpt, featured image, metadata, or custom fields.
- It’s available in many Kadence Blocks (Advanced Text, Advanced Image, Video Popup, Section, Icon, etc.), so your design can adapt based on context.
- [Modal Block ⧉](https://docs.nexcess.com/software/kadence/modal-block/)**:** The **Modal** block lets you create overlay windows (popups) without leaving the current page.

- Populate a Modal container that can be opened on click.
- You can also control the trigger, overlay style, close button, and visual styling.
- [Post Grid/Carousel Block ⧉](https://docs.nexcess.com/software/kadence/post-grid-carousel-block/)**:** This block is for listing posts, pages, or custom content in grid, masonry, or carousel layouts. 

- You choose which post types to display and can filter the post query by taxonomies.
- Multiple layout options, including a carousel with auto-play options.
- [Query Loop (Adv) Block ⧉](https://docs.nexcess.com/software/kadence/blocks/advanced-query-loop-block/)**:** The **Query Loop (Adv)** block gives you full control over how content is queried and displayed.

- Use dynamic Advanced Query Loops and [Query Cards ⧉](https://docs.nexcess.com/software/kadence/blocks/advanced-query-loop-block/#query-card-block) to display post loop content.
- You can include filter controls (dropdowns, checkboxes, text search, and more) that let users refine the displayed results based on taxonomy, metadata, date, and more.

To view all of the Premium Blocks in detail, [view the Kadence Blocks Pro documentation list ⧉](https://docs.nexcess.com/software/kadence/).

Kadence Blocks Pro adds premium blocks to WordPress and adds extensive features to the Free Kadence Blocks plugin. To see all the possibilities with **Kadence Blocks Free + Pro**, check out the **Kadence Blocks Knowledge Base**.

[Kadence Blocks Knowledge Base ⧉](https://www.kadencewp.com/help-center/knowledge-base/kadence-blocks/)

Theme Kit Pro Features

The **Kadence Theme Pro** plugin takes the foundational Kadence Theme and adds professional-grade customization features to the WordPress Customizer.

- [Header Addons ⧉](https://docs.nexcess.com/software/kadence/theme/header-addons/)**:** Adds over 20 extra header elements beyond what the free theme provides. Such as a second button, contact details, search bar, toggle panels, widget areas, and more

- This pairs well with Dynamic Content from Kadence Blocks Pro.
- [Mega Menus ⧉](https://docs.nexcess.com/software/kadence/theme/mega-multicolumn-menu/)**:** Extends the primary navigation with advanced features for creating multi-column mega menus.
- [Header/Footer Scripts ⧉](https://docs.nexcess.com/software/kadence/theme/add-scripts-in-header-footer/)**:** Makes it easy to insert custom scripts (for analytics, tracking, pixels, etc.) directly into your header or footer via the Customizer, without needing to edit theme files.

Kadence Custom Fonts

The Kadence Theme and plugins offer native built-in support for Google Fonts. However, you may have a non-Google font that you wish to use. In this case, Kadence Custom Fonts is a plugin you want to use. The **Kadence Custom Fonts** plugin allows users to upload and use any font file on a website, providing complete control over typography. This works for manually uploading a file or connecting to Adobe for Adobe TypeKit Fonts.

1. From a Kadence account, download the **Kadence Custom Fonts** plugin from your Kadence dashboard.![Custom Fonts](https://docs.nexcess.com/wp-content/uploads/2026/06/Custom-Fonts.jpg)
2. Install it on the site using the standard upload method (**Plugins → Add New Plugin → Upload Plugin**). Once finished, activate the plugin.
3. Navigate to the **Dashboard → Appearance → Kadence → Custom Fonts** page to upload font files. Click on the **Add** **New** button to add a new font. This will bring you to the font importer, where you can fill out font-related details and upload font files.
![](https://docs.nexcess.com/wp-content/uploads/2026/06/SelectFont.jpg)

- From the Font Type dropdown, you can also use Adobe Type Kit Fonts, if preferred. [Learn more ⧉](https://docs.nexcess.com/software/kadence/theme/custom-fonts/#adobe-typekit-fonts).
![Adobe Type Kit Font](https://docs.nexcess.com/wp-content/uploads/2026/06/Adobe-Type-Kit-Font-1024x329-1.jpg)
4. Once a font is uploaded, it becomes available in the WordPress Customizer (**Appearance →** **Customize → Colors & Fonts → Typography**) and in the block editor’s typography font controls. These fonts also apply to the Kadence Blocks plugin and other areas where you can select fonts with Kadence.

For a complete overview of the Kadence Custom Fonts plugin, [view the Kadence Custom Fonts document ⧉.](https://docs.nexcess.com/software/kadence/theme/custom-fonts/)

Kadence CAPTCHA

The **Kadence CAPTCHA plugin** helps protect your website forms from spam and automated bot submissions. It integrates seamlessly with **WordPress** and **WooCommerce** forms, adding a simple verification step for users. This ensures that critical forms, like login, checkout, and other non-block-based forms, stay secure from bad actors.

![Dark Captcha Sample](https://docs.nexcess.com/wp-content/uploads/2026/06/Dark-Captcha.jpg)

Both the **Kadence Form Block** ([Learn more ⧉](https://docs.nexcess.com/software/kadence/form-block/#spam-prevention)) and the **Advanced Form Block** ([Learn more ⧉](https://docs.nexcess.com/software/kadence/advanced-form-block/#misc-fields)) also include built-in CAPTCHA options. However, these are configured differently from the CAPTCHA plugin. The **Kadence CAPTCHA** plugin specifically secures forms that are not created with Kadence Blocks.

1. From a Kadence account, download the **Kadence CAPTCHA** plugin. Install and activate it on the WordPress site.
![Download Kadence CAPTCHA](https://www.kadencewp.com/help-center/wp-content/uploads/sites/14/2024/03/My-Account-Kadence-WP-?-2024-03-25-at-8.29.54-PM.jpg)
2. After installation, go to the WordPress Dashboard and navigate to the **Settings → CAPTCHA** page to access the CAPTCHA settings.
![](https://docs.nexcess.com/wp-content/uploads/2026/06/Google-v3.jpg)

- Google reCAPTCHA – Kadence CAPTCHA supports Google reCAPTCHA v2 and v3. [Learn more about setting up Google reCAPTCHA with Kadence ⧉](https://docs.nexcess.com/software/kadence/blocks/captcha/#setting-up-google-recaptcha).
- Cloudflare Turnstile – Kadence CAPTCHA also supports Cloudflare Turnstile. [Learn more about setting up Cloudflare Turnstile with Kadence ⧉](https://docs.nexcess.com/software/kadence/blocks/captcha/#setting-up-cloudflare-turnstile).
3. From here, you can enable CAPTCHA for forms and connect to your preferred source API.

![Light Captcha Sample](https://docs.nexcess.com/wp-content/uploads/2026/06/Light-Captcha.jpg)

For more details on the **Kadence CAPTCHA** **plugin**, view the [official Kadence CAPTCHA document ⧉](https://docs.nexcess.com/software/kadence/blocks/captcha/).
