## How do software updates work?

**Source:** [https://deliciousbrains.com/faq/ome-software-updates/](https://deliciousbrains.com/faq/ome-software-updates/)

## Why a count of offloaded media?

**Source:** [https://deliciousbrains.com/faq/media-library-size/](https://deliciousbrains.com/faq/media-library-size/)

Strange, right? Most WordPress plugins are limited to a certain number of sites, so why is this one using the number of offloaded media items? It turns out to be more fair…

Let’s say you have 3 small WordPress sites. The Bronze license would probably serve you well. While a big site like TechCrunch would need a much bigger license. That’s fair.

Now lets imagine licenses were limited by number of sites instead (like most other WordPress plugins): Bronze 1 site, Silver 2 sites, Gold 5 sites, etc. TechCrunch would only need a Bronze license while you would need Gold. Boo-urns.

## What happens if I’ve already offloaded media using the Lite version?

**Source:** [https://deliciousbrains.com/faq/what-happens-if-ive-already-offloaded-media-using-the-lite-version/](https://deliciousbrains.com/faq/what-happens-if-ive-already-offloaded-media-using-the-lite-version/)

Your plan includes a quota for the total number of offloaded media items, regardless of whether they were offloaded using the free or premium version.

For example, if you upgrade to a 20,000 item plan but have already offloaded 18,000 items with the free version, you’ll have 2,000 remaining in your plan.

## Do development and staging sites count toward my limit?

**Source:** [https://deliciousbrains.com/faq/development-staging-sites/](https://deliciousbrains.com/faq/development-staging-sites/)

Development and staging sites are ignored and do not count towards the offloaded Media Library limit. For example, offloading media on awesomesite.com will count towards the limit, but using it on dev.awesomesite.com, awesomesite.dev, staging.awesomesite.com, etc., will not count toward your limit.

## How do I free up some of my offloaded Media Library limit?

**Source:** [https://deliciousbrains.com/faq/free-up-limit/](https://deliciousbrains.com/faq/free-up-limit/)

You can get a list of your currently active sites and  deactivate them anytime from [My Account](https://deliciousbrains.com/my-account/). This will stop that  site’s offloaded Media Library size from counting toward your license  limit. You could also use WP Offload Media’s tools to remove some offloaded Media Library items from the bucket so they no longer count, or if not used anyway, simply remove the Media Library item entirely.

## How is my license usage calculated exactly?

**Source:** [https://deliciousbrains.com/faq/usage-calculation/](https://deliciousbrains.com/faq/usage-calculation/)

We simply count the number of media items that you have uploaded  to Amazon S3, DigitalOcean Spaces, or Google Cloud Storage and send that number to our server. The plugin does this for  each site you have the license installed on. We can then add up the numbers  to see if you’re approaching your license limit and notify you about it.

## What counts as an “active site”?

**Source:** [https://deliciousbrains.com/faq/site-limit/](https://deliciousbrains.com/faq/site-limit/)

When you use WP Migrate on a production site, it is counted as an active site. After 30 days of not using WP Migrate on that site, it will no longer count as an active site. Multisite production sites count as one activation. Development and staging sites are ignored and do not count toward the site limit. For example, using your license on awesomesite.com will count as one active site, but using it on dev.awesomesite.com, awesomesite.dev, staging.awesomesite.com, etc will not count toward your limit.

## Can I deactivate sites?

**Source:** [https://deliciousbrains.com/faq/free-up-sites/](https://deliciousbrains.com/faq/free-up-sites/)

Customers told us that logging into [My  Account](https://deliciousbrains.com/my-account/) to deactivate a bunch of sites every couple of months was a pain. We’ve implemented the [active sites](#site-limit) system to eliminate this. By only counting sites you’ve used in the last 30 days, there’s no need to deactivate sites regularly. In the unlikely event that we incorrectly flag one of your dev/staging sites as a production site that counts toward your limit, simply let us know and we’ll correct that for you.
