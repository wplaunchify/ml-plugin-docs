## Free version

**Source:** [https://doc.wpclever.net/woosb/basic-installations/free-version/](https://doc.wpclever.net/woosb/basic-installations/free-version/)

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-banner-1.png)

You can find the free version and install it directly from the WordPress plugin repository:

- Navigate to **Plugins >> Add New.**
- Type “WPC Product Bundles for WooCommerce” in the search box.
- Click **Install Now >> Activate**.

![WPC Product Bundles for WooCommerce](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-installation-free.png)

Find the free version of WPC Product Bundles from the WordPress repository.

Or you can download it from this link: [https://wordpress.org/plugins/woo-product-bundle/](https://wordpress.org/plugins/woo-product-bundle/) .

![WPC Product Bundles for WooCommerce](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-installation-download-free.png)Download the free installation file from the plugin page.

## Premium version

**Source:** [https://doc.wpclever.net/woosb/basic-installations/premium-version/](https://doc.wpclever.net/woosb/basic-installations/premium-version/)

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb_772x250_2021.png)

After successfully purchased the Premium license, users will receive a confirmation email sent to their inbox with the installation *.zip* file attachment.

- Download the Premium *.zip* format file.
- Deactivate the free version, then delete it from your site.
- Click **Upload New >> Choose file**.
- Locate the Premium file then press **Install Now >> Activate**.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-basic-installation.png)

Now you can access the plugin settings from the admin dashboard under the **WPClever** section.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpclever.png)

### VERIFY LICENSE KEYS

In order to verify your identity as a Premium user of our plugin, whom has purchased a license from our website at wpclever.net, please go to **WPClever >> License Keys** to enter your key there.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/license-keys.png)

Verified users will enjoy:

- Premium support from our professional Support Team at [wpc.ticksy.com](http://wpc.ticksy.com) for FREE.
- Unlimited Premium plugin update with notification in the Plugins section. Users who have got their Premium plugins from other sources, **not** our official website, won’t be able to update to higher versions.
- Direct access to Downloads to get the .zip file of the latest version on **Membership** page. (You must use your *License Email* to register for an account on our website first if you haven’t done so before).
