## Bundled products on the bundle page

**Source:** [https://doc.wpclever.net/woosb/plugin-settings/bundled-products-on-the-bundle-page/](https://doc.wpclever.net/woosb/plugin-settings/bundled-products-on-the-bundle-page/)

## Bundled products on the bundle page

#### 1/ Position:

Choose a position to display the list of bundled products in bundle page:

- Above Add to Cart button
- Under Add to Cart button
- Under the title
- Under the price
- Under the excerpt
- In a new tab
- No (hide it)

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-plugin-settings-position.png)

This is the default position where the list of bundled products appears on the bundle page.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-smart-bundle-list.png)

If you want to adjust the position of bundle name on bundled products’ individual pages, choose an option in the “Bundles” section.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-above-under-text-settings.png)

Where the list of all bundles that an individual product is included in appears:

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-above-under-text.png)

#### 2/Layouts:

In the plugin setting, the default layout is List. Users can choose another layout there for all bundles storewide:

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-layouts.png)

To change the layout of specific bundles, you can choose a layout in the *Bundled products* tab of the bundle page:

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-layout.png)

#### 3/ Variations Selector Interfaces:

WPC Product Bundles provides two kinds of selector interfaces:

- Default interface
- Use WPC Variations Radio Buttons

*3.1/ Default interface:*

The default interface displays a drop-down for **attributes** of each variable product in a bundle (for example, product A has two attributes, there are 2 drop-down lists, one for Size, one for Color, see image below).

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-default-smart-bundle.png)

*3.2/ Use WPC Variations Radio Buttons:*

If you choose to display the radio buttons in the front-end, please install the WPC Variations Radio Buttons plugin first. Then, set things up in Radio Button plugin settings. WPC Variations Radio Buttons can also bring about **ddSlick, Select2,** and **HTML tags** interfaces to your bundle.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpsctore-ddslick.png)

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-radio-buttons.png)The chosen interface in the Radio Buttons tab of each variable product will be displayed in the smart bundle when that product is added as a bundled item. Different variable products with different chosen interfaces will be displayed differently in a bundle.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-radio-buttons.png)Radio Buttons interface on Smart Bundles

**Source:** [https://doc.wpclever.net/woosb/plugin-settings/bundles-details/](https://doc.wpclever.net/woosb/plugin-settings/bundles-details/)

## Bundle settings

You can choose *Yes/No* respectively for each of the following options to display/hide the details of bundled products in bundle page:

- Thumbnail image
- Quantity
- Short description
- Price/ subtotal
- Plus/minus buttons for quantity input

![Configure the bundle details.](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-plugin-settings-bundle-details.png)Configure the bundle details.

In the “Show price” option, you can choose 1 of the following options:

- *Price:*show unit price per bundled product.
- **Subtotal:** show unit price x quantity per bundled product. If the Custom quantity option is enabled, the subtotal will be updated upon changing the quantity.
- *No:* hide the price of bundled products. Only the quantity is shown.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-default-interface.png)Show price: Price

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-spcstore-subtotal.png)Show price: Subtotal

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-subtotal-plus-minus.gif)Show price: Subtotal with Plus/Minus buttons enabled

#### Change Image

When the Change image option is enabled, the main product image will be replaced with the most recently chosen variation of the variable sub-product inside the smart bundle. This feature only works for variable sub-products, not for simple products or variations as bundled items.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-change-image-setting.png)

See how it works in the frontend:

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-change-image-scaled.gif)

## Coupon Restriction

**Source:** [https://doc.wpclever.net/woosb/plugin-settings/coupon-restriction-2/](https://doc.wpclever.net/woosb/plugin-settings/coupon-restriction-2/)

## Coupon Restriction

In order to exempt bundles from the coupon application, you can set it up accordingly:

- *No:* All kinds of coupons are applicable to bundles.
- *Exclude bundles:* For auto-priced bundles, all coupons are applicable. Manually priced bundles only accept fixed cart amount coupons.
- *Exclude bundled products*: For manually priced bundles, all coupons are applicable. Auto-priced bundles only accept fixed cart amount coupons.
- *Exclude both bundles and bundled products*: No coupons are applicable to product bundle type.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-cart-checkout-coupon-restriction.png)Coupon restriction choices

## Price formats

**Source:** [https://doc.wpclever.net/woosb/plugin-settings/price-formats/](https://doc.wpclever.net/woosb/plugin-settings/price-formats/)

## Price formats

Choose a format to define how the bundle price is displayed in shop archive page:

- From Min price, ie. “From $49”
- Min price only, ie. “$20”
- Min – Max, ie. “$20 -$49”
- Regular and Sale price, ie. “$20$49”

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-plugin-settings-price-format.png)

You can add a custom price display for each bundle in the box next to “Custom display price” under *Bundled Products* tab of the bundle page.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-plugin-settings-custom-display-price.png)

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-wpcstore-custom-display-price.png)Custom display price in the front end

## Search settings

**Source:** [https://doc.wpclever.net/woosb/plugin-settings/search-settings-2/](https://doc.wpclever.net/woosb/plugin-settings/search-settings-2/)

## Search settings

Configure the search behavior on your site:

- **Search limit:** enter a number to limit the maximum of results appearing in search.
- **Search by ID:** choose “Yes” to enable ID search by numeric input
- **Search exact:** choose “Yes” then products are displayed only when the whole title or content is matched.
- **Search sentence:** choose “Yes” to enable phrase search
- **Accept same product:** choose “Yes” to allow a product to be added several times to the same bundle.

From version *5.9.8* on, users can choose product types that can appear in the Search box from the plugin setting.

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-search-settings.png)

From version 7.2.1, users can now choose to hide or show thumbnails of products in the backend for faster search results:

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-hide-thumbnail-backend.png)

Hiding thumbnails will help results to be loaded faster when typing for items:

![](https://doc-14bd3.kxcdn.com/wp-content/uploads/2020/06/woosb-hide-thumbnails-backend.png)
