# Image Overlay Quick Start Guide

*Category from Kadence Blocks - PRO Extension documentation*

## Image Overlay Block

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/image-overlay-quick-start-guide/](https://www.kadencewp.com/help-center/docs/kadence-blocks/image-overlay-quick-start-guide/)

The image overlay block adds a highly customizable image menu option to the new editor. The block provides a background picture with an overlay. The overlay can have a background color and text and offers many customizable settings.

To set up the image overlay on your site, follow the [quick start tutorial](https://www.liquidweb.com/docs/kadence-blocks/image-overlay-quick-start-guide/).

Select the Image Overlay Block from the blocks list:

![Select Block](https://www.liquidweb.com/wp-content/uploads/2019/04/Image-Overlay-1024x630.jpeg)
## General

The general tab lets you set several customizations. There is an image selector to choose or update the image. The image can be set dynamically.

The image file size provides options for sizes registered on your site. The image overlay also lets you set a link for the image.

The max width setting sets the max width of the image and is adjustable for desktop, tablet, and mobile devices by clicking on the corresponding icons.

There are several animation options provided when a mouse hovers over the image. The image can remain static, zoom in, slide, grayscale, or blur when the hover event triggers.

The overlay opacity settings set the opacity of the overlay color when the image isn’t hovered over.

The image can preserve a ratio size instead of the image size if you enable the option.![Image Overlay General setttings tab](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-General-setttings-tab.jpeg)
### Style

The style tab provides several sections of settings.

The style tab sets the image overlay color using a color selector.

The overlay hover opacity sets the opacity for the overlay color when the mouse hovers over the image.![Image Overlay Style settings](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-Style-settings.jpeg)### Border Settings

Border settings let you change the border color, style, and width. You can also adjust the border-radius and position from the edge.

![Image Overlay Border Settings](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-Border-Settings.jpeg)### Text Alignment Settings

You can adjust the text’s vertical and horizontal alignment. The vertical value can be the top, center, or opposite. The horizontal alignment can be left, center, right, or opposite. The opposite value sets the title and text to opposite alignments.

![Image Overlay Text Alignment Settings](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-Text-Alignment-Settings.jpeg)### Title Settings

The title settings allow you to enable or disable the title text. You can also change the color, background color, HTML tag, font size, line height, letter case, font family, font weight, letter spacing, padding, and margin.

![Image Overlay Title Settings](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-Title-Settings.jpeg)### Subtitle Settings

The subtitle settings provide similar settings as the title. The subtitle can be enabled or disabled. In addition to the other settings, the subtitle can be hidden until hovered or always be visible.

![Image Overlay Subtitle Settings](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-Subtitle-Settings.jpeg)### Title and Subtitle Divider

The title and subtitle can have a divider between them. The divider style can be solid, dashed, dotted, or double lines. You can also change the divider’s color, height, and width.![Image Overlay Title and Subtitle Divider](https://www.liquidweb.com/wp-content/uploads/2019/01/Image-Overlay-Title-and-Subtitle-Divider.jpeg)
## Advanced

### Padding / Margin

You can set the padding and margin in the advanced tab. The values can be set individually or can be linked. The settings can also be adjusted for desktop, tablet, and mobile devices.
