## How to use Conditional Headers

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/conditional-headers/](https://www.kadencewp.com/help-center/docs/kadence-theme/conditional-headers/)

Kadence Theme Kit Pro allows you to set conditional headers throughout your site. For example, you can have a transparent header on your front page but a sticky one on all your post pages. The ability to set unique headers for specific pages gives you the power to show your audience more relevant information.

This is a feature of **Kadence Theme Kit Pro**. [Click here](https://www.liquidweb.com/software/kadence/pricing) to view our pricing plans. [Click here](https://www.liquidweb.com/docs/kadence-theme/kadence-theme-pro-addon/) to learn how to activate Kadence Theme Kit Pro.

## Enable Conditional Header

Kadence disables conditional headers by default. To enable the feature, navigate to *Appearance > Kadence* in your admin dashboard. Under the Pro Addons section, engage the switch to active the **Conditional Headers** feature.

![Kadence enable Conditional Headers](https://res.cloudinary.com/lwcom/images/w_1024,h_629,c_scale/f_auto,q_auto/v1780355734/prod/Kadence-enable-Conditional-Headers/Kadence-enable-Conditional-Headers.jpeg?_i=AA)Kadence enable Conditional Headers
## Create a Conditional Header

After you have enabled Conditional Headers, you can create an additional header inside your Customizer. While inside the admin dashboard, navigate to *Appearance > Customizer > Header > Conditional Header*. Inside the Customizer menu, you can change the Current Preview Header, view your additional headers, enable or disable them as necessary, and add more headers.

![Conditional Headers Menu](https://res.cloudinary.com/lwcom/images/w_372,h_492,c_scale/f_auto,q_auto/v1780355730/prod/Conditional-Headers-Menu/Conditional-Headers-Menu.jpeg?_i=AA)Conditional Headers MenuWhen you add a new header, you have the option to **Start Basic**, **Copy Default**, or **Import** an existing header. The default Extra Header provided is an example of the **Start Basic** option. If you select **Copy Default**, your new header will look the same as the default header at the creation time.

![Add Header](https://res.cloudinary.com/lwcom/images/w_465,h_393,c_scale/f_auto,q_auto/v1780355725/prod/Add-Header/Add-Header.jpeg?_i=AA)Add Header#### Notes

If a navigation menu is already assigned in another header, it will be shared across all headers that use it. Any edits made to that menu will automatically update everywhere it appears.

To keep your conditional headers unique, assign a **different navigation menu** to each one. This ensures that changes in one header do not affect others, since navigation menus are defined globally in WordPress.
## Header Preview

You can view any header you have created by selecting the Current Preview. The Customizer will let you know what header you are previewing in the Header General section. While previewing your header, you can make any alterations you want and publish your changes.

## Conditional Settings

A new header will not show until you set conditions to meet. Kadence provides a few different conditional options that you can arrange for additional headers.

### Display Settings

The **Display Settings** lets you set where Kadence will display the header. For example, you can select the Entire Site, Front Page, Blog Page, and many others. You can also add rules to display the header on the Front and Blog Page if you decide. While in the **Display Settings**, you can also choose what pages to exclude the header from. This setting allows you to provide multiple conditions where Kadence can display your header.

![Conditional Headers Display Settings](https://res.cloudinary.com/lwcom/images/w_285,h_720,c_scale/f_auto,q_auto/v1780355706/prod/Conditional-Headers-Display-Settings/Conditional-Headers-Display-Settings.gif?_i=AA)Conditional Headers Display Settings
### User Settings

User Settings will also let you know what users can view in the header. The User Settings allow you to select All Users, Logged In Users, Logged Out Users, or a specific user role. Similar to the Display settings, you can add additional rules or choose users for whom the header hides.

![Custom Header User Settings](https://res.cloudinary.com/lwcom/images/w_273,h_720,c_scale/f_auto,q_auto/v1780355700/prod/Custom-Header-User-Settings/Custom-Header-User-Settings.gif?_i=AA)Custom Header User SettingsIf you run into a case where a conditional header isn’t showing on the front-end for you or others, it is important to always ensure your User Settings are properly configured. **By** **default**, this is set to **none**. In return, no one will see the conditional header until the User Settings are properly configured.![User Settings](https://res.cloudinary.com/lwcom/images/w_626,h_466,c_scale/f_auto,q_auto/v1780352418/prod/User-Settings/User-Settings.jpg?_i=AA)
### Expires Settings

Another feature of conditional headers is the ability to set an expiration. When you click the Expires Settings menu, the Customizer displays a calendar to select a date and time the header will expire. After a header expires, it will no longer display on the front end of your site. There is also a reset link to help you reset the expiration time.
