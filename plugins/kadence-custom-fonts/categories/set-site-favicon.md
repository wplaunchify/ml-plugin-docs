## Set Site Favicon

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/set-site-favicon/](https://www.kadencewp.com/help-center/docs/kadence-theme/set-site-favicon/)

The favicon is the icon that shows in your browser tab. In Virtue and Pinnacle, the favicon was set in Theme Options> Misc Settings. WordPress now includes this option within the customizer.

![No Favicon Assigned](https://docs.nexcess.com/wp-content/uploads/2026/06/favicon-min.jpg)

To set the favicon, navigate to Appearance> Customize:

![Appearance Customize](https://docs.nexcess.com/wp-content/uploads/2026/06/download-8-min.jpeg)

In the customizer, open the “Site Identity” tab:

![Site Identity](https://docs.nexcess.com/wp-content/uploads/2026/06/download-9-min-662x1024-1.jpeg)

Upload your favicon and save the setting:

![Favicon Assigned](https://docs.nexcess.com/wp-content/uploads/2026/06/download-11-min-465x1024-1.jpeg)

If using Virtue or Pinnacle themes, be sure that the favicon is not already set in Theme Options> Misc Settings.
