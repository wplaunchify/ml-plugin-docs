## Single Post Layout Customizer Settings

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/single-post-layout-customizer-settings/](https://www.kadencewp.com/help-center/docs/kadence-theme/single-post-layout-customizer-settings/)

Use the **Kadence Single Post Layout Settings** to customize the single post layout. The Single Post Layout Settings can be accessed from **Appearance**  → **Customize** → **Posts/Pages Layout** → **Single Post Layout**.

![Kadence Single Post Layout - Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Zight-Recording-2025-05-05-at-03.08.49-PM-1024x442-1.gif)

Post Title Settings

**Show Post Title:** Toggle this to enable or disable the entire post title section.

**Post Title Layout:**Choose from **In** **Content** or **Above** **Content**. When using *in-content* titles, the title will blend in with the post content. When using the *above content* option, the title will appear as a banner above the post content.

**Container Width:** Choosing **Above** **Content** also allows you to set the Container Width.

- **STANDARD**:  Background Full-Width, Content Contained
- **FULLWIDTH**:  Background and Content Full-Width
- **CONTAINED**:  Background and Content Contained

**Post Title Align:** Align the title to the left, center, or right side of the page.

**Container Min Height:**If you’ve selected the *Above Content* layout option, use this to set a minimum height for the post title section.

![Kadence Single Post Layout - Post Title Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2025-05-05-at-2.03.57-PM-442x1024-1.png)

Title Elements

The **Title** **Elements** section allows you to control what information appears in your post title section. You can use the eye icons to enable or disable different title elements. In addition to enabling/disabling elements, you can also drag and drop items to control the order. 

**Breadcrumbs:** If you’re using the Kadence Breadcrumbs, you can choose whether or not to display the post title in the breadcrumbs. *(The Kadence breadcrumbs main behaviors can be modified from the Customizer -> General -> Breadcrumbs settings.)*

**Categories:** This option shows the current categories of the current post.

- **Divider**: Choose one of four dividers to place between category titles.
- **Style**: Choose a style for category names: Normal, Pill, or Underline.

**Title:** Choose to show the post title or not.

**Meta:** The meta information includes many more options to customize the metas shown within the post title area.

- **Divider**:  Choose the desired meta divider.
- **Show Author**: Enable or disable the post author.
- **Enable Author Link**: Link to the author archive.
- **Show Author Image**:  Show author gravatar.
- **Author Image Size**: If image enabled – set the image size.
- **Author Label**:  Show or hide the author label (i.e. Posted by).
- **Show Date**: Show the post publish date.
- **Show Time**: Show the post publish time.
- **Date Label**: Show or hide the label (i.e. Posted on).
- **Show Last Updated Date**: Show the post modified date.
- **Show only if different from publish date?**
- **Show Time**: Show the post modified time.
- **Updated Date Label**: Show or hide the label (i.e. Updated).

**Excerpt**: Show or hide the post excerpt.

![Kadence Single Post Layout - Title Elements Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Zight-Recording-2025-05-05-at-02.11.16-PM.gif)

![Title Elements](https://docs.nexcess.com/wp-content/uploads/2026/06/Title-Elements-1.jpg)

**Default Post Layout:** Select from one of several layouts:

- Normal – Uses the theme’s Content Width.
- Narrow – Creates a layout narrower than the standard theme content width, ideal for more compact designs.
- *(The Narrow Layout Content Max Width can be set from the Customizer -> General -> Layout settings.)*
- Fullwidth – Extends content to the full width of the page.
- If using a Boxed Site Layout, this option may still respect the container width unless otherwise styled.
- Left/Right Sidebar – Allows a sidebar to be added to the Single Post. Choose between Sidebar 1 and Sidebar 2.

**Post Default Sidebar:**Choose the Default Sidebar used in posts (i.e. Sidebar 1 or Sidebar 2). This option is applicable when using a sidebar layout.

![Kadence Single Post Layout - Default Post Layout Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2025-05-05-at-2.35.37-PM.png)

**Content Style:**Select either **Boxed** or **Unboxed** style. When using the boxed option, the post content will become boxed in. When using unboxed, the content will be unboxed and unrestricted.

**Content Vertical Spacing**: Controls the spacing above and below the content section.

![Kadence Single Post Layout - Content Style Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2025-05-05-at-2.36.03-PM.png)

Additional Post Features

- **Show Featured Image**:  enable or disable the post featured image.
- **Featured Image Position**:  Above, Behind or Below
- **Show Featured Image Caption?** (This option becomes available only when you select **Above** or **Below** as the Featured Image Position.)
- **Featured Image Ratio**:  Choose from one of several image ratios.
- **Show Post Tags**:  Tags appear after the content section.
- **Show Post Author Box?**
- **Author Box Style**:  Normal or Center.
- **Use Author Archive Link**:  Link name to author archive.
- **Show Post Navigation**: Previous/Next post links appear after content section.
- **Show Related Posts**
- **Related Posts Columns**: 2, 3 or 4.
- **Related Posts Title**: The Related Posts section title.
- **Related Posts Order By**:  Choose from several options.
- **Related Posts Order**:  Descending or Ascending.
- **Endlessly Loop Related Carousel**:  Enable to loop endlessly or disable to use rewind effect.
- **Show Comments**: Enable or disable comments section.
- **Show Comment Date**: Show or hide comment dates.

Single Post Design Settings

Use the Design Tab at the top of the Single Post Layout Settings to control colors throughout single posts.

![Post Design Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Post-Design-Settings.jpg)

Post Title

**Post Title Font:**

- The circle represents and sets the Post Title color. Click it and you should see a color picker.
- The three rectangles should let you set the Font Family, Style, and Size, respectively.
- The SIZE tab will have the options for **Font Size**, **Line Height**, **Letter Spacing**, and Text Case (**Transform**).

**Category Colors:** Adjust the title Category Colors.

**Category Font:**Set the font family, font style, and font size for title categories.

**Breadcrumbs Colors:** Adjust the Breadcrumbs Color for the initial state and the hover state.

**Breadcrumbs Font:**Set the font family, font style, and font size for the title breadcrumbs.

**Meta Colors:** Adjust the Meta Color for the initial state and the hover state.

**Meta Font:**Set the font family, font style, and font size for the title meta.

**Excerpt Colors:** Adjust the Excerpt Color for the initial state and the hover state.

**Excerpt Font:**Set the font family, font style, and font size for the title excerpt.

**Post Title Background:** Set the Post Title Background. This can be set to a solid color, gradient, or image.

**Border:** Select a Border for the Top and Bottom of the Post Title and/or the Left and Right side. This initial icon will be an X. Click on the X to select a specific Border Style. You will also be able to select the Border Width*(px)*and Color once a Border Style is selected. *(See the GIF below.)*

![Single Post Design](https://docs.nexcess.com/wp-content/uploads/2026/06/Single-Post-Design.jpg)

Default Post Layout

**Site Background:** Set a Background Color for the Single Post pages. This applies to the entire Site Background.

**Content Background:** Set a Content Background color for Single Posts. This applies to the Background of the Main Content.

![Default Post Layout](https://docs.nexcess.com/wp-content/uploads/2026/06/Default-Post-Layout.jpg)

Related Post Settings

Related Posts Section Title Font: Adjust the font color, family, style, and size for the main Related Posts title text.

Related Posts Section Background: Set a specific background color for the related posts section.

![Related Posts](https://docs.nexcess.com/wp-content/uploads/2026/06/Related-Posts.jpg)

![Related Posts Example](https://docs.nexcess.com/wp-content/uploads/2026/06/Related-Posts-Example.jpg)

Override Single Post Layout Settings

The default post layout settings can be overridden on individual posts.  While editing a post, click the **Page Settings** icon in the top bar to adjust your layout settings.

![Override default post layout settings for individual posts.](https://docs.nexcess.com/wp-content/uploads/2026/06/Edit-Single-Post-Layout-Settings-1024x561-1.png)
