## Installing and Creating Kadence Elements

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/installing-kadence-elements/](https://www.kadencewp.com/help-center/docs/kadence-theme/installing-kadence-elements/)

Kadence Elements is a feature available in the [Kadence Theme Kit Pro plugin](https://www.liquidweb.com/software/kadence/). This plugin extends the functionality of the free Kadence Theme.

To create a **Hooked Element**, you must first install, activate, and license the *Kadence Theme Kit Pro*plugin. ([Click here to learn more](https://www.liquidweb.com/docs/kadence-theme/kadence-theme-pro-addon/).) Once the *Theme Kit Pro plugin* is activated on the website, navigate to the **Dashboard -> Appearance -> Kadence** page and enable the **Hooked** **Elements** option.

![Enabled Hooked Elements](https://www.liquidweb.com/wp-content/uploads/2025/05/Enabled-Hooked-Elements-scaled.jpg)Once finished, either click the Customize button or manually navigate to the new **Dashboard -> Appearance -> Kadence -> Elements** page. At the top of the page, click the **Add New Element** button to begin creating your first Element.

![Add New Element](https://res.cloudinary.com/lwcom/images/w_1024,h_753,c_scale/f_auto,q_auto/v1780352985/prod/Add-New-Element/Add-New-Element.jpg?_i=AA)You will be prompted to select an **Element** **Type** when creating a new *Element*.

![New Element Setup](https://www.liquidweb.com/wp-content/uploads/2022/04/New-Element-Setup.jpeg)[Click here](https://www.liquidweb.com/docs/kadence-theme/the-four-types-of-kadence-elements/) to learn about the *Four Kadence Element Types* and what each one can do.
