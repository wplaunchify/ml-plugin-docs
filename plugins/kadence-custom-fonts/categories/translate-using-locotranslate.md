## How to translate using LocoTranslate

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/translate-using-locotranslate/](https://www.kadencewp.com/help-center/docs/kadence-theme/translate-using-locotranslate/)

Loco Translate is a plugin that allows you to make changes to your string translations within the WordPress admin area. Editing these files directly on your site streamlines the process and eliminates the need to edit any theme files.

The process of getting started with the plugin is the same as any other in the WordPress repository.

You can either search for the plugin in the repository or manually install it:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-5.gif)

Or download the plugin in your WP admin area:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-3.gif)

With Loco Translate installed, you’ll now see an option in your admin for accessing the plugin settings:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/LocoSettings.png)

Before we translate, we need to decide which text we’re changing. For this example, we’ll be changing the “Next Post” and “Previous Post” text in our Dutch site’s blog.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-47.png)

Within the Loco settings, select the plugin or theme that you’re trying to translate. This string is a part of Kadence Theme:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-1-13.png)

After you’ve opened up your plugin or theme, select the language you want to edit:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-2-11.png)

If you don’t see your language in the list, then you can create a new PO file for your language’s translations:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-4.gif)

Once you’ve accessed your language file, search for the string that you want to change in the string editor:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-3-6.png)

Search for any additional strings you may want to edit, and make your changes:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-5-4.png)

When you’re satisfied with your translations, click the blue “Save” button:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-6-6.png)

Finally, view the front end of your site to ensure that your changes are reflected. If you’re not seeing your string translations, be sure to clear your site’s and or browser’s cache:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-4-6.png)
