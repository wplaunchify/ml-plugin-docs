## Adding a Full-width Row

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/adding-a-fullwidth-row/](https://www.kadencewp.com/help-center/docs/kadence-blocks/adding-a-fullwidth-row/)

The block editor allows blocks to be aligned fullwidth or wide width. This can be done by clicking on the align button in the block toolbar and then choosing the fullwidth option.
