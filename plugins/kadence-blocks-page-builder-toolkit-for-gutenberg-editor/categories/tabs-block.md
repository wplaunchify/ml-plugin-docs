## Tabs Block

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/tabs-block/](https://www.kadencewp.com/help-center/docs/kadence-blocks/tabs-block/)

The tabs block gives you an extremely versatile option for adding tabs to your Gutenberg layouts. The block allows you to customize the layout and appearance of your tabs to give you limitless possibilities.

To use the tabs block, first select it from your block list:

![Select Tabs Block](https://docs.nexcess.com/wp-content/uploads/2026/06/TabsBlock-min-1024x632-1.jpeg)

**Adding Tabs:** Set the number of tabs you’d like to show and choose to display your tabs horizontally or vertically:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabsblock.gif)

**Reordering Tabs**: To change the order of your tabs, first select the parent **Tabs Block**. From there, click on the specific **Tab Title** you wish to move. You will see directional arrow icons appear in the toolbar; click these arrows to shift the tab left or right.

![Reordering Tabs](https://docs.nexcess.com/wp-content/uploads/2026/06/Reordering-Tabs.gif)

Inner Tabs Blocks are locked by default. This is standard, and it is **not** **possible** to unlock inner tab blocks, as it can cause issues with the entire block.

![Locked Tabs](https://docs.nexcess.com/wp-content/uploads/2026/06/Locked-Tabs.jpg)

**Delete Tabs:**To delete a tab, select the specific **Tab Title** you wish to remove. In the block toolbar (next to the movement arrows), click the **“X” icon** to delete that individual tab.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/ZightRecording2025-11-07at10.23.37AM-ezgif.com-video-to-gif-converter.gif)

Content Settings define the background, border, and padding for your tab content. Adjust the colors and spacing to meet your needs:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabs-1024x493-1.png)

The Tab Title Color Settings allow you to set the background and border for your tab titles. Control the normal, hover, and active states separately :

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabcolors-415x1024-1.png)

Tab Title Spacing and Border Settings allow you to set the spacing of your titles as well as the border style:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabsmargin.gif)

Tab Title Font Settings sets the fonts of your title. Set the family, size, line height, and spacing of your tab titles:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabsfonts-357x1024-1.png)

If you wish, you can add an icon to each individual tab:

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabsicons-1024x493-1.png)

In the Advanced Tab, you can set the padding/margin, content minimum height, and max-width for your Tabs Block.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabs-block-advanced-settings.png)

You can also save the block as the default, add an HTML anchor, or add additional CSS class(es) to the tabs block.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/tabs-block-advanced.png)
