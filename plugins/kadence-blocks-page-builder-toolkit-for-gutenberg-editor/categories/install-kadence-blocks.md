## Installing Kadence Blocks

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/install-kadence-blocks/](https://www.kadencewp.com/help-center/docs/kadence-blocks/install-kadence-blocks/)

The following steps provide details on installing the [Kadence Blocks](https://www.kadencewp.com/kadence-blocks/) plugin on your WordPress site. The Kadence Blocks plugin is free and can be used without a premium purchase. Kadence Blocks can be found under the name *Gutenberg Blocks with AI by Kadence* in the plugin dashboard.

You can extend the Kadence Blocks functionality using the premium Kadence Blocks Pro plugin. You can [click here](https://www.kadencewp.com/kadence-blocks/premium/) to learn more.

Built-in WordPress Installation

You can install the Kadence Blocks plugin directly from your WordPress Dashboard. Below are instructions on how you can do this.

In the WordPress **Dashboard**, go to **Plugins -> Add New Plugin**.

![Kadence Blocks Add new Plugin](https://docs.nexcess.com/wp-content/uploads/2026/06/Kadence-Blocks-Add-new-Plugin-scaled-1.jpg)

Then, you can search for **Kadence** **Blocks**and locate the **Gutenberg Blocks with AI By Kadence** plugin.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Kadence-Blocks-Download-scaled-1.jpg)

Finally, click on the **Install** **Now** button and then the **Activate** button. You will then have successfully installed and activated Kadence Blocks.

Manual Installation

You can install the Kadence Blocks plugin manually by downloading it from [WordPress.org](https://wordpress.org/) and uploading it to your WordPress Plugins. Below are instructions on how you can do this.

First, download the Kadence Blocks plugin by [clicking here](https://wordpress.org/plugins/kadence-blocks/). Ensure you keep this file in the ZIP format, as it needs to be uploaded in this compressed format. (Do not extract)

![Download Blocks](https://docs.nexcess.com/wp-content/uploads/2026/06/Download-Blocks-1024x661-1.jpg)

Next, navigate to your WordPress Dashboard and go to **Plugins -> Add New Plugin**. At the top of the Add New Plugin page, click on the **Upload** **Plugin** button.

![Upload Kadence Blocks Pro](https://docs.nexcess.com/wp-content/uploads/2026/06/Upload-Kadence-Blocks-Pro-scaled-1.jpg)

Then, click on the **Choose** **File** button at the top of the page and select your Kadence Blocks Zip file. Once you have selected the file, click the **Install** **Now** button.

![Upload Blocks](https://docs.nexcess.com/wp-content/uploads/2026/06/Upload-Blocks-1024x369-1.jpg)

Once the plugin is installed, click the blue **Activate** **Plugin** button to activate your plugin. Now your Kadence Blocks plugin is Activated on your website.

Determining which blocks are from Kadence and from other plugins/WordPress

Our blocks can be found under the “KADENCE BLOCKS” category, or simply by noticing the block icon color. They are all in our brand color, blue.
