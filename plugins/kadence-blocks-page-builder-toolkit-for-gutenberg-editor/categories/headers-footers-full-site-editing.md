## Building Headers and Footers in Full Site Editing with Kadence Blocks

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/headers-footers-full-site-editing/](https://www.kadencewp.com/help-center/docs/kadence-blocks/headers-footers-full-site-editing/)

Full Site Editing Themes empower you to create dynamic Page Templates that seamlessly integrate Headers, Footers, and Content into a cohesive design. These versatile Templates can be utilized across Pages, Posts, and Layouts, ensuring consistent styling throughout your site. Enhance your designs further by incorporating Advanced Header Blocks into your Headers and utilizing Advanced Navigation Blocks in your Footers, providing even greater flexibility for your FSE Templates.

## Full Site Editing

Full Site Editing (FSE) is a powerful feature in WordPress that enhances the Gutenberg Editor, enabling users to not only edit posts and pages but also customize the entire layout and design of their websites. With FSE, you can effortlessly modify headers, footers, sidebars, and other template parts using blocks, granting you greater flexibility and control over your site’s appearance.

To leverage the features of FSE, you must activate a theme that supports FSE. **Currently, Kadence does not provide an FSE theme.** For a complete FSE experience, consider using an *FSE-supported* theme such as [Twenty Twenty-Four](https://wordpress.org/themes/twentytwentyfour/).

### Templates

In FSE, Pages, Posts, and Archives are crafted using **Templates**, providing a more flexible and cohesive design across your website. This approach allows you to customize the structure and appearance of your content while ensuring consistency throughout your site. 

To access Templates, go to the **Dashboard -> Appearance -> Editor** page and navigate to the **Templates** tab.

![Templates](https://res.cloudinary.com/lwcom/images/w_1023,h_505,c_scale/f_auto,q_auto/v1780354339/prod/Templates/Templates.jpg?_i=AA)The Twenty Twenty-Four theme, like other FSE themes, includes pre-built **Templates** for various purposes. For example, Twenty Twenty-Four features the *“Pages”*Template that is automatically applied to all newly created pages. Additionally, default Templates for single posts and archives are provided. These Templates offer customization options to meet your specific needs or can be entirely replaced with your own designs, providing flexibility in how your content is presented.

Next to each Template, you’ll find an icon featuring three dots. Click on this icon and select the **Edit** option to modify the template.

![Edit a Template](https://res.cloudinary.com/lwcom/images/w_1024,h_480,c_scale/f_auto,q_auto/v1780354314/prod/Edit-a-Template/Edit-a-Template.gif?_i=AA)When editing a Template, take note of the Header and Footer Patterns in the list view. These patterns are utilized to display the header and footer across various templates.

![List View](https://res.cloudinary.com/lwcom/images/w_348,h_149,c_scale/f_auto,q_auto/v1780354310/prod/List-View/List-View.jpg?_i=AA)View the sections below for more information on Patterns and how to use them.

### Patterns

In FSE, you can create **Patterns** that can be utilized throughout your website, both within and outside of FSE templates.

Access Patterns by going to the**Dashboard -> Appearance -> Editor** and navigating to the **Patterns** tab.

![Access Patterns](https://res.cloudinary.com/lwcom/images/w_1024,h_503,c_scale/f_auto,q_auto/v1780354331/prod/Access-Patterns/Access-Patterns.jpg?_i=AA)Patterns can be created by selecting a block in the Editor and using the Block Toolbar to create a new Pattern. This process includes the selected block and all its nested blocks in the new Pattern. Patterns can be classified as either Synced or Unsynced. If a Pattern is set to Synced, any modifications made to that Pattern will be reflected in all other instances where the Pattern is used.

![Create a Pattern](https://res.cloudinary.com/lwcom/images/w_928,h_626,c_scale/f_auto,q_auto/v1780354351/prod/Create-a-Pattern/Create-a-Pattern.gif?_i=AA)Once a Pattern is created, it can be added to your website, anywhere in the Editor, just like other blocks. The Pattern can be found by searching for the Pattern Name when adding a new Block.

![Adding a Pattern](https://res.cloudinary.com/lwcom/images/w_930,h_696,c_scale/f_auto,q_auto/v1780354344/prod/Adding-a-Pattern/Adding-a-Pattern.gif?_i=AA)
### Header and Footer Patterns

Typically, the Header and Footer sections of Templates are created using Patterns.

![Header Patterns](https://res.cloudinary.com/lwcom/images/w_1024,h_432,c_scale/f_auto,q_auto/v1780354325/prod/Header-Patterns/Header-Patterns.jpg?_i=AA)Edit these patterns either by finding them in the **Dashboard -> Editor -> Templates** list or by selecting the **Pattern** in the **Editor** and clicking on the **Edit** button from the **Block Toolbar**. This will bring you directly to the Pattern Editor to make changes to all instances of the Pattern.

![Edit Pattern](https://res.cloudinary.com/lwcom/images/w_693,h_303,c_scale/f_auto,q_auto/v1780354307/prod/Edit-Pattern/Edit-Pattern.jpg?_i=AA)
#### Editing the Header Pattern

When editing the Header Pattern, you’ll see a prompt suggesting that you try the Kadence Header Block. Click the **Replace with Kadence Header** button to automatically swap the current Header Contents for an Advanced Header Block. This will enable you to select or create a new Advanced Header Block, effectively replacing the existing Header Contents.

![Replace Header Pattern](https://res.cloudinary.com/lwcom/images/w_1024,h_507,c_scale/f_auto,q_auto/v1780354290/prod/Replace-Header-Pattern/Replace-Header-Pattern.gif?_i=AA)Once finished, customize your Advanced Header Block as preferred. This will update all instances of the Header Pattern to your newly created Advanced Header. 

Learn more about getting started with [Advanced Headers and Navigations here](https://www.liquidweb.com/docs/kadence-blocks/getting-started-with-advanced-header-navigations/).

#### Editing the Footer Pattern

Use Kadence Blocks to design your Footer Pattern. Start by either navigating to the Dashboard -> Editor -> Template page and editing the Footer Pattern or by selecting the Pattern in the Editor and clicking on Edit from the Block Toolbar.

The contents within the Footer Pattern can be replaced with a main Row Layout Block.

![Footer Row Layout Block](https://res.cloudinary.com/lwcom/images/w_1024,h_449,c_scale/f_auto,q_auto/v1780354273/prod/Footer-Row-Layout-Block/Footer-Row-Layout-Block.gif?_i=AA)Use Kadence Blocks to customize the Footer Contents. For example, [Advanced Image Blocks](https://www.liquidweb.com/docs/kadence-blocks/advanced-image/) can be used to display Logos or Images; [Advanced Navigation Blocks](https://www.liquidweb.com/docs/kadence-blocks/the-kadence-navigation-adv-block/) can be used to add Navigations and Advanced Text Blocks can be used to add general texts.

![Footer Navigation](https://res.cloudinary.com/lwcom/images/w_1024,h_507,c_scale/f_auto,q_auto/v1780354266/prod/Footer-Navigation/Footer-Navigation.jpg?_i=AA)Once finished, don’t forget to save the Footer Pattern for the changes to take effect. This will update all instances of the Footer Pattern to use the new Kadence Blocks version.

### Conclusion

Once the Header and Footer Patterns are customized using Kadence Blocks, the Templates will all update accordingly. When creating a new Post/Page or viewing your website, the Header and Footer will reflect the changes made to the Patterns.
