## Set Equal Column Heights with the Row Layout Block

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/set-equal-column-heights-with-the-row-layout-block/](https://www.kadencewp.com/help-center/docs/kadence-blocks/set-equal-column-heights-with-the-row-layout-block/)

Within the settings for the row layout block you can make each column have an equal height. To do this create a row layout with 2 or more columns and click on the “structure settings” in the row layout block settings.
