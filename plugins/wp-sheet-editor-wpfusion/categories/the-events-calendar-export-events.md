In this tutorial, you will learn how to export events from The Events Calendar to a CSV file, Excel or Google Sheets. Now let’s see how to export events to different formats and platforms:

## Option 1: Export The Events Calendar to CSV file

Open the **Export** tool on the top toolbar.

![Open the Export tool in the events spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/22183004/the-events-calendar-export-events-02.png)

Now configure these values to download the data of your events in a CSV file:

- **Which columns do you want to export:** You can export all columns or only selected columns.
- **Which rows do you want to export:** You can export all your events, only the events from a specific search, or the events that you have manually selected in the spreadsheet.
- **What app will you use to edit this file:** Here you need to select the format. In this example, we will select **CSV File.**
- **Name of this export:** You can enter a name here and run this same export in the future with one click.
- Click on **Start new export.**

![Configure columns, rows and CSV format for exporting The Events Calendar events](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/22183029/the-events-calendar-export-events-03.png)

Once you do that, the export will start and a CSV file will be downloaded to your computer, containing the details of your The Events Calendar events. Here’s a preview of our events in the downloaded CSV file.

![the-events-calendar-export-events](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/22183114/the-events-calendar-export-events-05.png)

## Option 2: Export your events to Excel file (XLSX)

To export The Events Calendar to a Microsoft Excel file (XLSX), first open the **Export** tool.

![Open the Export tool in the events spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/22183004/the-events-calendar-export-events-02.png)

After you open the **Export** tool, select these values to download the events data in an Excel file:

- **Which columns do you want to export:** You can export all columns or only selected columns.
- **Which rows do you want to export:** You can export all your events, only the events from a specific search, or the events that you have manually selected in the spreadsheet.
- **What app will you use to edit this file:** Microsoft Excel (XLSX)
- **Name of this export:** You can enter a name here and run this same export in the future with one click.
- Click on **Start new export.**

![Configure The Events Calendar export in Microsoft Excel XLSX format](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/22183052/the-events-calendar-export-events-04.png)

Here’s a preview of our events in the downloaded Excel file.

![the-events-calendar-export-events](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/22184556/the-events-calendar-export-events-excel.png)

## Frequently Asked Questions on Exporting Events

### Can I manage other The Events Calendar data with WP Sheet Editor?

Yes, you can manage and export / import events, organizers and venues.

### Can I export only selected events?

Yes, you can do this in two ways:

1. Use the **Search** tool to filter events by status, price, organizer, venue, or any other field. Once done, export all the results from your search.
2. Use the checkbox picker to mark specific events and export only the events that you manually selected.
