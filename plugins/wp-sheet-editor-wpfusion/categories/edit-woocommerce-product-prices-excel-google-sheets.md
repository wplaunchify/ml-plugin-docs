## 1. Export WooCommerce product prices to Excel or Google Sheets

The **Export** tool in **WP Sheet Editor** lets you download your product catalog as a CSV or XLSX file that you can open in Google Sheets or Microsoft Excel.

**Optional:** Click **Display variations** if you also need to export and edit prices for product variations.

![Display WooCommerce product variations to export pricing to Excel or Google Sheets](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14091832/display-variations-to-export-pricing.png)

Go to **WP Sheet Editor > Edit products** and click **Export** in the top toolbar.

![Export WooCommerce prices with WP Sheet Editor](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084231/how-to-export-woocommerce-prices.png)

Configure your export settings:

- **What columns do you want to export:** Select the fields you need, such as 
```
Name
```

, 
```
SKU
```

, 
```
Regular price
```

, 
```
Sale price
```

, 
```
Date sale price starts
```

, and 
```
Date sale price ends
```

.
- **Which rows do you want to export:** Select **All the products from my current search**, or the products you have manually selected in the spreadsheet.
- **What app will you use to edit this file:** Choose **Microsoft Excel (XLSX)** or **Google Sheets (CSV file)**, depending on where you want to edit the file.
- **Name of this export:** Optional. Give the export a name if you want to reuse these settings for future pricing updates.
- Click **Start new export** to download the file.

![Set up export options to edit WooCommerce prices in Google Sheets or Excel](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084433/set-up-export-options-product-prices.png)

## 2. Edit prices in Google Sheets or Microsoft Excel

Open the exported file in Google Sheets or Microsoft Excel and make your pricing changes. You can edit prices manually, use formulas to update multiple products at once, change sale dates, or compare your prices with information from another spreadsheet.

For example, if you want to increase prices by 15%, you can use a formula such as 
```
=C2*1.15
```

 and apply it to the products you want to update. You can also use formulas to add a fixed amount or calculate new prices based on values in other columns.

Using a spreadsheet also makes it easier to share pricing files with vendors, accountants, or assistants without giving them access to your WordPress dashboard.

![Bulk edit WooCommerce prices in Excel or Google Sheets spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084140/bulk-edit-prices-in-excel-or-google-sheets.png)

## 3. Import edited prices back into WooCommerce

When you finish editing the spreadsheet, save the file and open the **Import** tool in WP Sheet Editor. From there, you can upload the file and use it to update your WooCommerce products.

![Import product prices tool in WP Sheet Editor](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084249/import-product-prices-in-woocommerce.png)

Upload your file:

- **Source:** Select **File from my computer**.
- Click **Choose file** and select your updated CSV or XLSX file.
- Click **Next**.

![Select spreadsheet file to import WooCommerce product prices](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084412/select-csv-pricing-to-import.jpg)

**Optional:** Tick **Show advanced options** if you need to change CSV field separator.

![Advanced import settings for CSV product price updates](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084114/advanced-import-selection-settings.jpg)

Map your spreadsheet columns:

- Select **Import all the columns** to automatically match the headers, or choose **Select individual columns to import** if you only want to update specific price fields.

![Choose product price columns to map and import into WooCommerce](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084157/choose-columns-to-import-prices.png)

Next, choose how WP Sheet Editor should identify the products you want to update:

- Select **Update existing products and ignore new products** so the import only updates products that already exist in your store.
- **Matching Field:** Match the rows by **SKU** or **ID** so each update goes to the correct product.
- Click **Next**.

![Map rows by SKU to update existing WooCommerce product prices](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084328/map-rows-in-pricing-import-woocommerce.jpg)

Review the preview to make sure the products and prices look correct. When everything is ready, click **Start import** to apply the changes.

![Run the import to bulk update WooCommerce prices from Google Sheets or Excel](https://media.wpsheeteditor.com/wp-content/uploads/2026/09/14084349/run-import-woocommerce-prices.jpg)
