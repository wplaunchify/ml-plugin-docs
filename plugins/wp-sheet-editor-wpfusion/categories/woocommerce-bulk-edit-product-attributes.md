## Method 1: Edit product attributes in the spreadsheet

WP Sheet Editor displays product attributes in the spreadsheet. Every global attribute you have, as well as custom attributes, will appear in the spreadsheet as editable columns. In this example, you can see that our spreadsheet displays the **Color** and **Size** attributes.

![woocommerce attribute columns in wp sheet editor](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26192151/attribute-columns-in-the-spreadsheet.png)

If you double-click a cell in an attribute column, you can easily select terms for that attribute from a searchable dropdown.

![selecting woocommerce attribute terms in a spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26191230/bulk-select-attributes-woocommerce-e1787799183993.png)

And if you want to add a new term without having to open WooCommerce’s native attributes page, you can do so directly from the spreadsheet cells. Just enter the new term, and click on **Add option.**

![creating new attribute terms in wp sheet editor spreadsheet cells](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26191246/create-new-attribute-terms-woocommerce.png)

If the attribute itself doesn’t exist yet (for example, you don’t have a “Material” attribute at all), you’ll need to create it first from WooCommerce’s **Products > Attributes** page. Once the attribute exists, it will show up as a column in the spreadsheet and you can fill it in using the steps above.

You can also copy and paste between cells and columns, including copying values from a custom attribute column into a global attribute column, or autofill a column down to match a pattern. This makes it easy to standardize attribute data across many products without retyping anything.

Once you’re done managing your product attributes in the spreadsheet, click **Save** to apply the changes.

![save changes after bulk updating attribute terms in woocommerce products spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26191902/save-attribute-changes.png)

## Method 2: Bulk update attributes

The **Bulk Edit** tool allows you to apply attribute changes to hundreds or thousands of WooCommerce products. This is useful when you don’t want to edit just a few products but dozens or hundreds/thousands of products at once.

**Important:** Before bulk updating products, always make a backup of your site since changes can’t be undone.

To choose which products you want to edit, you have at least three ways:

1. **Edit all products.** Just open the **Bulk Edit** tool and select **Edit all the rows from my current search**, which will update the products currently loaded in the spreadsheet, whether there are active search filters or not.
2. **Manually select specific products.** Use the checkbox picker on the left side of the spreadsheet to select the products you want to modify.
3. **Search for the products you want to edit.** The **Search** tool allows you to filter WooCommerce products using any field as a search filter, combine different search filters, etc.

Whatever the selection method, you need to open the **Bulk Edit** tool after deciding which products you will update.

![opening bulk edit attributes tool in wp sheet editor](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26192605/open-bulk-edit-attributes.png)

In the **Bulk Edit** tool, you need to:

1. Select which products you will edit
2. Choose the field you’re editing. In this case, it should be a product attribute field like Color, Size, Material, etc.
3. Choose the type of edit you want to apply: Set a completely new value, replace specific attributes, etc.

### Set the same attributes to all selected products

1. Select attribute field (Product color, size, material, etc.)
2. Set value
3. Enter the new attribute terms
4. Select if you want to edit products or variations
5. Execute

![values to set the same attribute terms in bulk in woocommerce products](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26200654/set-same-attributes-in-bulk.jpg)

### Bulk replace specific attributes

1. Select attribute field (Product color, size, material, etc.)
2. Replace
3. Enter the attribute you want to remove
4. Enter the attribute you want to add instead
5. Select if you want to edit products or variations
6. Execute

![values to bulk replace woocommerce product attribute terms](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26201225/replace-specific-attributes-in-bulk.jpg)

### Remove specific attribute terms from products

1. Select attribute field (Product color, size, material, etc.)
2. Remove terms from posts
3. Enter the attribute you want to remove
4. Select if you want to edit products or variations
5. Execute

![values to remove attribute terms from products woocommerce](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26201553/remove-specific-attributes-from-products.jpg)

You can also copy from other columns; for example, copy from custom attribute columns to global attribute columns.

## Method 3: Export and import product attributes using CSV, Excel, XML files

WP Sheet Editor lets you export and import WooCommerce attribute data using CSV, XLSX and XML files. This is useful when you want to edit attribute data outside WordPress, hand it off to someone else, or bring in attribute values generated by another system.

1. Open the **Export** tool in the spreadsheet’s top toolbar.
2. **Select the fields you want to export.** In this example, we will export the Product Color and the Product Size attributes.
3. **Select the rows you want to export:** All rows, all rows from a search, only specific rows you have manually selected in the spreadsheet.
4. Select the file extension. you can export CSV and Excel files.

![exporting woocommerce attributes to csv or excel file](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26202445/export-attribute-fields-woocommerce.jpg)

Once you have downloaded your WooCommerce product attribute data, you can apply all the changes you want in Excel or Google Sheets.

![manage product attributes in csv or excel](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26203249/csv-containing-woocommerce-attributes-1.png)

To import WooCommerce product attributes:

1. Open the **Import** tool.
2. Select the CSV, Excel or XML file from your computer.
3. Map the columns (which will be automatically done if you exported the file with WP Sheet Editor)
4. Select the product ID or SKU as an identifier to map the rows.
5. Run the import to bulk update product attributes from the CSV, XSLX or XML file.

![import woocommerce product attributes](https://media.wpsheeteditor.com/wp-content/uploads/2026/08/26203616/import-woocommerce-attributes.jpg)

Importing is a solid way to manage WooCommerce product attribute terms in bulk, especially when the source data was generated outside WordPress.
