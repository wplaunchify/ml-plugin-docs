## Two Ways to Add Meta Keywords

You have at least two ways to add meta keywords to your WordPress content. You can use the spreadsheet or import the meta keywords from a CSV or Excel file. Let’s see both ways in detail.

## 1- Use the spreadsheet to add meta keywords Yoast SEO

First, let’s search for all the posts missing SEO keyword in order to work only with those posts in the spreadsheet.

To to this, open the **Search** tool.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201836/add-meta-keywords-yoast-seo-2.png)

Now tick the **Enable advanced filters** checkbox and select these values:

- **Field:** SEO Keyword
- **Operator:** =
- **Value:** Leave this field empty.

Click on **Run search** to filter all your posts and find all the entries without SEO keyword.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201903/add-meta-keywords-yoast-seo-3.png)

Now the spreadsheet displays only the posts missing keyphrase.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201923/add-meta-keywords-yoast-seo-4.png)

Go to the **SEO keyword** column and you can start adding the Yoast SEO meta keyword / keyphrase in the spreadsheet cells. And once you’re done, click on **Save.**

![how to add keywords in yoast seo](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201945/add-meta-keywords-yoast-seo-5.png)

## 2- Upload Yoast meta keywords in bulk

With WP Sheet Editor, you can import a CSV or Excel file containing meta keywords and easily update your posts. Just find the posts or pages missing SEO keywords, edit them using your favorite CSV editor, and upload the Yoast SEO keywords.

First, let’s open the **Search** tool.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201836/add-meta-keywords-yoast-seo-2.png)

Tick the **Enable advanced filters** checkbox and select these values:

- **Field:** SEO Keyword
- **Operator:** =
- **Value:** Leave this field empty.

Click on **Run search** to filter all your posts and find posts missing keyword.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201903/add-meta-keywords-yoast-seo-3.png)

Now the spreadsheet displays only the posts missing keyphrase.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26201923/add-meta-keywords-yoast-seo-4.png)

Next, open the **Export** tool to download a CSV or Excel file containing the filtered data.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202034/add-meta-keywords-yoast-seo-7.png)

Select these values in the **Export** tool:

- **What columns do you want to export:** We will export these columns to assign this task to someone in our team:
- Title
- SEO Title
- SEO Description
- SEO Keyword (which is empty)
- And post ID
- **Which rows do you want to export:** All the rows from my current search.
- **What app will you use to edit this file:** Here you need to select the file format. You can select **CSV file** or **Excel file.**
- **Name of this export:** You can add a name to run this same export later with one click.
- Click on **Start new export.**

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202054/add-meta-keywords-yoast-seo-8.png)

Now we have downloaded a CSV file containing all posts without Yoast SEO keyword.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202111/add-meta-keywords-yoast-seo-9.png)

As you can see below, we have added the SEO keyphrases in the CSV, which we’re going to import into WordPress.

![how to add keywords in yoast seo](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202134/add-meta-keywords-yoast-seo-10.png)

Click on **Import.**

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202012/add-meta-keywords-yoast-seo-6.png)

In **Source**, select **File from my computer.**

Now click on **Choose File** and locate the file on your computer.

Click on **Next.**

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202151/add-meta-keywords-yoast-seo-11.jpg)

We will **Import all the columns** in this example.

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202223/add-meta-keywords-yoast-seo-12.png)

Now select **Update existing items, ignore new items** and map the rows using the **record_id** and **ID** fields.

Click on **Next.**

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202242/add-meta-keywords-yoast-seo-13.png)

Finally, you’ll see a preview. If everything is OK, you need to click on **The preview is fine, start import.**

![how-to-add-meta-keywords-yoast-seo-spreadsheet](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/26202303/add-meta-keywords-yoast-seo-14.png)
