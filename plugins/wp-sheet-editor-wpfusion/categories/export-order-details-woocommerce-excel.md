## How to Export Order Details from WooCommerce to Excel

**Source:** [https://wpsheeteditor.com/export-order-details-woocommerce-excel/](https://wpsheeteditor.com/export-order-details-woocommerce-excel/)

Need to review or report on your store’s orders in a spreadsheet? In this guide I will show you how to export WooCommerce order details to Excel, including information such as order dates, customer names, products, totals, and order statuses.

You can use the exported data to sort and analyze orders outside WordPress or share it with your team. Follow the steps below to export the order details you need.

## Step 4. Export order details to Excel (XLSX)

Set up the export settings to download your WooCommerce orders in an Excel file (XLSX):

- What columns do you want to export: You can export specific columns, all columns, or all the columns that are currently active in the spreadsheet.
- **Which rows do you want to export:** We will export all the rows. You can export all orders, only manually selected orders, or all orders from a specific search (by status, billing data, specific products, by coupon used, etc.)
- **What app will you use to edit this file:** Microsoft Excel (XLSX)
- **Name of this export:** You can add a name to this export and run it later again with one click.
- **Optional:** You can export all order details in one row, or tick the **Export every product (line item) as separate rows** checkbox.
- Click on **Start new export.**

![export-order-details-woocommerce-excel](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/14101518/export-woocommerce-order-details-to-excel-3.png)

Once the Excel file containing your order details has been downloaded into your computer, you can open it with Excel. Below you can see we have exported our orders.
