## Open the categories spreadsheet

Go to **WP Sheet Editor > Edit product categories** and you’ll see all your WooCommerce spreadsheets displayed in the spreadsheet.

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23140239/convert-woocommerce-product-categories-into-tags-01.png)

## Convert specific categories into tags

You have two ways to convert specific product categories into product tags.

### 1- Do it in the spreadsheet

Locate the **Taxonomy** column in the spreadsheet, and select **product_tag** to convert them into tags.

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23135808/convert-woocommerce-product-categories-into-tags-02.png)

You can convert multiple categories into tags by selecting the **product_tag** value in the spreadsheet and then clicking on **Save** to apply the changes.

![convert woocommerce product categories into tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23135850/convert-woocommerce-product-categories-into-tags-03.png)

### 2- Select and convert categories in bulk

The spreadsheet includes a checkbox picker where you can select every category that you want to convert into a tag. In the screenshot below, we have selected multiple categories, which we will convert into tags in bulk.

After selecting the categories you will convert, open the **Bulk Edit** tool.

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23141334/convert-woocommerce-product-categories-into-tags-07-2048x1165-1.jpg)

Once you’re in the **Bulk Edit** tool, select these values to convert all the selected categories into tags:

- **Select the rows that you want to update:** Edit all the rows that I selected manually in the spreadsheet
- **What field do you want to edit:** Taxonomy
- **Select type of edit:** Set value
- **Replace existing value with this value:** product_tag
- **Tip:** Pay attention to the number of categories that will be converted to make sure the number matches your selection.
- Click on **Execute Now.**

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23142456/convert-selected-categories-into-tags.png)

## Convert empty categories into tags

If you decide to convert only the empty categories (categories with no products), you can do it by first filtering the categories where products count is 0 and then converting them in bulk.

### 1- Search for the empty categories

First, let’s see which categories are without products. To do this, let’s open the **Search** tool.

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23143515/convert-empty-categories-into-tags-1.png)

Now select these values to display only empty categories in the spreadsheet:

- Tick the **Enable advanced filters** checkbox.
- **Field:** Count
- **Operator:** =
- **Value:** 0
- Click on **Run search.**

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23143537/convert-empty-categories-into-tags-2.png)

After running the search, all the empty categories will be displayed in the spreadsheet; you can look at the **Count** column and you’ll see only categories where count is 0.

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23143559/convert-empty-categories-into-tags-3.png)

### 2- Convert the empty categories into tags

You need to open the **Bulk Edit** tool.

![convert-woocommerce-product-categories-into-tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23143625/convert-empty-categories-into-tags-4.png)

Finally, select these values in the **Bulk Edit** tool in order to convert empty categories into tags:

- **Select the rows that you want to update:** Edit all the rows from my current search
- **What field do you want to edit:** Taxonomy
- **Select type of edit:** Set value
- **Replace existing value with this value:** product_tag
- Click on **Execute Now.**

![convert woocommerce empty product categories into tags](https://media.wpsheeteditor.com/wp-content/uploads/2026/10/23143654/convert-empty-categories-into-tags-5.png)
