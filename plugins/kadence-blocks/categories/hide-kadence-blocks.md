## How to hide Kadence blocks via WordPress Gutenberg Preferences

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/hide-kadence-blocks/](https://www.kadencewp.com/help-center/docs/kadence-blocks/hide-kadence-blocks/)

To hide**Kadence Blocks** from showing in the WordPress **Gutenberg editor** using **Preferences**, follow these simple steps:

1. **Edit or Add a Post or Page.**
2. **Open the Preferences menu**.- Click the three vertical dots**(⋮)** in the top-right corner of the Gutenberg editor.
- Select **“Preferences”** at the bottom of the dropdown.
3. **Go to the “Blocks” tab** in the Preferences pop-up.
4. **Find Kadence Blocks**.- Scroll through the list of block types.
- Look for **Kadence Blocks** (they usually start with names like *Row Layout*, *Advanced Button*, etc.).
5. **Uncheck the blocks that you want to hide**.
6. **Close the Preferences window**.

![](https://www.liquidweb.com/wp-content/uploads/2025/07/Zight-Recording-2025-07-31-at-10.02.38-AM.gif)**Notes**:

- The hidden Kadence blocks will no longer appear in the **block inserter** (the “+” button).
- They can still appear if already used in existing content unless removed manually.
