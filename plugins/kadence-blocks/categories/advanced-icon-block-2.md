## Icon Block

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/advanced-icon-block-2/](https://www.kadencewp.com/help-center/docs/kadence-blocks/advanced-icon-block-2/)

The Advanced Icon Block allows you to configure icons in a myriad of ways.  Setting up the icon block is simple!

Firstly, select the icon block from your Gutenberg blocks list. Remember that Kadence Blocks are all blue for faster selection:

![Select Icon Block](https://docs.nexcess.com/wp-content/uploads/2026/06/Advanced-Button-min.jpeg)

By default, the block adds a single icon. However, you add more icons using the “Add Another Icon” button located on the toolbar.

![Icon block add another icon button](https://docs.nexcess.com/wp-content/uploads/2026/06/Icon-block-add-another-icon-button.gif)

When multiple icons are chosen, you need to edit them individually by opening each icon’s settings:

Select which Icon you’d like to edit by selecting the icon from the List View.

![Icon block select icon](https://docs.nexcess.com/wp-content/uploads/2026/06/Icon-block-select-icon.gif)

The individual icon settings are as follows:

![Icon block general settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Icon-block-general-settings.jpeg)

![Icon block Advanced settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Icon-block-Advanced-settings.jpeg)

Configure your icons as needed. When happy with the layout, save your page changes and view on the frontend:

![Advanced Icon Block](https://docs.nexcess.com/wp-content/uploads/2026/06/Icon-Blocka-1024x518-1.jpg)

![Advanced Icons](https://docs.nexcess.com/wp-content/uploads/2026/06/Advanced-Icon-2-1024x229-1.jpg)
