# How To Download Previous Versions Of The Kadence Theme And Plugins

*Category from Kadence Blocks documentation*

---

## How to Download Previous Versions of the Kadence Theme and Plugins

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/how-to-download-previous-versions-of-the-kadence-theme-and-plugins/](https://www.kadencewp.com/help-center/docs/kadence-blocks/how-to-download-previous-versions-of-the-kadence-theme-and-plugins/)

If you need to test with an earlier version of the Kadence theme or plugins, or you are troubleshooting an issue and want to compare behavior across versions, you can follow the steps below to download previous releases.

---

## Kadence Plugins from WordPress.org

You can download earlier versions of plugins such as **Kadence Blocks** using the WordPress.org plugin repository.

### Steps:

1. Visit the plugin’s page on WordPress.org.
For example: [https://wordpress.org/plugins/kadence-blocks](https://wordpress.org/plugins/kadence-blocks)
2. Click the **“Advanced View”** link in the right-hand sidebar. (or [click here](https://wordpress.org/plugins/kadence-blocks/advanced/))
3. Scroll down to the **“Previous Versions”** section.
4. Select the version number you want, then click **Download**.

![Downgrade Blocks](https://docs.nexcess.com/wp-content/uploads/2026/06/Downgrade-Blocks.gif)

## Kadence Theme (Free Version)

Older versions of the Kadence Theme are available through the WordPress Themes SVN repository.

### Steps:

1. Go to [https://themes.svn.wordpress.org/kadence](https://themes.svn.wordpress.org/kadence) to view all available version numbers.
2. Once you identify the version you want, use the following format to download it: 
```
https://downloads.wordpress.org/theme/kadence.{version}.zip
```

**Example:**
[https://downloads.wordpress.org/theme/kadence.1.1.35.zip](https://downloads.wordpress.org/theme/kadence.1.1.35.zip)

---

## Kadence Pro Plugins

For premium products such as **Kadence Blocks Pro** and **Kadence Theme Pro**, previous versions are available in your Kadence account.

### Steps:

1. Log in to your Kadence account:
[https://www.kadencewp.com/my-account/downloads](https://www.kadencewp.com/my-account/downloads)
2. Scroll to the plugin you want to download.
3. Use the dropdown menu to select an older version, then click **Download**.
