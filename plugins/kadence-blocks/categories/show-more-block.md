## Show More Block

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-blocks/show-more-block/](https://www.kadencewp.com/help-center/docs/kadence-blocks/show-more-block/)

The Show More Block gives you an easy way to preview of a larger section of content.  The preview size can be adjusted by device type and a fade-out can be applied to the preview.

![Insert a Show More block](https://docs.nexcess.com/wp-content/uploads/2026/06/Zight-Recording-2025-10-14-at-04.00.14-PM.gif)

Overview

The **Show More** block is actually a group of blocks that includes a Section block and a Buttons (Adv) block.  The [Section block](https://docs.nexcess.com/software/kadence/section-block/) serves as the container for your content.

The “Show More” and “Show Less” buttons are powered by our [Buttons (Adv) block](https://docs.nexcess.com/software/kadence/advanced-buttons/) so you can customize them like you would any group of buttons.

![Kadence Show More block - List View](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2025-10-14-at-3.51.20-PM.png)

General Block Settings

Once you’ve added your content to the Show More block, you can adjust your settings.

![Show More Block - General Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Zight-Recording-2025-10-14-at-04.05.39-PM.gif)

**Display “hide” button once expanded** – when enabled, the “Show Less” button appears after the content has been expanded.  When disabled, the button does not appear and users cannot revert to the preview state.

**Maximum Preview Height** – the height of the preview window.  Responsive height settings for tablet and mobile are also available.

**Fade out preview** – toggle whether to fade the preview.

**Fade Size** – Adjust the size of the preview fade.

![Show More - General Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2025-10-14-at-4.14.50-PM.png)

Advanced Block Settings

**Padding** – Set the padding for the block.  Responsive options are available.

**Margins** – Set the margins for the block.    Responsive options are available.

**Expand Settings** – Set the default expand state for desktop, tablet, and mobile.

**Block Defaults** – Allows you to save your settings for future Show More blocks.

**Advanced** – Add Additional CSS class(es) to your block.

![Show More block - Advanced Settings](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2025-10-14-at-4.17.09-PM.png)
