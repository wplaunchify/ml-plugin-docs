## Activation

**Source:** [https://quadlayers.com/documentation/woocommerce-checkout-manager/activation/](https://quadlayers.com/documentation/woocommerce-checkout-manager/activation/)

Here we will explain how to install and activate WooCommerce Checkout Manager PRO in your WordPress site.

1. Download the *woocommerce-checkout-manager.zip* file from your [account](https://quadlayers.com/account/orders/).
2. Open your website’s WordPress admin panel at *mysite.com/wp-admin/*.
3. In the WP dashboard, go to *Plugins > Add New*.
4. Click *Upload Plugin*, at the top of the screen.
5. Click the *Choose File* button, use the pop-up window to look for the *woocommerce-checkout-manager-pro.zip* file, and select it.
6. Go to *Plugins > Installed Plugins* and click the *Activate* button under the **WooCommerce Checkout Manager PRO** section in the plugins list.

## Install WooCommerce Checkout Manager Free

The WooCommerce Checkout Manager PRO extends the free version of the plugin that you can find in the WordPress repository.

1. After installing WooCommerce Checkout Manager PRO, you may see a red alert in your admin dashboard to directly install the [WooCommerce Checkout Manager Free](https://quadlayers.com/checkout/?add-to-cart=74066&variation_id=118554).

1. Press the **Install WooCommerce Checkout Manager** button.
2. After the installation, you’ll see a new button to activate the plugin. Click the *Activate* button and you’re good to go.

## Activate License

Here we will show you how to activate the license for your WooCommerce Checkout Manager PRO plugin.

1. After installing WooCommerce Checkout Manager PRO and WooCommerce Checkout Manager Free, you’ll see a new section in the WordPress admin dashboard.
2. Go to the license tab in WooCommerce / Checkout / License

1. Now you have to include your license and activation email and then press the *Save Changes* button.

Go to the license tab in your QuadLayers [account](https://quadlayers.com/account/licenses/) and then copy and paste your license key and email activation.
