## Emails

**Source:** [https://quadlayers.com/documentation/woocommerce-checkout-manager/emails/](https://quadlayers.com/documentation/woocommerce-checkout-manager/emails/)

Let’s see how to include custom fields in the email notifications.

1. Go to *WooCommerce > Checkout > Email*
2. In the **Add custom fields** setting, select **Yes**
3. Then, add the Email Order Status where you want to include the custom fields
