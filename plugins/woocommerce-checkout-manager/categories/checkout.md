## Checkout

**Source:** [https://quadlayers.com/documentation/woocommerce-checkout-manager/checkout/](https://quadlayers.com/documentation/woocommerce-checkout-manager/checkout/)

Here we will have a look at some of the features that Checkout Manager for WooCommerce offers on the checkout page.

## Force shipping address

This option allows you to remove the toggle checkbox to display the shipping fields. Shipping fields will be always displayed and the user will be forced to fill them in.

## Force create an account

By activating this, you remove the option to create an account during the purchase process. The account will be created with the email defined by the user in the billing fields.

## Remove order notes

It allows you to remove the order notes in the checkout form.

## Add message before checkout

Include a custom message before or after the checkout form.
