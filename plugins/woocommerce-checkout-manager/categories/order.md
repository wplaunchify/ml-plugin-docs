## Order

**Source:** [https://quadlayers.com/documentation/woocommerce-checkout-manager/order/](https://quadlayers.com/documentation/woocommerce-checkout-manager/order/)

With WooCommerce Checkout Manager, you can add a section that includes specific data related to the order (status, custom fields, etc.).

It also allows you to set a thank you page next to the custom fields the users complete during the purchase process.

## Add upload files

This option allows to upload and display images during the order process. The user can also edit or delete files through the order page.

## Add custom fields

You can include a section on the Received order and Thank you page to display the values of the custom fields completed during the purchase process.
