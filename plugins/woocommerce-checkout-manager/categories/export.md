## Export

**Source:** [https://quadlayers.com/documentation/woocommerce-checkout-manager/export/](https://quadlayers.com/documentation/woocommerce-checkout-manager/export/)

WooCommerce Checkout Manager allows you to **export the custom fields** created in the billing, shipping, and advanced section.

WooCommerce doesn’t offer native support for the orders and customer fields, so you need to install the official plugin [WooCommerce Customer / Order / Coupon Export.](https://woocommerce.com/products/ordercustomer-csv-export/)

Checkout Manager for WooCommerce is compatible with this plugin and lets you include the custom fields in the exports generated by WooCommerce Customer / Order.

To export your customer and order fields, you have to activate the *Export* custom fields option in the advanced tab and follow the steps described [here](https://docs.woocommerce.com/document/ordercustomer-csv-export/).
