## Adding conditional fields

Checkout Manager for WooCommerce supports conditional checkout fields allowing you to show/hide those fields based on the value of the parent field.

### Conditional parent

Select the conditional parent field and hide the current field based on the parent value.

### Conditional parent value

Checkout Manager detects the parent field type and allows you to select the value based on the available options.
