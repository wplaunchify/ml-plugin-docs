## Login Me Now – Passwordless, Magic Link, OTP & Social Login for WordPress

**Source:** [https://wordpress.org/plugins/login-me-now/](https://wordpress.org/plugins/login-me-now/)

## Description

	
#### What is Login Me Now?

Login Me Now is a modern login and access control solution for WordPress. It helps you:

- Grant temporary access with secure one-time links
- Log in without passwords
- Offer Google and Facebook social login
- Switch between user accounts instantly
- Use browser extensions for one-click dashboard access
- Verify users with SMS-based one-time passwords
- Track login history and activity
- Manage modules, integrations, and features from a single hub

New: Phone OTP Login

Allow users to verify identity with one-time passwords delivered via SMS using Firebase or Twilio.

Improved Email Magic Link

Refined modal, confirmation step, and updated email template for a more professional experience.

#### Key Features

### Passwordless & Temporary Login

- Generate secure login links with expiration time (hours or days)
- No passwords needed — secure login with one click
- Control access using validity periods and conditional settings

### Social Login

- Google and Facebook login support
- Use shortcodes to place login buttons anywhere
- Pro: Sync profile photo and name
- Pro: Redirect users to any page after login

### Phone OTP Login (New)

- OTP delivery through Firebase or Twilio Verify
- Rate limiting, resend cooldown, and reCAPTCHA supported
- Country flag selector and restriction options
- Store and normalize phone numbers in user profiles
- Works via shortcode or wp-login.php login provider interface

### User Switching

- Instantly switch between user accounts
- No logout/login cycles required

### Email Magic Link

- Single-use secure login links
- Clean modal with validation and success confirmation
- Friendly email template with clear CTA

### Activity Log

- Integrates with Simple History
- Track who logged in and how they authenticated

### Browser Extensions

- [Chrome Extension](https://chrome.google.com/webstore/detail/login-me-now-wordpress-lo/kkkofomlfhbepmpiplggmfpomdnkljoh)
- [Firefox Add-on](https://addons.mozilla.org/en-US/firefox/addon/login-me-now/)
- Uses encrypted JWT tokens for secure and fast access
- No passwords are stored in the extension

### Modules Hub (New)

- Toggle modules, integrations, and upcoming features from one dashboard
- Search, filter, and manage active, available, and upcoming modules
- Module state persists automatically

## Installation

	1. Install via the WordPress.org plugin repository or upload manually.
2. Activate the plugin.
3. Configure settings under “Login Me Now” in the WordPress dashboard.
4. (Optional) Install the Chrome or Firefox extension for one-click multi-site access.

## FAQ

	### Do I need the Chrome extension to create temporary login links?
No. The extension is optional. You can generate links directly inside WordPress.
### Does the plugin or extension have access to my passwords?
No. Passwords stay safely stored by WordPress. The plugin and extension never access them.
### Can I track temporary user activity?
Yes. With Simple History, you can track logins and interactions.
### Is the Email Magic Link secure?
Yes. All links are time-limited and single-use.
### How do I add Google or Facebook login buttons?
Use these shortcodes:

[login_me_now_google_button]

[login_me_now_facebook_button]
