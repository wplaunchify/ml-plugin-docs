# Stripe WooCommerce Extension

			Welcome to the documentation for the Stripe WooCommerce Extension! Here you can find all sorts of helpful information about accepting payments on your WooCommerce site via the Stripe extension. Please refer to the sections below for more information.

## What can the Stripe extension do?

[↑ Back to top](#doc-title)

Using a Stripe account, you can accept payments on your WooCommerce site without setup costs or monthly fees. You can offer the following payment methods:

- Credit and debit cards (American Express, Visa, MasterCard, and more!)
- Express checkouts such as [Apple Pay](https://www.apple.com/apple-pay/), [WeChat Pay](https://pay.wechat.com/en/index.shtml), and [Cash App Pay](https://cash.app/cash-app-pay)
- [Local payment methods](https://woocommerce.com/document/stripe/setup-and-configuration/additional-payment-methods/) such as Alipay, Boleto, SEPA, and more
- [Buy now, pay later](https://woocommerce.com/document/stripe/setup-and-configuration/additional-payment-methods/) methods such as Affirm, Afterpay, and Klarna
- Machine learning to order enabled payment methods using [Optimized Checkout Suite](https://woocommerce.com/document/stripe/admin-experience/optimized-checkout-suite/) for checkout.
- Customers can pay in their preferred currency via [Adaptive Pricing](https://woocommerce.com/document/stripe/admin-experience/optimized-checkout-suite/adaptive-pricing/)

**NOTE:**The fees for each transaction are determined exclusively by Stripe themselves. For pricing information, please visit [Stripe’s website](https://stripe.com/pricing).
