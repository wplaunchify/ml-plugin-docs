## How to make a Dynamic Search Results Title in Kadence

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/dynamic-search-results-title/](https://www.kadencewp.com/help-center/docs/kadence-theme/dynamic-search-results-title/)

When using Kadence Theme Kit Pro + Kadence Blocks Pro, you may find yourself in a situation where you wish to dynamically display the **Search Results Page Title**. This document will guide you on using dynamic content within Kadence properly to achieve this.

When adding a Hooked Element to a Search Results page, whether it is just a Content Section Element or an entire Template Element, you may need to grab the current search results information. In this case, you should use the **Page** **Title** **Dynamic** **Content** option.

![Dynamic Title](https://docs.nexcess.com/wp-content/uploads/2026/06/Dynamic-Title.jpg)

![Dynamic Search Results](https://docs.nexcess.com/wp-content/uploads/2026/06/Dynamic-Search-Results-1024x182-1.jpg)

As a result, when searching for specific terms, the Search Results For: text is predefined. Then, the searched term will follow.

*Note: This feature requires Kadence Theme Kit Pro for Hooked Elements and the Kadence Blocks Pro plugin to unlock Dynamic Content.*
