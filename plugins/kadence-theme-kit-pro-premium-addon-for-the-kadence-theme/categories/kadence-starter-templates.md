## Kadence Starter Templates

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/kadence-starter-templates/](https://www.kadencewp.com/help-center/docs/kadence-theme/kadence-starter-templates/)

The Kadence Starter Templates library provides a collection of professionally designed, fully coded website layouts that allow you to launch complete web projects with just a few clicks. Instead of starting from scratch with a blank page and spending hours configuring global fonts, spacing, and color palettes, you can import an entire cohesive site architecture directly into your WordPress dashboard. This workflow allows you to skip the tedious initial design phases and focus immediately on replacing placeholder text and images with your unique content.

The import interface gives you complete control over how you deploy these pre-made design libraries onto your server. You can choose to import a complete multi-page website layout—including pre-built home, about, services, and contact pages—or selectively pull in individual page layouts into an existing site. Additionally, you can swap global color schemes and typography families before executing the import to match your branding perfectly. Review the following setup guides to connect the template library, resolve import errors, and accelerate your development workflow.
