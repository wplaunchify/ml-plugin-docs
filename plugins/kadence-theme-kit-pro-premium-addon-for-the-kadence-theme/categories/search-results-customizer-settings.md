## Search Results Customizer Settings

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/search-results-customizer-settings/](https://www.kadencewp.com/help-center/docs/kadence-theme/search-results-customizer-settings/)

Use the **Kadence Theme Search Results Settings** to customize the Search Result *archive pages*. The **Search Result Settings** can be accessed from the **Customizer -> Search Results** settings.

![Search Results Example](https://www.liquidweb.com/wp-content/uploads/2025/05/Search-Results-Example-scaled.jpg)
## Title Settings

**Show Search Results Title:** This setting enables or disables the default Search Results Title.

**Search Results Title Layout:** Set the Search Result Title Layout to In Content or Above Content. The In Content option places the title inside the top of the content, while the Above Content option adds a Search Results Title Banner above the content. *(View examples.)*

**Container Width:** When using the Above Content Layout, set the container width to either Standard, Fullwidth, or Contained.

**Search Results Title Align:** Set an alignment for the title. This can be set to Left, Center, or Right.

**Container Min Height:** Add a minimum height to an Above Content Search Results Title container.![Search Results Title](https://www.liquidweb.com/wp-content/uploads/2025/05/Search-Results-Titler-491x1024.jpg)
## Archive Layout Settings

**Archive Layout:** Choose between Normal, Narrow, Fullwidth, or Left/Right Sidebar for the Search Results Archive layout.

- Normal – Uses the theme’s Content Width.- *(The Content Max Width can be set from the Customizer -> General -> Layout settings.)*
- Narrow – Creates a layout narrower than the standard theme content width, ideal for more compact designs.- *(The Narrow Layout Content Max Width can be set from the Customizer ->  General -> Layout settings.)*
- Fullwidth – Extends content to the full width of the page.- If using a Boxed Site Layout, this option may still respect the container width unless otherwise styled.- *(The Archive Grid Boxed Spacing can be adjusted from the Customizer -> General -> Layout settings.*)
- Left/Right Sidebar – Allows a sidebar to be added to the Search Archive. Choose between Sidebar 1 and Sidebar 2.- *(Sidebars can be designed from the Dashboard -> Appearance -> Widgets page.)*

**Post Archive Default Sidebar:** Set a default sidebar layout for Search Archive pages.

**Content Style:** Set the Search *Archive Content Style* to either Boxed or Unboxed. *(View the examples below.)*

**Search Result Columns**: Adjust the number of columns for displaying posts on Search Archive pages. This setting controls how many posts appear per row.![Search Archive Layout](https://www.liquidweb.com/wp-content/uploads/2025/05/Search-Archive-Layout.jpg)
## Search Item Elements

**Search Item Elements:** The Search Item Layout controls the Archive Loop items. For example, each post in a search archive displays elements such as a featured image, title, and META information. Each instance of this is a Search Item. Use the **Search Item Elements** option to control which elements appear on each Search Item, including the featured image, title, excerpt, META, and more. 

Below is an overview of each Search Item Element and the available options related to it.![Search Item Elements](https://www.liquidweb.com/wp-content/uploads/2025/05/Search-Item-Elements.jpg)*Use the Eye Icon to control the visibility of Search Item Elements.*
### Feature (Image)

**Set Image Ratio:** Adjust the featured image ratio for search items. The available options are:

- Inherit
- 1:1
- 4:3
- 3:2
- 16:9
- 2:1
- 4:5
- 3:4
- 2:3**Image is Link to Post:** Enable this option to make the featured image clickable, linking directly to the post.

**Set Image Size:** Set the featured image size for search items. Available options are:

- Thumbnail
- Medium
- Medium Large
- Large
- Full![Feature](https://www.liquidweb.com/wp-content/uploads/2025/02/Feature.jpg)
### Categories

**Choose a Divider:** Choose from one of the various Divider Styles. The Divider will be placed between categories whenever multiple categories exist.

**Choose a Style:** Choose a Category Style. This can be set to Normal, Pill, or Underline. See examples of these styles below.

### META

**Choose a Divider:** Set a Divider to place between different *META* items.

**Show Author:** Enable this to show the Post Author details.

**Enable Author Link:** Enable this to allow the Post Author Name to link to the Author Archive.

**Show Author Image:** Enable this to show the Author Profile Image. *(When this setting is enabled, you will be able to set an Image Max Width.)*

![Author Image Size](https://www.liquidweb.com/wp-content/uploads/2025/02/Author-Image-Size.jpg)**Author Label:** Set the Author Label. *(For example: By)*

**Show Date:** Enable this to show the Post Date.

**Show Time:** Enable this to show the Post Time.

**Updated Date Label:** Click on the Eye Icon to show and use a Date Label. Then, you can set the Label as preferred.

![Date Label](https://www.liquidweb.com/wp-content/uploads/2025/02/Date-Label.jpg)![Meta](https://www.liquidweb.com/wp-content/uploads/2025/02/Meta-432x1024.jpg)**Show Last Updated Date:** Enable this to show the Last Updated Date.

**Show Only If Different From Publish Date:** Enable this if you only want the Last Updated Date to show if the date differs from the original Published Date.

**Show Time:** Enable this option to also show the Post Last Updated Time along with the Date.

**Show Categories:** Enable this option to show the Post Categories inside the META information. *(See the image below.)*

**Show Comments:** Enable this option to show the Post Comments inside the META information. *(See the image below.)*

**Show Only If Post Has At Least One Comment:**Enable this option to hide the comment count from the META information if there is less than one comment on the post.

![Meta Sample](https://www.liquidweb.com/wp-content/uploads/2025/02/Meta-Sample.jpg)![Meta 2](https://www.liquidweb.com/wp-content/uploads/2025/02/Meta-2.jpg)

## Design Settings

**Design Tab:** At the top of the Customizer, go to the **Design** **tab** to adjust the styles of the archive page, including colors, fonts, and other visual settings.

### Search Results Title

**Title Color:** Set the Search Results Title color.

**Archive Title Background:** Set the Search Archive Title Background to either a Color, Gradient, or Image. *(See the GIF to the right.)*

**Background Overlay Color:** Set a Search Archive Title Background Overlay. This can be set to a Color or a Gradient.

**Border:** Select a Border for the Top and Bottom of the Search Results Title and/or the Left and Right sides. This initial icon will be an X. Click on the X to select a specific Border Style. You will also be able to select the Border Width*(px)*and Color once a Border Style is selected.![Search Results Title](https://www.liquidweb.com/wp-content/uploads/2025/05/Search-Results-Title.jpg)![Search Results Title](https://www.liquidweb.com/wp-content/uploads/2025/05/Search-Results-Title.gif)
### Archive Layout

**Search Item Title Font:** Adjust the Font Setting for Search Items. This includes the Font Color, Font Family, Font Style, and other font settings, such as the Text Transform, Line Height, and Letter Spacing. *(See the example GIF on the right.)*

**Item Category Colors:** Set the Search Item Category Colors for the Initial and Hover States.

**Item Category Font:** Adjust the Font Settings for the Search Item Category Text. This includes the Font Family, Font Style, and other font settings, such as the Text Transform, Line Height, and Letter Spacing. *(See the example GIF on the right.)*

**Item META Colors:** Adjust the META Colors for the Initial and Hover State.

**Item META Font:** Adjust the Item META Font Settings. This includes the Font Family, Font Style, and other font settings, such as the Text Transform, Line Height, and Letter Spacing. 
*(See the example GIF on the right.)*

**Site Background:** Set a Background Color for the Search Result Pages. This applies to the entire Site Background.

**Content Background:** Set a Content Background color for the Search Result Pages.
