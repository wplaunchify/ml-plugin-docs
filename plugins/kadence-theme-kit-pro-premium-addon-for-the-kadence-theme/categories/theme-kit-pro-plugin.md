## Kadence Theme Kit Pro Plugin

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/theme-kit-pro-plugin/](https://www.kadencewp.com/help-center/docs/kadence-theme/theme-kit-pro-plugin/)

The Kadence Theme Kit Pro plugin enhances the functionality of the free Kadence Theme by adding premium features such as Hooked Elements, Header Add-ons, and Conditional Headers.

To use **Kadence Theme Kit Pro** on your website, the **free Kadence Theme** must also be **installed** and **activated**, as *Kadence Theme Kit Pro* is an *extension* of the **free** **Kadence Theme**, not a replacement.

The Kadence Theme Kit Pro plugin is available in both the [Kadence Plus and Kadence Ultimate Plans](https://www.liquidweb.com/pricing/). You can also purchase the Kadence Theme Kit Pro plugin [individually](https://www.liquidweb.com/software/kadence/).

## Installing Kadence Theme Kit Pro

Once you have access to the Kadence Theme Kit Pro plugin, you can download it from your Kadence [Downloads & License](https://software.liquidweb.com/) page.

![Downloads and licenses](https://www.liquidweb.com/wp-content/uploads/2021/05/Downloads-and-licenses-1024x601.jpg)You will see Kadence Theme Pro listed in your Products list. You can click on the Download button to download the Kadence Theme Pro Zip. Be sure to leave the file compressed and don’t unzip it.

![Download Kadence Theme Pro](https://res.cloudinary.com/lwcom/images/w_1024,h_572,c_scale/f_auto,q_auto/v1780354961/prod/Download-Kadence-Theme-Pro/Download-Kadence-Theme-Pro.jpg?_i=AA)Next, navigate to your WordPress Dashboard and go to Plugins -> Add New Plugin. At the top of the Add New Plugin page, click on the **Upload** **Plugin** button.

![Upload Kadence Blocks Pro](https://www.liquidweb.com/wp-content/uploads/2022/07/Upload-Kadence-Blocks-Pro-scaled.jpg)Then, click the **Choose** **File** button and select your Kadence Theme Kit Pro zip file. Once you have selected the file, click the **Install** **Now** button.

![](https://res.cloudinary.com/lwcom/images/w_1023,h_309,c_scale/f_auto,q_auto/v1780354957/prod/Install-Kadence-Pro/Install-Kadence-Pro.jpg?_i=AA)Once the plugin is installed, click the blue **Activate** **Plugin** button to activate your plugin. Now your Kadence Theme Kit Pro plugin is activated on your website.

## Enable Addons

Once you have the Kadence Theme Kit Pro plugin activated, you can toggle on any of the addons you’d like to activate. These include:

- **Header Addons.** Adds [20 elements](https://www.liquidweb.com/docs/kadence-theme/header-addons/) to the header builder.
- **Conditional Headers.** [Build Extra Headers to display conditionally](https://www.liquidweb.com/docs/kadence-theme/how-to-use-conditional-header/).
- **Ultimate Menu.**Adds menu options for[mega menus](https://www.liquidweb.com/docs/kadence-theme/how-to-create-a-mega-multicolumn-menu/), highlight tags, icons and more.
- **Header/Footer Scripts.** Adds options into the WordPress Customizer to add [header and footer scripts](https://www.liquidweb.com/docs/kadence-theme/how-to-add-scripts-in-header-footer/).
- **Hooked Elements.** Add [content anywhere](https://www.liquidweb.com/docs/kadence-theme/how-to-use-element-hooks/) into your site conditionally. This is what you’ll need for [Kadence Elements Templating](https://www.liquidweb.com/knowledge-base/kadence-theme/kadence-elements/).
- **WooCommerce Addons.** Adds new options into the customizer for WooCommerce stores.
- **Infinite Scroll.** Adds infinite scrolling for archive pages.
- **Color Palette Switch (Dark Mode).** Adds a color palette switch so you can [create a dark mode](https://www.liquidweb.com/docs/kadence-theme/how-to-use-the-color-palette-switch-dark-mode/) for your website.
- **Local gravatars.** Local gravatars from your servers to improve site performance.
- **Archive custom settings.** Allows you to [assign custom display settings for taxonomies](https://www.liquidweb.com/docs/kadence-theme/archive-custom-settings-kadence-theme-kit-pro/).
