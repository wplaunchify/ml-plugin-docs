## Editing a Row in the Header

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/editing-a-row-in-the-header/](https://www.kadencewp.com/help-center/docs/kadence-theme/editing-a-row-in-the-header/)

Each row in the Kadence Theme header can be edited with custom settings. For example, you can set a custom background or specific row minimum height.  You can access these settings by clicking on the settings toggle beside the row name in the editor.

### Layout

There are three options for the header row layout: **Standard**, **Fullwidth**, and **Contained**.

- The **Standard** layout will show the background in full width but the header row contents will be contained (*this follows the content’s maximum width*).
- The **Fullwidth** layout will show the background and content in full width.
- The **Contained** layout will make both background and content follow the content’s maximum width.
