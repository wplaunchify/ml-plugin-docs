## Installing and Creating Kadence Elements

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/installing-kadence-elements/](https://www.kadencewp.com/help-center/docs/kadence-theme/installing-kadence-elements/)

Kadence Elements is a feature available in the [Kadence Theme Kit Pro plugin](https://www.kadencewp.com/kadence-theme/theme-kit-pro/). This plugin extends the functionality of the free Kadence Theme.

To create a **Hooked Element**, you must first install, activate, and license the *Kadence Theme Kit Pro*plugin. ([Click here to learn more](https://docs.nexcess.com/software/kadence/theme/theme-kit-pro-plugin/).) Once the *Theme Kit Pro plugin* is activated on the website, navigate to the **Dashboard -> Appearance -> Kadence** page and enable the **Hooked** **Elements** option.

![Enabled Hooked Elements](https://docs.nexcess.com/wp-content/uploads/2026/06/Enabled-Hooked-Elements-scaled-1.jpg)

Once finished, either click the Customize button or manually navigate to the new **Dashboard -> Appearance -> Kadence -> Elements** page. At the top of the page, click the **Add New Element** button to begin creating your first Element.

![Add New Element](https://docs.nexcess.com/wp-content/uploads/2026/06/Add-New-Element.jpg)

You will be prompted to select an **Element** **Type** when creating a new *Element*.

![New Element Setup](https://docs.nexcess.com/wp-content/uploads/2026/06/New-Element-Setup.jpeg)

[Click here](https://docs.nexcess.com/software/kadence/theme/types-of-elements/) to learn about the *Four Kadence Element Types* and what each one can do.
