## Header Addons

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/header-addons/](https://www.kadencewp.com/help-center/docs/kadence-theme/header-addons/)

**Header Addons** is one of the features that you can add in Kadence by installing, activating, and licensing the [Kadence Theme Kit Pro plugin](https://docs.nexcess.com/software/kadence/theme/theme-kit-pro-plugin/).

![Header Addons in Kadence Pro](https://docs.nexcess.com/wp-content/uploads/2026/06/header-addons-kadence-pro.png)

To use the header addons, click on the **Customize** link under **Header** **Addons** or visit the WordPress Customizer via the admin menu link under Appearance or the WP toolbar link on the front end.

Go to the **Header** section.

These are the additional header items that Header Addons comes with:

- [Account](https://docs.nexcess.com/software/kadence/theme/add-a-login-and-account-menu/)
- HTML 2
- Third Navigation
- Fourth Navigation
- Divider
- Divider 2
- Divider 3
- Search Bar
- Widget area
- [Contact](https://docs.nexcess.com/software/kadence/theme/add-contact-information/)
- Button 2
- [Toggle Widget Area](https://docs.nexcess.com/software/kadence/theme/add-toggle-open-menu-for-desktop/)
- Mobile Navigation 2

For a complete overview of all of the Free and Premium Header Items, [click here](https://docs.nexcess.com/software/kadence/theme/classic-header-items/).

![Header Addons](https://docs.nexcess.com/wp-content/uploads/2026/06/Header-Addons.jpeg)Header Addons

```
Note: Not all items are available in Desktop and Tablet/Mobile views.
```

To add one or more of these items to your site’s header, drag the item(s) onto the header builder and configure them to your liking.
