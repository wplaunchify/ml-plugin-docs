## Kadence Infinite Scroll

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/infinite-scroll/](https://www.kadencewp.com/help-center/docs/kadence-theme/infinite-scroll/)

The **Kadence Infinite Scroll** feature is a powerful feature within **Kadence** **Theme** **Kit** **Pro**, designed to enhance the user experience on your archive pages (like your blog, search results, or shop). It dynamically loads new posts as the user scrolls, eliminating the need to click standard pagination links.

![Infinite Scroll GIF](https://res.cloudinary.com/lwcom/images/w_1024,h_575,c_scale/f_auto,q_auto/v1780351811/prod/Infinite-Scroll-GIF/Infinite-Scroll-GIF.gif?_i=AA)The Infinite Scroll feature is available in Kadence Theme Kit Pro. This plugin must be active on the website to access this feature. [Click here to learn about activating Theme Kit Pro.](https://www.liquidweb.com/docs/kadence-theme/kadence-theme-pro-addon/)

## 1. Enabling Infinite Scroll

Once Kadence Theme Kit Pro is active on the website, navigate to the **Dashboard -> Appearance -> Kadence Page** and enable the **Infinite Scroll Box**.

![Enable Infinite Scroll](https://www.liquidweb.com/wp-content/uploads/2025/10/Enable-Infinite-Scroll-scaled.jpg)- After enabling, you can click the **Customize** link to be taken directly to the settings.
- Alternatively, you can navigate manually via the WordPress Customizer: **Appearance > Customize > General > Infinite Scroll**.

Learn more about the configurable Infinite Scroll settings below.

## 2. Configuring Infinite Scroll Settings

From the **Appearance > Customize > General > Infinite Scroll** settings, you will be able to configure how Infinite Scroll works on your website. This consists of toggleable settings and the option to set an end-of-content text. Use the toggles to enable/disable Infinite Scroll on different post types.

**Infinite Scroll for Blog:** Enable this option to use Infinite Scroll on all post archives. 
*(The default WordPress post type)*

**Infinite Scroll for Search:** Enable this option to use Infinite Scroll on search results archives.

**Infinite Scroll for Products:**Enable this option to use Infinite Scroll on Products.
**Infinite Scroll for Custom Post Types:** Enable this option for Infinite Scroll to work on all custom post type archives.
**End of Content Text:** This setting allows you to set a message for when the end of the archive content is met.![Infinite Scroll](https://res.cloudinary.com/lwcom/images/w_708,h_1024,c_scale/f_auto,q_auto/v1780351862/prod/Infinite-Scroll/Infinite-Scroll.jpg?_i=AA)Once finished, the Infinite Scroll function will be added to the appropriate **Post Type Archive Pages**.
