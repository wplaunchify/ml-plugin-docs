## The Kadence Theme Breadcrumb Settings

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-theme/theme-breadcrumb-settings/](https://www.kadencewp.com/help-center/docs/kadence-theme/theme-breadcrumb-settings/)

When using the Kadence Theme, you have the option to utilize *Kadence Breadcrumbs*. The Kadence Theme offers a standard way to present Breadcrumbs across your website. This allows users to easily navigate across posts, categories, and pages.

![Example Breadcrumbs](https://docs.nexcess.com/wp-content/uploads/2026/06/Example-Breadcrumbs.jpg)

*If you are using a Kadence Element, you can present the breadcrumbs by using the Kadence Breadcrumbs Shortcode. Click here to learn more.*

Theme Breadcrumb Settings

You can access the **Kadence** **Breadcrumb** **Settings** from the **Customize -> General -> Breadcrumbs**settings.

![Breadcrumbs](https://docs.nexcess.com/wp-content/uploads/2026/06/Breadcrumbs.jpg)

Breadcrumb Engines

In some cases, you can control breadcrumbs using SEO-related plugins. 

The Kadence Theme also supports using breadcrumbs from other sources, such as **Yoast**, **RankMath**, and **SEOPress**. *(To use a different breadcrumb engine, you must have the plugin preinstalled on your website.)*

![Breadcrumb Engine](https://docs.nexcess.com/wp-content/uploads/2026/06/Breadcrumb-Engine.jpg)
