# How to Hide a Menu Without Preventing Access

                    
                    Usually, when you hide a menu item, it also blocks access to the corresponding admin page. Sometimes that’s not what you want. There is a way to remove a link from the admin menu without making it inaccessible. Here’s how:

1. Select a role or a user.

![](https://adminmenueditor.com/wp-content/uploads/2017/12/click-to-select-role-narrow.png)
2. Select a menu item.

![](https://adminmenueditor.com/wp-content/uploads/2018/01/select-menu-hide-cosmetic.png)
3. Click the “hide without preventing access” toolbar button.

![](https://adminmenueditor.com/wp-content/uploads/2018/01/cosmetic-hide-button.png)

### Tips

- To un-hide the item, click the same button again.
- You can hide an item from all roles and users (including yourself) by selecting the “All” option first.
- Hiding a menu item in this way doesn’t change its permissions. You can still [allow/deny access](https://adminmenueditor.com/documentation/how-to-hide-a-menu-item/) by using menu checkboxes or the “Permissions” dialog.
