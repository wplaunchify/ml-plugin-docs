## How to Move from Tag Groups Free to Pro

**Source:** [https://taxopress.com/docs/tag-groups-free-pro/](https://taxopress.com/docs/tag-groups-free-pro/)

The Tag Groups plugin has a Free and Pro version:

- The Free version is on WordPress.org.
- The Pro version is behind a paywall on this website, for TaxoPress members.

You are using the Free version if you see a message like this in your WordPress admin area:

If you have the Free version of Tag Groups installed, [follow these steps to update to the Pro version](https://taxopress.com/docs/installation-pro/):

- Download the Pro version from your TaxoPress account.
- Go to the “Plugins” screen in your WordPress site.
- Click “Add New”.
- Install the Pro version of Tag Groups.

This upgrade is 100% safe and you will not lose any data or settings.

## How to Install Tag Groups Pro

**Source:** [https://taxopress.com/docs/installation-pro/](https://taxopress.com/docs/installation-pro/)

Thank you for purchasing the Tag Groups Pro plugin.

The Pro version of Tag Groups replaces the Free version. So in this guide, we’ll show you how to install Tag Groups Pro and disable the Free version if you have it installed.

---

## How to download the Tag Groups plugin

You should have received a download link to the plugin. It is also possible to download the latest version of the plugin from TaxoPress.com.

- Go to the “[Account](https://taxopress.com/your-downloads/)” area of TaxoPress.com.
- Click “View Details and Downloads”.

- On the next screen, you’ll find a download link under the “Products” heading.
- You will have a .zip file downloaded to your desktop.

---

## How to install the Tag Groups plugin

The next step is to upload the .zip file to your WordPress site.

- Go to “Plugins” in your WordPress site.
- Click “Add New”.

- Click “Upload Plugin”.
- Click “Choose File”
- Select the .zip file that you downloaded.
- Click “Install Now”.

- Click “Activate Now”.
- Click “Activate” for Tag Groups Pro. If you have the Free version installed, that will be automatically deactivated when the Pro version is activated.

## Introduction to Tag Groups

**Source:** [https://taxopress.com/docs/introduction-tag-groups/](https://taxopress.com/docs/introduction-tag-groups/)

Welcome to the Tag Groups plugin!

Tag Groups allow you to organize your WordPress tags in groups.

The Tag Groups plugin allows you to show tags in clouds, tabs, accordions, tables, lists and much more. You can customize your term displays with a huge number of options and use them in posts, pages, blocks, or shortcodes.

## What are Tag Groups?

Tag Groups are like containers that contain tags. These groups have IDs, names and an order in which they appear in tag clouds and in menus.

This screenshot below shows a real example. “Place” is a Tag Group that contains tags such as “Alps”, “France”, “Germany”, and “Paris”. Using a group allows these tags to be displayed together. “Subject” is another Tag Group and contains tags such as “animals”, “castle”, and “park.

This example uses the Toggle Post Filter. Visitors can select tags and see a list of posts that match their search criteria. [Click here to see a Toggle Post Filter demo.](https://demo.taxopress.com/post-filter-tags-menu/)

This next screenshot is another example using Tag Groups. “Year” is a Tag Group that contains tags such as “2012, “2019, and “2021”.

This examples uses the Shuffle Box feature. This is a tag cloud that allows you to filter the tags by their names or by their Tag Groups. [Click here to see a Shuffle Box demo](https://demo.taxopress.com/shuffle-box/).

## First Steps With Tag Groups

**Source:** [https://taxopress.com/docs/first-steps-tag-groups/](https://taxopress.com/docs/first-steps-tag-groups/)

Follow these steps to start using the Tag Groups plugin for the first time. After installing the plugin, this guide will get you started with Tag Groups.

---

## Step #1. Select the Taxonomies

The plugin creates a new menu called **Tag Groups**. First you should go to the **Taxonomies** sub-menu.

Select the taxonomy that you want to organize in groups. The default is **Tags** (post_tag), which is the default taxonomy that people mean when they talk about “WordPress tags”.

- Don’t select more taxonomies than you actually want to use with that plugin.
- Don’t select more than one taxonomy from each post type. You can see the post type when hovering your mouse over a taxonomy.
- Avoid using hierarchical taxonomies, such as categories. Hierarchical taxonomies are not officially supported, but you can experiment with them if you like.

After you have saved your changes, a new submenu **Tag Groups Admin** will appear under the menu of that chosen post type. For Tag (post_tag), you find the **Tag Groups Admin** menu under **Posts**.

---

## Step #2. Create and Edit Tag Groups

The next step is to create groups. Before you have any tag groups, you cannot assign your tags to them.

![](data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMSIgaGVpZ2h0PSIxIiB4bWxucz0iaHR0cDovL3d3dy53My5vcmcvMjAwMC9zdmciPjwvc3ZnPg==)

- Create a new group below a row by clicking on the plus icon.
- Click on the trash icon to delete a group.
- Click on an arrow to move a group up or down. The order is relevant for displaying groups in tag clouds.
- Drag and drop a group to a new position.
- Click into a name to edit it.
- Click on the number of tags to go to the list of tags, filtered by the selected group.
- Click on the paper sheets icon to go to the list of posts, filtered by the selected group.

You can always come back later and add, rename and reorder the groups.

Deleting a group will not delete any tags, but mark them as “unassigned”.

---

## Step #3. Assign Tags

Next, go to the tags (or your chosen taxonomy) and assign them to groups. By default, each tag is unassigned (group ID 0). In the free version each tag can be assigned only to *one* group.

There are several ways how to assign tags to groups or unassign them.

1. When you create a new tag, select the group in the drop-down menu.
2. Click on an existing tag and on the edit screen select the group in the drop-down menu.
3. Click on “Quick Edit” under the tag in the list and select the group in the drop-down menu.
4. Change multiple tags in one go with the “Bulk Actions” menu.

## How to Install Tag Groups Free

**Source:** [https://taxopress.com/docs/installation/](https://taxopress.com/docs/installation/)

The installation of the free version of the Tag Groups plugin is straightforward. It can be installed using the same process as for other plugins on WordPress.org. Please follow these steps:

- Go to “Plugins” then “Add New”.
- Search for “Tag Groups” and click “Install Now”.

Alternatively, you can click on “Upload Plugin” and then upload the [ZIP file](https://wordpress.org/plugins/tag-groups/). Or you upload the unzipped 
```
tag-groups
```

 folder to the 
```
/wp-content/plugins/
```

 directory. If you upload the unzipped files directly to your server, you may have to fix the file permissions for css and js files.

- Click on “Activate”.
