## Custom Order for Tags and Categories

This TaxoPress Pro feature can control the order of Tags and Categories. The order you choose will display when you’re editing posts, and in frontend displays.

Go to the “[Taxonomies](https://taxopress.com/docs/taxonomies-admin-area/)” screen and choose the taxonomy you want to order. There are five choices:

- ID
- Name
- Counter
- Random
- Term Order

![Custom taxonomy order](https://taxopress.com/wp-content/uploads/2025/07/order-taxonomy-1024x516.png)order taxonomy

If you click on the “Taxonomy Terms Table” you’ll be to reorder your terms using a drag-and-drop interface.

![Reorder your terms using a drag-and-drop interface](https://taxopress.com/wp-content/uploads/2025/07/drag-drop-order-1024x710.png)drag drop order

This “Term Order” feature is also available throughout the plugin. For example, in the “[Terms Display](https://taxopress.com/docs/taxopress/tag-clouds/)” feature, you can now choose to sort the terms using the order. As you can see in this screenshot below, we’ve solved the problem with the magazine issue numbers.

![Custom taxonomy order in Terms Display](https://taxopress.com/wp-content/uploads/2025/07/term-order-term-display-1-1024x590.png)term order term display

## Taxonomies: Post Types

**Source:** [https://taxopress.com/docs/taxonomies-post-types/](https://taxopress.com/docs/taxonomies-post-types/)

This guide will show you how to assign your WordPress taxonomies to different post types. You can find this by visiting [the Taxonomies screen](https://taxopress.com/docs/introduction-taxonomies-screen/) and editing a taxonomy.

If you check the box for a post type, your taxonomy will be attached to that post type.

By default, many archive pages for post types will only show one taxonomy. If you check the box “Archive page result”, you will be able to show multiple taxonomies on the the archive pages.

![Taxonomies: Post Types](https://taxopress.com/wp-content/uploads/2021/04/edit-taxonomy-post-types.png)edit taxonomy post types

## Taxonomies: Deactivate or Delete

**Source:** [https://taxopress.com/docs/taxonomies-deactivate-or-delete/](https://taxopress.com/docs/taxonomies-deactivate-or-delete/)

This guide will show you how to remove or deactivate taxonomies. You can find this by visiting [the Taxonomies screen](https://taxopress.com/docs/introduction-taxonomies-screen/) and editing a taxonomy.

Please note that this feature is limited in several ways:

- You can not delete the Tags and Categories taxonomies because they are core features of WordPress.
- You can not delete taxonomies from a third party plugin such as WooCommerce.

For these special taxonomies, you can only click “Deactivate Taxonomy” as in the screenshot below. You will see a message saying “Taxonomy has been successfully deactivated”. You will then see a button saying “Re-activate Taxonomy”.

![The "Deactivate Taxonomy" button](https://taxopress.com/wp-content/uploads/2021/04/delete-1024x221.png)

For any taxonomy that you created with TaxoPress, you will have the option to deactivate or delete the taxonomy.

![The "Deactivate Taxonomy" and "Delete Taxonomy" buttons](https://taxopress.com/wp-content/uploads/2021/04/deactivate-1024x337.png)

If you click “Delete Taxonomy”, TaxoPress will ask to confirm your decision:

![Box asking to confirm that you want to delete this.](https://taxopress.com/wp-content/uploads/2021/04/taxopress-confirm-delete.png)

## Taxonomies: Admin Area

**Source:** [https://taxopress.com/docs/taxonomies-admin-area/](https://taxopress.com/docs/taxonomies-admin-area/)

This guide will show you how to change the “Admin Area” options for your taxonomies. You can find this by visiting [the Taxonomies screen](https://taxopress.com/docs/introduction-taxonomies-screen/) and editing a taxonomy.

These five settings control how your taxonomy appears in the WordPress admin area:

- **Show user interface**: Should there be a visible interface in the WordPress admin area to manage these terms?
- **Show in admin menus**: Should there be links to this taxonomy in the WordPress admin menus?
- **Show in frontend menus**: Should this taxonomy be available for the frontend “Menus” and “Navigation” options?
- **Show admin column**: Should a column for this taxonomy appear on screens such as “Posts” and “Pages”?
- **Show in “Quick Edit” and “Bulk Edit”**: Should this taxonomy be available in editing tools on screens such as “Posts” and “Pages”?
- **Show in Filter**: Should this taxonomy be available in filters on screens such as “Posts” and “Pages”?

![Edit taxonomy admin area](https://taxopress.com/wp-content/uploads/2021/04/edit-taxonomy-admin-area.png)edit taxonomy admin area

## Media Tags

**Source:** [https://taxopress.com/docs/media-tags/](https://taxopress.com/docs/media-tags/)

TaxoPress provides a “Media Tags” taxonomy so you can organize your Media Library.

You can edit the settings for Media Tags by visiting [the “Taxonomies” screen](https://taxopress.com/docs/introduction-taxonomies-screen/). You can see this taxonomy under the “Media” menu in your WordPress dashboard.

![Media Tags in the TaxoPress plugin](https://taxopress.com/wp-content/uploads/2021/04/media-tags.png)

## Introduction to the Taxonomies Screen

**Source:** [https://taxopress.com/docs/introduction-taxonomies-screen/](https://taxopress.com/docs/introduction-taxonomies-screen/)

The “Taxonomies” screen will show all the taxonomies created by WordPress and your plugins and themes.

On this screen, you can also click “Add New” and create your own taxonomies.

![Edit taxonomies Screen](https://taxopress.com/wp-content/uploads/2021/04/taxonomies-screen-1024x445.png)taxonomies screen

When you click “Edit”, you’ll be able to change the settings for each taxonomy. For example, you can change the visual labels or control whether the taxonomy is organized in parent-child relationships. Here, you can also describe what your taxonomy is used for. Here you also can set the default terms for this taxonomy and enter the term names or slugs.

![Edit taxonomy screen](https://taxopress.com/wp-content/uploads/2021/04/edit-categories-main-1024x613.png)edit categories main

In the “Post Types” area, you can assign any taxonomy to any post type, including your Media Library. On this screen you can also opt to show content from all post types on archive page.

![Edit taxonomies - post type](https://taxopress.com/wp-content/uploads/2021/04/edit-taxonomy-post-types-1024x606.png)edit taxonomy post types

Inside each taxonomy, you’ll find many useful settings. For example, in the “Admin Area” settings, you can control how your taxonomy appears in your WordPress dashboard.

![Edit taxonomy admin area](https://taxopress.com/wp-content/uploads/2021/04/edit-taxonomy-admin-area.png)edit taxonomy admin area
