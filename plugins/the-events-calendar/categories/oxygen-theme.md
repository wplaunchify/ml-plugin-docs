## Using Oxygen Page Builder with The Events Calendar

**Source:** [https://docs.nexcess.com/software/the-events-calendar/oxygen-theme/](https://docs.nexcess.com/software/the-events-calendar/oxygen-theme/)

Many of our users use the [Oxygen builder](https://oxygenbuilder.com) and its accompanying theme with our plugins. Sometimes they don’t work together seamlessly, but with a few tweaks, your single event page and your main calendar page will play together nicely with Oxygen.

If you are using our legacy calendar views, make sure to [enable the updated calendar views](https://theeventscalendar.com/knowledgebase/k/enabling-updated-calendar-views/?id=legacyviews) under **Events →** **Settings → Display.**

Next, make sure that you choose the **Default Events Template** option.

![The events display setting page with the Events template option highlighted in red as well as the option to use updated calendar designs when using the oxygen page builder.](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2021-07-12-at-10.08.10-AM.jpg)

From there, you can create a new template with Oxygen and [add the code provided in this handy tutorial on the Oxygen website](https://classic.oxygenbuilder.com/tutorial/how-to-setup-the-events-calendar-with-oxygen/).
