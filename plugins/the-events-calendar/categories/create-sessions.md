## Creating Sessions in Event Schedule Manager

**Source:** [https://docs.nexcess.com/software/the-events-calendar/create-sessions/](https://docs.nexcess.com/software/the-events-calendar/create-sessions/)

Sessions are the building blocks of your event schedule, as demonstrated in the [[New User Primer](https://docs.nexcess.com/software/the-events-calendar/event-schedule-manager/)].

## Creating Sessions

You can create sessions in both the Classic and Block Editor as seen below. The following are the Essential fields to creating a Session.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/EssentialFields.jpg)Essential Fields in Creating a Session

1. The title of the Session
2. The Session’s description
3. You can choose whether the Speaker or Speakers are displayed with a typed name, or via the Speakers Custom Post Type. The [Speakers](https://docs.nexcess.com/software/the-events-calendar/create-speakers/) KB article explains the difference between the two.
4. The names of the Speakers presenting the Session
5. You can add one or multiple [Sponsors](https://docs.nexcess.com/software/the-events-calendar/create-sponsors/) to a session. You can also drag and drop them to change their order.
6. The date and time a session will take place.
7. There are three types of Sessions. Regular, mainstage, and break&lunch. Mainstage sessions will be highlighted differently than regular and break sessions. Break&Lunch sessions are plain text.
8. You can select which Tracks a session will be a part of. You can also Add Tracks.
9. You can choose which location a Session will take place. For example, rooms that have specific names. You can also Add Locations from this area.
10. You can add a Featured Image to make the Session stand out.

## Displaying Sessions in context (aka schedule)

Once you created all of the sessions you need for your schedule, it’s time to display them on a page or post. This can be done in one of two ways:

Using the [[tec_schedule] shortcode](https://docs.nexcess.com/software/the-events-calendar/schedule-shortcodes/) and its many, many parameters.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Screenshot-2023-11-07-at-14-56-14-Edit-Page-Schedule-‹-The-Events-Calendar-Complete-Collection-—-WordPress.jpg)Displaying the Schedule using the Schedule Shortcode

Or, using the schedule block (block editor)

![Event Schedule Manager block](https://docs.nexcess.com/wp-content/uploads/2026/06/ESMScheduleBlock.jpg)Displaying the Schedule using the Schedule Block

## Adding multiple Speakers to a Session

To add multiple **Speakers** to a **Session**, repeat the normal process you used to add the first speaker:

1. [Create Speakers](https://docs.nexcess.com/software/the-events-calendar/create-speakers/) under **Schedule > Speakers** and add the necessary information for each.
2. Add a new session or edit an existing one.
3. Select **Speakers** under the **Session Information** section. Click into the **Speakers** box to select as many **Speakers** as you’d like, repeating for each one. You can drag the added **Speakers** to reorder them.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-1-3.jpg)Add Speakers to a Session
