## RSVP Event Website Setup Guide

**Source:** [https://docs.nexcess.com/software/the-events-calendar/rsvp-event-website-setup-guide/](https://docs.nexcess.com/software/the-events-calendar/rsvp-event-website-setup-guide/)

In this guide, we’ll walk you through the steps you need to create an RSVP event website from start to finish.

You can use this guide for these types of RSVP websites, for example:

- Weddings
- Birthday parties
- Church events
- Conferences that don’t require a fee
- Religious gatherings
- Funerals or memorials
- Author signings or readings
- Corporate trainings or lunches
- Family or school reunions
- Graduations
- Holiday events

Check out [our blog post](https://theeventscalendar.com/blog/tips/create-a-custom-rsvp-website-in-wordpress/) on RSVP website creation for inspiration.
