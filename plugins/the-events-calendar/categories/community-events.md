## Getting Started with Community Events and Tickets

**Source:** [https://docs.nexcess.com/software/the-events-calendar/community-events/](https://docs.nexcess.com/software/the-events-calendar/community-events/)

Ready to get started with Community Events? We’ve got you covered! The steps below will help you get set up and ready to use your calendar’s new add-on features.

If you are new to our core plugin, The Events Calendar, you’ll want to make sure to [familiarize yourself with it](https://docs.nexcess.com/software/the-events-calendar/events-calendar/) before continuing here.

1. [Download and install the plugin](https://docs.nexcess.com/software/the-events-calendar/downloading-and-installing-the-plugin/). Don’t forget that all of our paid add-ons require The Events Calendar to be installed and active as well.

2. If you’ve just purchased Community Events, the license key will be automatically added for you. Just in case you don’t have the license activated, see our guide on how to [input your license key](https://docs.nexcess.com/software/the-events-calendar/finding-and-inputting-your-license-key/). The plugin will work without the license key, but you’ll need it for automatic updates when a new version is released. Need updates on both your dev site and your live site? [We can do that](https://docs.nexcess.com/software/the-events-calendar/using-one-license-for-live-and-dev-sites/).

3. [Configure your settings](https://docs.nexcess.com/software/the-events-calendar/community-settings/). Choose from our many options so that Community Events works just how you want it.

4. [Add a link to your event submission page](https://docs.nexcess.com/software/the-events-calendar/community-events/) so that users can submit their events.

5. Make sure you know how to [manage submitted events](https://docs.nexcess.com/software/the-events-calendar/community-events/) so that you’re ready when the events start rolling in.

6. Use [shortcodes](https://docs.nexcess.com/software/the-events-calendar/community-shortcodes/) to embed Community Events in custom locations throughout your site.

Hooray! Community Events is now up and running! You can stop there or further tailor the plugin with the options below.

- [Integrate with your site’s theme](https://docs.nexcess.com/software/the-events-calendar/)
- Integrate with [Virtual Events](https://theeventscalendar.com/products/wordpress-virtual-events/) to enable virtual event submissions from your community.
- [Require specific fields on the event submission form](https://theeventscalendar.com/knowledgebase/k/required-fields-for-events-submission-form/)
- [Modify the Community Events page titles](https://docs.nexcess.com/software/the-events-calendar/community-events/)

If you run into trouble or need help, you can head to our [troubleshooting page](https://theeventscalendar.com/knowledgebase/category/errors/) or post to our [Help Desk](https://support.theeventscalendar.com/submit_ticket).
