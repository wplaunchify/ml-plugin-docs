## How to Add a Shortcode in WordPress

**Source:** [https://docs.nexcess.com/software/the-events-calendar/how-to-add-a-shortcode-in-wordpress/](https://docs.nexcess.com/software/the-events-calendar/how-to-add-a-shortcode-in-wordpress/)

With [Events Calendar Pro](https://theeventscalendar.com/products/wordpress-events-calendar/), you can [add calendar content](https://theeventscalendar.com/knowledgebase/k/inserting-calendar-content-into-posts-or-pages/) to any WordPress page or post. There are a few different methods that you can use to add a shortcode to your WordPress site, and we’ll show you how to do it below.

## Add a shortcode with the Block Editor

To add a shortcode using the Block Editor, you’ll want to head over to any new page or post by selecting Pages (or Posts) > Add New.

From there, choose the + sign to add a block, then search for the “shortcode” block.

![add a shortcode with the block editor](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-09-12-at-12.14.15-PM.jpg)

Then, enter the shortcode you’d like to use in the field provided and click Publish.

![add a shortcode using the Block Editor](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-09-12-at-12.15.45-PM.jpg)

## Add a shortcode with the Classic Editor

If you are using the Classic Editor, add the shortcode to the area of the post or page where you’d like to see it using the Text tab. Don’t forget to Publish or Update the post when you’re done!

![add a shortcode using the classic editor](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-09-12-at-12.21.54-PM.jpg)

## Add shortcode to WordPress sidebar widgets

To add a shortcode to a WordPress sidebar widget, head over to Appearance > Widgets. Then, search for a shortcode widget block and add it to the sidebar with your desired shortcode.

![add a shortcode to widget area](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-09-12-at-1.28.20-PM.jpg)

## Add shortcode to WordPress theme files

Lastly, you can add a shortcode right in your WordPress theme files. To do this, add the following shortcode to any WordPress template file.

```
<?php echo do_shortcode("[your_shortcode]"); ?>
```

## Do more with shortcodes!

Now that you know how to add a shortcode to your site, check out our [Shortcode Resources](https://docs.nexcess.com/software/the-events-calendar/shortcodes/) to use shortcodes with The Events Calendar plugins.
