## System Requirements

**Source:** [https://docs.nexcess.com/software/the-events-calendar/what-are-the-system-requirements-for-your-plugins/](https://docs.nexcess.com/software/the-events-calendar/what-are-the-system-requirements-for-your-plugins/)

Each of our plugins has its own system requirements but in general, this is what they expect:

- PHP 7.4 and above
- WordPress 6.6 and above

WordPress.org has some great info about the system requirements for WordPress Core, which you can read [here](http://wordpress.org/about/requirements/).
