## The Events Calendar System Requirements

**Source:** [https://docs.nexcess.com/software/the-events-calendar/system-requirements/](https://docs.nexcess.com/software/the-events-calendar/system-requirements/)

Each of our plugins has its own system requirements but in general, this is what they expect:

- PHP 7.4 and above
- WordPress 6.2.0 and above
- jQuery 3.5 and above
- HTTPs

WordPress.org has some great info about the system requirements for WordPress Core, which you can read [here](http://wordpress.org/about/requirements/).
