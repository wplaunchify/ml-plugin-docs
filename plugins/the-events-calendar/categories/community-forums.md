## WordPress.org Support Forums

**Source:** [https://docs.nexcess.com/software/the-events-calendar/community-forums/](https://docs.nexcess.com/software/the-events-calendar/community-forums/)

A number of our core plugins are freely available on [WordPress.org](https://wordpress.org/plugins/). In each case, there is also a community forum where you can ask questions and get help from the community.

If you require technical support and do not currently have a license key for one of our other products, we recommend you use those forums to seek help — as we are generally unable to provide technical support to non-license key holders here on the Help Desk.
- [The Events Calendar](https://wordpress.org/support/plugin/the-events-calendar/)
- [Event Tickets](https://wordpress.org/support/plugin/event-tickets/)
- [Image Widget](https://wordpress.org/support/plugin/image-widget)
- [Advanced Post Manager](https://wordpress.org/support/plugin/advanced-post-manager)

Though we monitor all of the above forums, we are unable to reply to each individual topic that is posted.

If you require more timely assistance, consider purchasing a license key: if you need help with The Events Calendar, for example, you could purchase an [Events Calendar PRO](https://theeventscalendar.com/product/wordpress-events-calendar-pro/) license key and, similarly, if you need help with Event Tickets, you might purchase an [Event Tickets Plus](https://theeventscalendar.com/product/wordpress-event-tickets-plus/) license key.

Thanks!
