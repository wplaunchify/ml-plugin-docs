## The Events Calendar Event Display

**Source:** [https://www.liquidweb.com/help-docs/software/events-calendar/event-display/](https://www.liquidweb.com/help-docs/software/events-calendar/event-display/)

The Event Display section for The Events Calendar provides site owners and designers with professional tools to customize how schedules, grids, and individual event listings appear across their WordPress site. Controlling your calendar’s layout is essential for highlighting high-priority events, matching your brand’s visual aesthetic, and providing a clean, easily navigable user interface. By utilizing these layout enhancements, you can ensure that your calendar remains visually engaging and highly structured for your community.

The documentation features a suite of tools built to elevate visual presentation and distribution:

**Using Featured Images with Events:** An exploration of how to attach media assets to scheduling profiles. This guide links core WordPress media workflows with your calendar layouts, explaining how to utilize high-resolution featured thumbnails to anchor individual event pages, improve list-view aesthetics, and boost overall engagement.

**The Calendar Embed Block:** A deep-dive guide into deploying the specialized Gutenberg block version of the popular 
```
[tribe_events]
```

 shortcode. This block allows administrators to seamlessly embed full, responsive calendar layouts directly into any WordPress post or page while using simple sidebar parameters rather than manually writing out complex shortcode attributes.

**Using Featured Events:** Instructions on how to utilize the “Feature Event” toggle within the post editor. Activating this parameter gives specified events a much more prominent, eye-catching design layout within both the monthly grid and standard list views, making it ideal for high-impact or premium gatherings.
