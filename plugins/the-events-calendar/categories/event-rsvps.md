## Creating RSVPs with Event Tickets

**Source:** [https://docs.nexcess.com/software/the-events-calendar/event-rsvps/](https://docs.nexcess.com/software/the-events-calendar/event-rsvps/)

Sometimes you may not want to sell tickets and charge a price for an event but would still like to have a list of people who will be attending. The RSVP ticket type in [Event Tickets](https://theeventscalendar.com/products/wordpress-event-tickets/) provides this functionality.

Instead of buying a ticket, entering credit card or PayPal information, or going through any other part of the checkout process, with the RSVP “ticket” option users just:

- Select a quantity for how many spots to RSVP.
- Enter their name and email address to confirm that they will be attending the event.
- Immediately receive a simple ticket confirming their reservation at the email address they entered.

**This article will show you how to enable and use the RSVP features of Event Tickets and Event Tickets Plus.**

**Note:**There is no eCommerce or payment-collection functionality with RSVPs. This article is only about the RSVP feature; to learn about selling tickets with Event Tickets and Event Tickets Plus, check out the [Making a Ticket](https://docs.nexcess.com/software/the-events-calendar/assigned-seating-tickets/) tutorial.

### Enabling RSVP Functionality

If you have The Events Calendar installed and activated on your site, then the RSVP meta box from Event Tickets will be enabled on events automatically. It will show up in the wp-admin edit screen for the events post type.

If you do not have The Events Calendar installed or would like to enable tickets on any other post type, first head to **Tickets → Settings** in your wp-admin. Once here, head to the “General” tab and check the boxes for each post type you want to use. [Read more about Event Tickets settings](https://docs.nexcess.com/software/the-events-calendar/event-tickets/).

### Using RSVP Functionality

#### Enabling RSVP

To add RSVPs, first head to the creation/edit screen. Scroll down and you will find the *RSVP*meta box (or RSVP block).

You’ll see the option to *Enable RSVP*on the event.

![RSVP metabox](https://docs.nexcess.com/wp-content/uploads/2019/10/rsvp-metabox-1024x330.png)The Enable RSVP option in the classic event editor

#### RSVP Fields

Once you’ve enabled RSVP, you’ll see additional options. Additional options such the RSVP waitlist are only available with Event Tickets Plus (part of our Pro license tier).

![](https://docs.nexcess.com/wp-content/uploads/2019/10/Screenshot-2026-09-14-at-10.07.21-AM-1024x801.png)

- **Limit** is the total number of spaces that are available: if you leave this blank it is assumed that there is no limit. If you have a limited number of spots for your event, you’ll want to make sure to set this accordingly.
- **Open RSVP** dictates when the RSVP becomes available. If you’re using RSVPs on a post or page, this field is required. If you are making RSVPs on an event, you don’t need to set this field- by default sales will start when you publish the event or ticket.
- **Close RSVP** does the reverse – you can set this to a date after which users cannot RSVP. As with the start sale field, setting this is optional for events and the default is to stop sales when the event itself starts.

If you have Event Tickets Plus, you will also see an option here for **collecting attendee information**. This feature allows you to request additional information beyond the name and email of the person RSVPing. You can learn about this feature in our separate [Attendee Information article](https://docs.nexcess.com/software/the-events-calendar/attendee-registration/).

If you’re using the block editor, enabling RSVP will look just a little bit different. Click in the default Event RSVP block or add a new RSVP block.

### Accepting RSVPs

Once you’ve enabled RSVP, site visitors can RSVP for the event. Once RSVPs are allowed according to the *Open RSVP* option, users will see something like this on your page:

![](https://docs.nexcess.com/wp-content/uploads/2019/10/Screenshot-2026-09-14-at-12.54.18-PM-1024x413.png)

![](https://docs.nexcess.com/wp-content/uploads/2019/10/Screenshot-2026-09-30-at-1.14.17-PM-1024x793.png)

If they click Going and enter their information, users will be tracked as RSVP attendees and receive a confirmation over email.

### Letting Attendees Edit RSVPs

Uers who have made RSVPs for your events to log in and edit their RSVP responses, attendee information, and more. From the event page, they can click the *View RSVP*link to go to their own page to make any necessary changes. Note that this feature requires attendees to create an account and log in before registering for your events.

![](https://docs.nexcess.com/wp-content/uploads/2019/10/Screenshot-2026-09-14-at-12.56.12-PM-1024x491.png)
