## Elementor Compatibility Handbook

**Source:** [https://docs.nexcess.com/software/the-events-calendar/elementor-compatibility-handbook/](https://docs.nexcess.com/software/the-events-calendar/elementor-compatibility-handbook/)

In this guide, we’ll discover how you can harness the power of Elementor to enhance your experience with The Events In this guide, we’ll discover how you can harness the power of Elementor to enhance your experience with The Events Calendar. Whether you’re looking to create stunning event pages, customize your calendar, or enhance your website’s design with event-related widgets, our products integrate with Elementor to offer endless possibilities for creativity and functionality.

The Events Calendar (version 6.4.0 and later) includes support for Elementor single event templates, providing native Elementor widgets for crafting your single event layouts. Elementor Free lets you [create static templates](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-single-event-templates-with-free-elementor), while Elementor Pro unlocks [dynamic templates for your events](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-dynamic-single-event-templates-with-elementor-pro) that apply automatically to every event matching your display conditions.

Our premium plugins add more. Events Calendar Pro includes four additional Elementor widgets and the 
```
[tribe_events]
```

 shortcode for embedding the calendar on Elementor pages. Event Tickets Plus adds Elementor widgets for displaying tickets and RSVPs.

**Event Tickets Plus:** The Event Tickets and Event RSVP Elementor widgets work with any of the setups above. They require Event Tickets and Event Tickets Plus, not Events Calendar Pro.

## Native Elementor widgets and shortcodes

- [Elementor Widgets for Events Calendar Pro](https://docs.nexcess.com/software/the-events-calendar/elementor-widgets/): Add the Event Countdown, Events List, Event, and Events View widgets to any page or post.
- [Elementor Widgets for Event Tickets Plus](https://docs.nexcess.com/software/the-events-calendar/elementor-widgets/#h-event-tickets-plus-widgets): Display ticket and RSVP forms on any page, post, or Elementor event template.
- [Using Shortcodes with Elementor Page Builder](https://docs.nexcess.com/software/the-events-calendar/elementor-widgets/#h-using-the-tribe-events-shortcode): Embed the main calendar on an Elementor page or page template with the 
```
[tribe_events]
```

 shortcode.
- [Customizing Event Data in Elementor](https://docs.nexcess.com/software/the-events-calendar/customize-elementor-data/): Snippets for showing only the next instance of a recurring event in Loop widgets, and for placing individual Additional Fields with a shortcode.

## Event templates with Elementor

[Using Elementor Templates with The Events Calendar](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/) covers each template workflow:

- [Static single event templates](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-single-event-templates-with-free-elementor): Apply the Single Event Starter Template with Elementor Free.
- [Dynamic single event templates](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-dynamic-single-event-templates-with-elementor-pro): Build templates in the Elementor Pro Theme Builder that apply to every event matching your display conditions.
- [Events with tickets](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-events-with-tickets): Add the Event Tickets widget (Event Tickets Plus) to your template, because tickets don’t appear on Elementor-designed event pages until you do.
- [Event Series pages](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-templates-for-event-series-pages): Create a template for Series pages with Events Calendar Pro and Elementor Pro.

## Using our plugins with the Hello Elementor theme

The Events Calendar works with Hello Elementor, Elementor’s own theme, the same way it works with any other WordPress theme. The [Single Event Starter Template workflow](https://docs.nexcess.com/software/the-events-calendar/elementor-templates/#h-single-event-templates-with-free-elementor) is documented using Hello Elementor alongside the Elementor and The Events Calendar plugins.
