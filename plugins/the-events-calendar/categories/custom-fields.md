## Adding Custom Fields to Events

**Source:** [https://docs.nexcess.com/software/the-events-calendar/custom-fields/](https://docs.nexcess.com/software/the-events-calendar/custom-fields/)

When creating your events, do you ever find yourself wishing there was a way to add additional information about your event? What about a checkbox to designate age-restricted events? Or a drop-down of “DJs” to select which one will be performing at the event? The ability to add these additional fields is included within our Events Calendar Pro plugin.

## Creating Additional Fields

To start creating additional fields, navigate to the **Events → Settings → Additional Fields** tab within your WordPress dashboard. Within this section, you can create as many of the following field types as you would like:

- Text
- Text Area
- URL
- Radio
- Checkbox
- Dropdown

When creating these fields, the “Field Label” will be the value that displays when editing the field as well as on the front end of your site when displaying the values assigned to it.

Also, when creating events, you’ll notice that the *radio*, *checkbox*, and *dropdown* options provide an additional field for setting the “Options”. This is where you can set the options for this field, one option per line.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/PRO-Additional-Fields-Settings-1.jpg)

## Adding Custom Fields to an Event

### Classic Editor

After your additional fields are created, they will be added to the edit screen for your events.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/PRO-Additional-Fields-Event-Edit-Screen.jpg)Classic Editor Additional Fields

### Block Editor

When adding a new block to display an Additional Field you can either search for “Additional fields”, which will list all of them (left screenshot), or search for the label of the additional field you want to add (right screenshot).

![](https://docs.nexcess.com/wp-content/uploads/2026/06/add-additional-fields-with-block-editor-1.jpg)Listing all additional fields in the block editor

![](https://docs.nexcess.com/wp-content/uploads/2026/06/add-additional-fields-with-block-editor-2.jpg)Searching for a specific additional field in the block editor

## Additional Fields on the Frontend

The values selected for the event will then be displayed within their own section on your event page.

![Additional fields appearing on the Block Editor](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-03-09-at-12.50.22-PM.jpg)

Additional fields can help you add all sorts of useful information right into your event pages. Have fun!
