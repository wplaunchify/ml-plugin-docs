## Museum Event Website Guide

**Source:** [https://docs.nexcess.com/software/the-events-calendar/museum-event-website-guide/](https://docs.nexcess.com/software/the-events-calendar/museum-event-website-guide/)

In this guide, we’ll walk you through the steps you need to create a museum event website from start to finish.

Check out [our blog post](https://theeventscalendar.com/blog/wordpress/how-to-create-a-museum-events-wordpress-site/) on creating a museum event website for even more inspiration.

Getting Started with WordPress

Before we can dive into the details of creating a custom museum website, we first need to get set up with WordPress. Here, you’ll also learn the basics of setting up themes and plugins on your WordPress site. Let’s take a look at how to get our website started!

- [Getting Started with WordPress](https://docs.nexcess.com/software/the-events-calendar/getting-started-with-wordpress/)
- [Install a WordPress Theme](https://docs.nexcess.com/software/the-events-calendar/install-a-wordpress-theme/)
- [How To Create a Child Theme (and Why)](https://docs.nexcess.com/software/the-events-calendar/how-to-create-a-child-theme-and-why/)
- [Installing a WordPress Plugin](https://docs.nexcess.com/software/the-events-calendar/downloading-and-installing-the-plugin/)

Using the Kadence Theme and Starter Templates

In this section, we’ll take a look at how to utilize the Kadence Theme and its starter templates to spin up a fully-designed museum event website in no time! In fact, you can use the Kadence Children’s Museum Starter Template to create your museum website in minutes.

- [Using Kadence Theme with The Events Calendar](https://docs.nexcess.com/software/the-events-calendar/kadence-theme/)

Adding Functionality with Plugins

Now that your website is set up, you can begin adding plugins that can improve the functionality of your museum event website. With The Events Calendar plugins, you can add events, tickets, and RSVPs to your WordPress site. Learn more in this section!

- [Creating Events](https://docs.nexcess.com/software/the-events-calendar/create-event/)
- [Using Featured Events](https://docs.nexcess.com/software/the-events-calendar/featured-events/)
- [Creating Virtual and Hybrid Events](https://docs.nexcess.com/software/the-events-calendar/create-virtual-event/)
