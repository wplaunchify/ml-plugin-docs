## The Events Calendar Event Attendees

**Source:** [https://www.liquidweb.com/help-docs/software/events-calendar/event-attendees/](https://www.liquidweb.com/help-docs/software/events-calendar/event-attendees/)

The Event Attendees section for The Events Calendar provides site administrators with complete structural control over visitor registrations, RSVP tracking, and ticket data. Efficiently managing your attendee database is crucial for coordinating smooth check-in workflows, handling post-event reporting, and personalizing communication. By offering a unified repository for all registration activity, this system bridges the gap between digital sales and real-world event coordination.

The platform focuses on three main areas of event operation: data management, front-end customization, and registration logic. Through the **Managing Event Attendees** overview, administrators can filter registrant data, check in guests, and manually edit profiles or export data sets. When shifts in scheduling or consumer requests happen, the system allows for **moving tickets and attendees** to entirely different listings or events. For tailored experiences, event coordinators can create complex **Attendee Registration Forms** via Event Tickets Plus to collect dietary rules, sizes, or custom information, while advanced formatting adjustments can be applied by **customizing the registration page design** or extending the backend reporting interface.
