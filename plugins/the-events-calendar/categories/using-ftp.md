## Using FTP

**Source:** [https://docs.nexcess.com/software/the-events-calendar/using-ftp/](https://docs.nexcess.com/software/the-events-calendar/using-ftp/)

You may have heard the term **FTP** before when referring to updates on your WordPress site. For some of our more advanced users, you can update your WordPress using File Transfer Protocol (FTP) instead of through your WordPress Dashboard.

## Why use FTP?

The advantages of FTP are the fast file transfer speed, ability to transfer multiple files and directories all in one place, and no size limits on single transfers.

Beyond that, it’ll streamline your update process and can create a seamless workflow between your local and server environments.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/evergreen-ad-events-calendar-1024x384-1.png)

## What is FTP used for?

You can use FTP to make updates to your website, including:

- [Manual updates to plugins](https://docs.nexcess.com/software/the-events-calendar/manual-updates/)
- [Installing plugins](https://docs.nexcess.com/software/the-events-calendar/downloading-and-installing-the-plugin/) (like [The Events Calendar](https://theeventscalendar.com/products/wordpress-events-calendar/))
- [Installing WordPress themes](https://docs.nexcess.com/software/the-events-calendar/install-a-wordpress-theme/)

## How can I access FTP?

In order to make changes to your website via FTP, follow these steps:

1. Download an FTP client, like [FileZilla](https://filezilla-project.org/).
2. Install FileZilla by double-clicking on the file. The process will vary slightly, depending on the operating system that you are using.
3. Open the FTP client app and enter your host, username, password, and port and click QuickConnect.
4. You can now update, add, and delete files from your WordPress site via FTP.

This article is a great resource to [take you through the steps](https://www.wikihow.com/Use-FTP) in-depth.
