## How to Block a WordPress User

**Source:** [https://docs.nexcess.com/software/the-events-calendar/how-to-block-a-wordpress-user/](https://docs.nexcess.com/software/the-events-calendar/how-to-block-a-wordpress-user/)

The situation may come up where you’d like to block a WordPress user from doing additional things on your WordPress site, like adding events, purchasing tickets, or interacting with your content in general.

Deleting their account entirely is one way to achieve this, but if the user has already added events with [Community Events](https://theeventscalendar.com/products/community-events/), or purchased tickets, you’ll need to reassign any of their content to another user.

Instead of going through this hassle, you can lock their account, with the help of a third-party plugin.

Let’s take a look at how to make this happen!

## Install Lock User Account

The first thing you’ll want to do is install the free third-party plugin, [Lock User Account](https://wordpress.org/plugins/lock-user-account/). To learn more about how to install a plugin, check out [this Knowledgebase article](https://docs.nexcess.com/software/the-events-calendar/downloading-and-installing-the-plugin/).

![Install Lock User Account](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-06-24-at-11.42.50-AM.jpg)

![](https://docs.nexcess.com/wp-content/uploads/2026/06/banner-ad-tec-demo-site-1024x384-1.png)

## Block a WordPress User

Once you have the plugin installed, simply head over to the **WordPress Dashboard > Users** > **All Users**.

Select the checkbox next to the user you’d like to block. Go to the **Bulk** **Actions** dropdown menu, choose **Lock** and click **Apply**.

![Block a WordPress user ](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-06-24-at-11.55.43-AM.jpg)

Once you do, you’ll see that the chosen account has been locked.

![WordPress user is now blocked](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-06-24-at-12.06.17-PM.jpg)

When this user tries to log in, they’ll see a message that their account is locked and they will not be able to log in to your WordPress site.

![Account is locked ](https://docs.nexcess.com/wp-content/uploads/2026/06/Screen-Shot-2022-06-24-at-12.10.45-PM.jpg)
