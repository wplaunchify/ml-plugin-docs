## Creating Ticket Coupons with WooCommerce

**Source:** [https://docs.nexcess.com/software/the-events-calendar/ticket-coupons-woocommerce/](https://docs.nexcess.com/software/the-events-calendar/ticket-coupons-woocommerce/)

👋 This guide explains how to create **WooCommerce** coupons. If you’re using **Tickets Commerce** then please follow [this guide](https://docs.nexcess.com/software/the-events-calendar/event-tickets-coupons/).

When selling tickets to events, offering discounts can be a powerful way to boost sales, reward loyal attendees, or run limited-time promotions.

WooCommerce opens up a lot of options for Event Tickets Plus users, and in this article, we’ll show you how to create some simple coupons.

👋 While WooCommerce is a free plugin, using WooCommerce with Event Tickets requires [Event Tickets Plus](https://theeventscalendar.com/products/wordpress-event-tickets/)

### Creating Coupons

You can get started creating coupons by following WooCommerce’s documentation at [https://docs.woocommerce.com/document/coupon-management/](https://docs.woocommerce.com/document/coupon-management/).

We’ll go over this in a bit more depth.

First, make sure that Event Tickets Plus and WooCommerce are both fully updated. Then you can go ahead and create an Event and add a Ticket to it, or you can add one to an already created event.

Next, head to the WooCommerce’s Marketing options under **Marketing > Coupons**. This menu will let you create them:

![WooCommerce Coupons menu](https://docs.nexcess.com/wp-content/uploads/2026/06/WooCommerce-Coupons-menu-1024x453-1.jpg)Create and manage coupons under **Marketing > Coupons**

Simply click on **Add Coupon** and it will bring up the creation menu.

Here, you can create different types of coupons as well. There are multiple options for the type of coupon, either a percentage discount, or a fixed discount. You can also limit or restrict the coupon itself; how many times it can be used, the minimum cart price for it to be allowed and much more!

![WooCommerce Coupon code](https://docs.nexcess.com/wp-content/uploads/2026/06/WooCommerce-Coupon-1024x574-1.jpg)Edit Coupon screen

These coupons can then be used on the WooCommerce Checkout page after adding a ticket. Depending on your theme, this may require clicking **Have a coupon? Click here to enter your code** first. Type the code in the box and you should see your discount pop up!
