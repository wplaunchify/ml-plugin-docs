## Plugin Installed but Features Are Missing

**Source:** [https://docs.nexcess.com/software/the-events-calendar/plugin-installed-but-features-are-missing/](https://docs.nexcess.com/software/the-events-calendar/plugin-installed-but-features-are-missing/)

If you’ve installed one of our premium plugins but some features are missing or not working as expected, then this is often a quick fix. Below are the two most common reasons for this issue and how to resolve them.

---

## 1. Make Sure the Plugin Is Activated

Sometimes, the plugin may be installed but not actually active on your site.

### How to check if the plugin is activated:

1. In your WordPress dashboard, go to **Plugins > Installed Plugins**.
2. Look for the name of the plugin you installed.
3. If you see an **“Activate”** link under the plugin name, it means the plugin is currently **inactive**.
4. Click **Activate**.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-4-scaled-1.jpg)

> For our premium features to work, the plugin must be active. Repeat this for any related plugins that we offer.

---

## 2. Check for Version Compatibility

Our plugins are designed to work together as a suite. If one plugin has been updated but others haven’t, this can cause features to disappear or break.

### Why this happens:

When we release an update, the **common code shared across our plugins** may change. To ensure compatibility, all related plugins need to be updated to the latest version at the same time. Running mismatched versions can result in features not showing up, even if the plugin is active.

### How to check and fix version issues:

1. In your WordPress dashboard, go to **Plugins > Installed Plugins**.
2. Look for any of our plugins that say **“Update Available”** and note which versions are currently active.
3. Update **all plugins in our suite** to the latest versions.
- You can update them by clicking the **“Update now”** link next to each plugin.
4. Once all plugins are updated, refresh your site or plugin settings page to see if the missing features appear.

> You may also see a notice in your dashboard prompting you to update multiple plugins together — make sure to follow it if you do.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/image-5-6.jpg)

## Still not seeing the features?

If the plugin is active and all related plugins are updated, but you’re still missing features:

- Clear your [site and browser cache.](https://docs.nexcess.com/software/the-events-calendar/how-to-clear-your-site-and-browser-cache-properly/)
- Check for [plugin conflicts](https://docs.nexcess.com/software/the-events-calendar/testing-for-conflicts/) by deactivating other non-related plugins temporarily.
- Contact our support team with your [system information](https://docs.nexcess.com/software/the-events-calendar/sharing-your-system-information/), and we’ll help you troubleshoot further.
