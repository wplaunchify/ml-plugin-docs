## Using Default Content on Events

**Source:** [https://docs.nexcess.com/software/the-events-calendar/default-event-content/](https://docs.nexcess.com/software/the-events-calendar/default-event-content/)

Say you have a calendar where 90% of the events happen in the same city, or even at the same venue. We’ve got you covered with Event Calendar PRO’s Default Content feature.

Customized defaults are an option for Events Calendar PRO users. Log on to your site’s backend, scroll to *Events → Settings*, and click the Default Content tab.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Default-content-1.jpg)

The top two options allow you to set a Default Venue or Default Organizer using respective tabs. The dropdown lists all of your published organizers or venues, which are editable from the Venue and Organizer admin pages. If you don’t want to use a Default Venue or Organizer, leave the dropdown blank or select No default.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Default-organizer-2.jpg)

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Default-venuie.jpg)

Below the dropdowns are the default address fields. Fill in any of the fields you want to use. Remember that these options will be automatically filled in on your New Event page, but you can still change them there as needed.

If you have a Default Venue applied *and*add Default Address information, the Default Venue will show on your backend Event pages. If you opt to add a new venue instead of using the default one, the Default Address information will be automatically entered into the new venue fields.

![](https://docs.nexcess.com/wp-content/uploads/2026/06/Default-venue-address.jpg)

You can add as many or as few custom default options as you want — in the screenshot above, all I’ve set is a default state (Washington). If I wanted to save even more time on the event creation side, I could set a default address or make a custom list of countries.
