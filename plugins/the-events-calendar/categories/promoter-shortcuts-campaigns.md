## Creating Promoter Shortcuts and Campaigns

**Source:** [https://docs.nexcess.com/software/the-events-calendar/promoter-shortcuts-campaigns/](https://docs.nexcess.com/software/the-events-calendar/promoter-shortcuts-campaigns/)

Promoter includes two features for reusing message configurations across events: **shortcuts** and **campaigns**. Shortcuts are individual reusable message templates. Campaigns are collections of shortcuts that can be applied to an event all at once. This article covers both.

## Promoter Shortcuts

A shortcut is a message template you can use to quickly create emails over and over again. With a shortcut, you pre-define:

- **Subject line and message content** — copy and [merge tags](https://docs.nexcess.com/software/the-events-calendar/event-categories-tags/)
- **Default audience** — attendees of this event, or attendees of all events
- **Scheduling** (optional) — when the message will be sent relative to the event’s date, start time, or end time

For example, instead of manually writing a reminder to attendees 3 days before every event, you can use the “Event Reminder” shortcut. In one click, your reminder is ready to go.

Shortcuts are accessible from two places:

**From the Shortcuts menu** — there is a link to your shortcuts in the main Promoter navigation.

![The Shortcuts link in the Promoter main navigation menu](https://docs.nexcess.com/wp-content/uploads/2026/06/shortcuts-menu.png)

**From the message editor** — shortcuts are also accessible while creating a new message.

![The shortcuts panel accessible from within the Promoter message editor](https://docs.nexcess.com/wp-content/uploads/2026/06/new-message.png)

### Working with Shortcuts

The Shortcuts page lists Promoter’s twelve default shortcuts.

![The Promoter Shortcuts page showing the twelve default shortcuts](https://docs.nexcess.com/wp-content/uploads/2026/06/twelve.png)

### Default Shortcut Actions

Each default shortcut supports the following actions:

![The action menu for a default shortcut in Promoter showing Preview, Edit, Duplicate, and Add to event options](https://docs.nexcess.com/wp-content/uploads/2026/06/default-shortcut-actions.png)

- **Preview** — View the shortcut’s message before using it.
- **Edit** (aka Customize) — Modify the shortcut’s content, audience, or schedule.
- **Duplicate** — Create a copy of the shortcut as a starting point for a custom version, without modifying the original.
- **Add to event** — Automatically schedule the pre-written message for selected events.

### Creating Custom Shortcuts

Custom shortcuts can be created in one of three ways from the Shortcuts page:

![The Create Custom Shortcut block on the Promoter Shortcuts page](https://docs.nexcess.com/wp-content/uploads/2026/06/promoter-create-shortcut.png)

1. Click the **Create Custom Shortcut** block to start from scratch.
2. Select **Edit** from a default shortcut’s action menu to customize that default shortcut directly.
3. Select **Duplicate** from a default shortcut’s action menu to create a custom copy.

### Custom Shortcut Actions

Custom shortcuts support the same four actions as default shortcuts, plus two additional ones:

![The action menu for a custom shortcut in Promoter, showing the additional Delete and Revert options](https://docs.nexcess.com/wp-content/uploads/2026/06/promoter-shortcuts-actions.png)

- **Delete** — Permanently removes a custom shortcut. Applies only to shortcuts created from scratch or duplicated from a default.
- **Revert** — Undoes any customization applied to a default shortcut, restoring it to its original factory settings. Applies only to default shortcuts that were edited.

## Promoter Campaigns

A campaign is a reusable collection of shortcuts that you can assign to an event in one step. Rather than adding shortcuts to an event one at a time, a campaign lets you apply a curated set of messages — your pre-event reminder, day-of message, post-event follow-up, and so on — all at once.

#### Creating a Campaign

Head to the Shortcuts page and expand the **Create a campaign** sidebar.

![The Create a Campaign sidebar expanded on the Promoter Shortcuts page](https://docs.nexcess.com/wp-content/uploads/2026/06/image-1024x553-1.png)

Shortcuts can be added to a campaign in one of two ways:

1. **Manually selecting shortcuts** — choose the shortcuts you use most often.
2. **Using the starter campaign** — a set of commonly used default shortcuts for a successful event promotion (the default shortcuts can be modified).

![The two campaign creation options: manually select shortcuts or use the starter campaign](https://docs.nexcess.com/wp-content/uploads/2026/06/image-2-1024x573-1.png)

### Manually Selecting Shortcuts

Click **Add a Shortcut to this campaign**. The screen will switch to Shortcut Adding Mode. Click the large plus (+) icon on any shortcut to add it to the campaign. When you’re done with your selection, click **Save** to exit Shortcut Adding Mode.

**Pro tips:**

- Campaigns require a minimum of two shortcuts.
- The default audience and schedule (if any) are shown in each shortcut box to help you decide which ones to include.

![Shortcut Adding Mode in Promoter showing shortcuts with plus icons to add them to a campaign](https://docs.nexcess.com/wp-content/uploads/2026/06/image-3-1024x496-1.png)

![A campaign taking shape with several shortcuts added](https://docs.nexcess.com/wp-content/uploads/2026/06/image-4-1024x503-1.png)

### Using the Starter Campaign

Click **Check out our Starter Campaign** to preview the suggested shortcuts. Click **Add Shortcuts** once you’ve reviewed them. You can remove any suggested shortcut after adding it.

![The Starter Campaign preview in Promoter showing the suggested shortcuts](https://docs.nexcess.com/wp-content/uploads/2026/06/image-5-1024x595-1.png)

![A campaign created from the Starter Campaign with shortcuts added](https://docs.nexcess.com/wp-content/uploads/2026/06/image-6-1024x475-1.png)

### Removing Shortcuts from a Campaign

You can remove a shortcut from a campaign at any time by clicking its contextual menu and selecting **Remove from campaign**.

![The contextual menu on a shortcut within a campaign, showing the Remove from campaign option](https://docs.nexcess.com/wp-content/uploads/2026/06/image-7-3.png)

Save the campaign when you’re done. Additional shortcuts can be added at any time by clicking **Add a Shortcut to this campaign**.

### Applying a Campaign to an Event

Campaigns are designed to be applied to events. To add a campaign to an event:

1. Navigate to the event of your choice.
2. Click the **Add Your Campaign** option.

![The Add Your Campaign option on an event in Promoter](https://docs.nexcess.com/wp-content/uploads/2026/06/image-13-1024x327-1.png)

![The campaign selection screen in Promoter](https://docs.nexcess.com/wp-content/uploads/2026/06/image-14-1024x504-1.png)

You’ll be taken to a confirmation screen. Review your shortcut selections carefully before proceeding — you can still adjust them at this step.

![The campaign confirmation screen in Promoter showing the shortcuts that will be applied to the event](https://docs.nexcess.com/wp-content/uploads/2026/06/image-16-1024x578-1.png)

After confirming, you’ll see a list of messages that were created as a result of adding the campaign to the event. All messages are set to Draft status and won’t send until they have been published. You can still undo the campaign at this stage by removing the messages from the Messages screen.

![The messages list for an event after a campaign has been applied, showing all messages in Draft status](https://docs.nexcess.com/wp-content/uploads/2026/06/image-17-1024x583-1.png)
