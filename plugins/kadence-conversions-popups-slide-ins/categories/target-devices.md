## Target Devices

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-conversions/target-devices/](https://www.kadencewp.com/help-center/docs/kadence-conversions/target-devices/)

Kadence Conversion items can be set to target specific devices. If your conversion item is too large for mobile devices, it may make sense to target only devices that can reasonably handle the conversion item.

In the following example, we have selected both desktop and tablet devices, thus eliminating the targeting for mobile devices. Toggle the desired devices by selecting them one at a time.
