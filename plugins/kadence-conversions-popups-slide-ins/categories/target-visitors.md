## Target Visitors

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-conversions/target-visitors/](https://www.kadencewp.com/help-center/docs/kadence-conversions/target-visitors/)

If you’d only like to show your conversion items to specific user roles, you can limit your target audience with this Kadence Conversion setting. When used in combination with targeted pages, you can gain greater control over how your conversion items are shown

By default, Kadence Conversions will show your conversion item to all users. However, you can select to show, or exclude, users from seeing a conversion item.

Target users based on their logged in/logged out status.

Users are identified by their role, which can only be identified if they are logged into your site. If they are not logged in, they cannot be identified as a specific user role and as such your user targeting won’t apply.

If you are using WooCommerce, you can target users by shop manager user role and customer user role. If you are using LearnDash, you can target users by their plugin-specific roles including student, LMS manager, instructor, and instructor’s assistant.

Any plugin that adds a user role will have that role available to you for user targeting, and user exclusion, in Kadence Conversions.
