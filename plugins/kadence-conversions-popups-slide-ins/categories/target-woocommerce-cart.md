## Target WooCommerce Cart

**Source:** [https://www.kadencewp.com/help-center/docs/kadence-conversions/target-woocommerce-cart/](https://www.kadencewp.com/help-center/docs/kadence-conversions/target-woocommerce-cart/)

If you are using WooCommerce with Kadence Conversions, there are some specific settings that will allow you to personalize the conversion item for specific shoppers and their interactions with your storefront. Change settings based on cart totals or if they’re purchasing a specific product or products. These include the following settings:

#### Only show cart total is more than.

Toggle this setting on and then set the number of cart items.

#### Only show cart total is less than.

Toggle this setting on and then set the number of cart items.

#### Only show if specific products in cart.

Toggle this setting on and then select the products you’d like the conversion shown for. You can toggle as many products as needed.

#### Hide if specific products in cart.

Toggle this setting on and then select the products you’d like the conversion hidden for. You can toggle as many products as needed.
